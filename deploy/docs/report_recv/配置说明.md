# 报告接收插件配置说明

> 配置位置：`config/web_monitor.yaml` 顶层 `report_recv:` 段
> 关联文档：[使用指南](./报告接收插件使用指南.md) §2.3、doc/70 §5.5
> 文档性质：**配置参考**（字段含义、取值、加载链路、定制方法）

---

## 1. 配置位置

报告接收插件**不是独立加载的插件**，而是内嵌在 `web_monitor` 插件里（`web_server.py` 直接 import `ReportRecvPlugin`）。因此它的配置不放在 `config/plugin_configs/`，而是通过 `config/web_monitor.yaml` 顶层的 `report_recv:` 段来定制。

```
config/
  web_monitor.yaml       ← 在此顶层加 report_recv: 段定制路径
  params.yaml            ← 主参数（plugin_load_order 等）
  plugin_configs/        ← 独立插件配置（report_recv 不在此）
```

> **默认部署无需任何配置**：`report_recv:` 段缺省时，三个路径回落到代码内置默认值（`<包目录>/config/...`）。

---

## 2. 完整配置模板

在 `config/web_monitor.yaml` 顶层追加 `report_recv:` 段：

```yaml
report_recv:
  db_path: "config/app.db"              # SQLite 数据库文件位置
  raw_json_dir: "config/data/reports"   # 整包原始 JSON 留存目录
  evidence_dir: "config/data/evidence"  # evidence 抓拍图存储目录
```

三个键都可缺省，缺省时用代码内置默认值。

---

## 3. 字段详解

### 3.1 `db_path`

| 项 | 说明 |
|---|---|
| 含义 | 报告六表（reports/report_steps/report_substeps/report_events/report_progress/subscriptions）的 SQLite 数据库文件路径 |
| 类型 | string（相对路径，相对工作目录；也支持绝对路径） |
| 默认值 | `<包目录>/config/app.db`（代码内置，yaml 未配置时） |
| 取值约束 | 父目录可写；首次启动自动建表；切换路径需迁移旧库 |
| 常见定制 | 多实例隔离：`db_path: "/data/report_recv_instance_1.db"` |

### 3.2 `raw_json_dir`

| 项 | 说明 |
|---|---|
| 含义 | 整包原始 JSON 留存目录，文件命名 `{device_id}/{report_id}.json` |
| 类型 | string（相对/绝对路径） |
| 默认值 | `<包目录>/config/data/reports` |
| 取值约束 | 目录可写；长期运行需配保留策略（如 90 天清理）防止磁盘满 |
| 常见定制 | 独立数据盘：`raw_json_dir: "/data/reports_raw"` |

### 3.3 `evidence_dir`

| 项 | 说明 |
|---|---|
| 含义 | evidence 抓拍图存储目录，文件命名 `{device_id}/{round_start_ms}/sub_{sub}_ts_{ts}.jpg` |
| 类型 | string（相对/绝对路径） |
| 默认值 | `<包目录>/config/data/evidence` |
| 取值约束 | 目录可写；图片体积较大，建议挂独立盘 |
| 常见定制 | 独立数据盘：`evidence_dir: "/data/evidence"` |

## 4. 配置加载链路

```
config/web_monitor.yaml 顶层 report_recv: 段
    │
    ▼
web_monitor_plugin.py::_init_component_config()
    │  self.plugin_config = yaml.load("config/web_monitor.yaml")
    │  self._web_server_config['report_recv']
    │      = self.plugin_config.get('report_recv', {})
    ▼
WebServer.__init__(config=self._web_server_config)
    │
    ▼
web_server.py::report_plugin = ReportRecvPlugin(
    config=self.config.get('report_recv', {})
)
    │
    ▼
ReportRecvPlugin.__init__()
    │  self._db_path     = self.config.get("db_path",     <代码默认>)
    │  self._raw_json_dir = self.config.get("raw_json_dir", <代码默认>)
    │  self._evidence_dir = self.config.get("evidence_dir", <代码默认>)
    ▼
插件加载完成，三个路径键生效
```

关键透传点在 `web_monitor_plugin.py::_web_server_config`：

```python
self._web_server_config = {
    ...
    'report_recv': self.plugin_config.get('report_recv', {}),  # 透传
}
```

## 5. 定制方法

### 5.1 方法 A：在 `web_monitor.yaml` 加 `report_recv` 段（推荐）

在 `config/web_monitor.yaml` 顶层追加：

```yaml
report_recv:
  db_path: "/data/report_recv/app.db"
  raw_json_dir: "/data/report_recv/raw_json"
  evidence_dir: "/data/report_recv/evidence"
```

重启 Web 服务即生效。`web_monitor_plugin._web_server_config` 已透传 `report_recv` 段，插件会读取这三个键。

### 5.2 方法 B：不改配置，用代码默认路径

零配置即用。数据库、原始 JSON、evidence 全部落到 `<包目录>/config/` 下。常规单机部署足够。
