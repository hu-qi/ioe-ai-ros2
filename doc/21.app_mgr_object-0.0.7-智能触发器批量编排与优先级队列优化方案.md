## 1. 现状分析与问题诊断

### 1.1 当前触发流程

```
_scan_loop() 每 2s 运行一次:
  for cargo_type in 1..6:
    ctx = engine.scan(cargo_type)           ← 每个类型只找一个配对
    if ctx:
      publish trigger.task_created           ← 立即下发
      break                                   ← 扫描结束

engine.scan(cargo_type):
  src_bay = cache.get_any_bound_bay(type)   ← "任一个" 已绑定仓位
  dst_bay = cache.get_any_empty_bay(type)   ← "任一个" 空终点仓位
  robot   = cache.get_idle_robot()          ← "任一个" 空闲 AGV
  if all exist: lock → return ONE task
```

### 1.2 四个缺陷

| 缺陷 | 根因 | 实际影响 |
|:---|:---|:---|
| **D1: 单任务瓶颈** | `scan()` 每次只返回 1 个 TaskContext | A1001/A1002 同时有货,但只触发 A1001→T2001, A1002 被忽略 |
| **D2: 无优先级** | `get_any_bound_bay()` 返回第一个匹配 | 无法按仓位编号/到货时间/紧急程度排列 |
| **D3: 无队列缓冲** | 匹配成功立即下发, 无排队机制 | AGV 繁忙时任务被丢弃, 需等下一轮扫描 |
| **D4: 盲目循环** | `for 1..6` 必须遍历全部才可能匹配 | 类型 1 有 3 个仓位时, 只能触发 1 个 |

### 1.3 实际场景示例

```
当前状态:
  起始仓位: A1001(已绑定,type=1), A1002(已绑定,type=1), B1001(已绑定,type=1)
  终点仓位: T2001(空,type=1), T2002(空,type=1), T3001(空,type=4)
  AGV:      1001(IDLE)

当前行为:
  scan(1) → A1001 → T2001 → robot=1001 → 1 个任务
  A1002, B1001 被忽略 ← 浪费

期望行为:
  batch_scan(1) → [(A1001,T2001,1001), (A1002,T2002,1001)]
  → 按优先级排序 → 入队 → AGV 空闲时逐一下发
  → 1001 执行 A1001→T2001 完成后, 自动下发 A1002→T2002
```

## 2. 优化方案设计

### 2.1 新架构

```
                         ┌─────────────────────────────────┐
                         │   SmartTriggerPlugin             │
                         │                                 │
                         │  _scan_loop() 每 2s              │
                         │    │                            │
                         │    ├─ batch_scan_all()           │
                         │    │   → TaskBatchMatcher        │
                         │    │   → [TaskCandidate...]       │
                         │    │   → sort_by_priority()       │
                         │    │                            │
                         │    ├─ TaskQueue.enqueue_all()     │
                         │    │                            │
                         │    └─ _dispatch_from_queue()      │
                         │        → AGV 空闲?               │
                         │        → dequeue → publish       │
                         │        → mark AGV busy           │
                         └──────────────┬──────────────────┘
                                        │
                         ┌──────────────┴──────────────────┐
                         │   事件驱动                        │
                         │   workflow.task_completed        │
                         │   bay.bound                      │
                         │   → _dispatch_from_queue()       │
                         └─────────────────────────────────┘
```

### 2.2 核心组件

| 组件 | 职责 | 位置 |
|:---|:---|:---|
| **TaskBatchMatcher** (新建) | 扫描所有缓存, 返回全部匹配的候选任务列表 | `components/trigger/batch_matcher.py` |
| **TaskQueue** (新建) | 优先级 FIFO 队列, AGV 感知的逐一下发, 去重保护 | `components/trigger/task_queue.py` |
| **TriggerEngine** (修改) | 整合 BatchMatcher, 新增 `batch_scan_all()` | `components/trigger/trigger_engine.py` |
| **SmartTriggerPlugin** (修改) | 整合 TaskQueue, 事件驱动的 dispatch | `plugins/smart_trigger_plugin.py` |

### 2.3 数据流

```
_scan_loop (每 2s):
  1. batch_scan_all()
     → 遍历 6 个 cargo_type
     → 对每个 type: 收集所有已绑定 src_bay + 所有空 dst_bay
     → 笛卡尔积匹配 (src × dst)
     → 去重 (已锁定/已在队列的跳过)
     → 优先级排序
     → 返回 [TaskCandidate...]

  2. queue.enqueue_all(candidates)
     → 入队 (去重保护)
     → 触发内部排序

  3. _dispatch_from_queue()
     → queue.peek_next() → 检查 AGV 空闲?
     → queue.dequeue() → 锁定资源
     → publish trigger.task_created
```

## 3. 优先级规则体系

### 3.1 排序规则 (多层排序, 从左到右)

```
TaskCandidate 排序键 = (
    货物类型优先级,      # 1. cargo_type 全局排序 (越小越优先)
    起始仓位编号,         # 2. src_bay 字母序 (A1001 < A1002 < B1001)
    终点仓位编号,         # 3. dst_bay 字母序 (同起始仓库就近原则)
    绑定时戳              # 4. bind_time 最早优先 (先到先服务)
)
```

### 3.2 cargo_type 优先级配置 (可配)

```yaml
# params.yaml 新增
smart_trigger:
  auto_start: true
  enabled: true
  scan_interval: 2.0
  # === 新增: 优先级配置 ===
  cargo_priority: [1, 2, 3, 4, 5, 6]   # 类型 1 最优先
  max_tasks_per_scan: 10                # 单次扫描最大任务数
  max_queue_size: 50                    # 队列最大容量
```

### 3.3 匹配规则

| 条件 | 逻辑 |
|:---|:---|
| 起始仓位 | `bind_status == 1` AND `in_task == False` AND `ai_detected == True` |
| 终点仓位 | `cargo_type == src.cargo_type` AND `is_empty == True` |
| AGV | `status == 'IDLE'` (下发时检查, 非入队时) |
| 去重 | 同一 (src_bay, dst_bay) 不重复入队 |

## 4. Step 1: 新建 TaskBatchMatcher 组件

**文件路径**: `app_mgr_object/components/trigger/batch_matcher.py` **(新建)**

```python
#!/usr/bin/env python3
"""
TaskBatchMatcher — 批量仓位匹配器

职责:
  - 扫描所有已绑定起始仓位和空终点仓位
  - 笛卡尔积生成候选任务列表
  - 按优先级规则排序
  - 去重 (排除已锁定/已在队列)
"""

import logging
from typing import List, Dict, Optional
from dataclasses import dataclass, field


@dataclass
class TaskCandidate:
    """候选任务 — 尚未锁定的匹配对"""
    src_bay: str
    dst_bay: str
    cargo_type: int
    bind_time: float = 0.0

    def key(self, cargo_priority: List[int]) -> tuple:
        """生成排序键"""
        # cargo_type 优先级 (在 priority 列表中的索引, 越小越优先)
        try:
            type_rank = cargo_priority.index(self.cargo_type)
        except ValueError:
            type_rank = 99

        return (
            type_rank,         # 类型优先级
            self.src_bay,      # 起始仓位字母序
            self.dst_bay,      # 终点仓位字母序
            -self.bind_time,   # 绑定时戳大的优先 (负值 = 最新优先)
        )


class TaskBatchMatcher:
    """批量仓位匹配器"""

    def __init__(self,
                 bay_cache,
                 dest_cache,
                 cargo_priority: List[int] = None,
                 logger: logging.Logger = None):
        """
        Args:
            bay_cache:     BayCache 实例
            dest_cache:    DestBayCache 实例
            cargo_priority: 货物类型优先级列表, 如 [1,2,3,4,5,6]
            logger:        日志记录器
        """
        self._bay_cache = bay_cache
        self._dest_cache = dest_cache
        self._cargo_priority = cargo_priority or list(range(1, 7))
        self._logger = logger

    # ════════════════════════════════════════════════════
    #  批量匹配
    # ════════════════════════════════════════════════════

    def batch_scan_all(self,
                       max_tasks: int = 10,
                       exclude_src: set = None,
                       exclude_dst: set = None) -> List[TaskCandidate]:
        """扫描所有货物类型, 返回全部候选任务

        Args:
            max_tasks:    单次扫描最大返回数
            exclude_src:  已锁定/已入队的起始仓位集合
            exclude_dst:  已锁定/已入队的终点仓位集合

        Returns:
            按优先级排序的候选任务列表
        """
        exclude_src = exclude_src or set()
        exclude_dst = exclude_dst or set()
        all_candidates: List[TaskCandidate] = []

        for cargo_type in self._cargo_priority:
            if len(all_candidates) >= max_tasks:
                break

            # 获取该类型下所有可用起始仓位
            available_src = self._bay_cache.get_bound_bays_of_type(
                cargo_type, exclude_in_task=True
            )
            # 过滤已锁定/已入队
            available_src = [b for b in available_src if b not in exclude_src]

            if not available_src:
                continue

            # 获取该类型下所有空终点仓位
            empty_dst = self._dest_cache.get_empty_bays_of_type(cargo_type)
            empty_dst = [b for b in empty_dst if b not in exclude_dst]

            if not empty_dst:
                continue

            # 笛卡尔积: src × dst
            for src_bay in available_src:
                if len(all_candidates) >= max_tasks:
                    break

                # 获取该仓位的绑定时戳
                bay_status = self._bay_cache.get_bay_status(src_bay)
                bind_time = bay_status.get('bind_time', 0.0) if bay_status else 0.0

                for dst_bay in empty_dst:
                    if len(all_candidates) >= max_tasks:
                        break

                    candidate = TaskCandidate(
                        src_bay=src_bay,
                        dst_bay=dst_bay,
                        cargo_type=cargo_type,
                        bind_time=bind_time,
                    )
                    all_candidates.append(candidate)

        # 按优先级排序
        all_candidates.sort(key=lambda c: c.key(self._cargo_priority))

        if self._logger:
            self._logger.info(
                f"批量匹配完成: {len(all_candidates)} 候选任务 "
                f"(exclude_src={len(exclude_src)}, exclude_dst={len(exclude_dst)})"
            )

        return all_candidates[:max_tasks]

    def get_exclusion_sets(self, locked_src: set, locked_dst: set,
                           queued_src: set, queued_dst: set) -> tuple:
        """合并排除集合"""
        return (
            locked_src | queued_src,
            locked_dst | queued_dst,
        )
```

## 5. Step 2: 新建 TaskQueue 组件

**文件路径**: `app_mgr_object/components/trigger/task_queue.py` **(新建)**

```python
#!/usr/bin/env python3
"""
TaskQueue — 任务优先级队列 + AGV 感知分发

职责:
  - 维护候选任务 FIFO 队列 (已排序)
  - 去重保护 (同一 src→dst 不重复入队)
  - AGV 感知: 检查 AGV 空闲时才出队
  - 资源锁定: 出队时同步调用 ResourceLocker.lock()
"""

import threading
import logging
from typing import List, Optional, Set
from .batch_matcher import TaskCandidate


class TaskQueue:
    """任务优先级队列"""

    def __init__(self,
                 resource_locker,
                 robot_cache,
                 bay_cache,
                 logger: logging.Logger = None):
        """
        Args:
            resource_locker: ResourceLocker 实例
            robot_cache:     RobotCache 实例
            bay_cache:       BayCache 实例
            logger:         日志记录器
        """
        self._locker = resource_locker
        self._robot_cache = robot_cache
        self._bay_cache = bay_cache
        self._logger = logger

        self._lock = threading.Lock()
        self._queue: List[TaskCandidate] = []
        self._queued_src: Set[str] = set()
        self._queued_dst: Set[str] = set()

        # 统计
        self._enqueue_count: int = 0
        self._dequeue_count: int = 0
        self._skip_duplicate_count: int = 0

    # ════════════════════════════════════════════════════
    #  入队
    # ════════════════════════════════════════════════════

    def enqueue_all(self, candidates: List[TaskCandidate]) -> int:
        """批量入队 (去重)

        Returns:
            实际入队的数量
        """
        added = 0
        with self._lock:
            for candidate in candidates:
                if self._is_duplicate(candidate):
                    self._skip_duplicate_count += 1
                    continue

                # 按 cargo_type 优先级插入 (已排好序的 candidates 直接 append)
                # 队列插入位置保持顺序
                insert_pos = len(self._queue)
                for i, existing in enumerate(self._queue):
                    if existing.cargo_type > candidate.cargo_type:
                        insert_pos = i
                        break

                self._queue.insert(insert_pos, candidate)
                self._queued_src.add(candidate.src_bay)
                self._queued_dst.add(candidate.dst_bay)
                self._enqueue_count += 1
                added += 1

        if self._logger and added > 0:
            self._logger.info(
                f"任务入队: +{added}, 队列长度={len(self._queue)}, "
                f"跳过重复={self._skip_duplicate_count}"
            )
        return added

    # ════════════════════════════════════════════════════
    #  出队 (AGV 感知)
    # ════════════════════════════════════════════════════

    def try_dequeue(self) -> Optional[TaskCandidate]:
        """尝试出队一个任务 (需 AGV 空闲 + 资源未锁定)

        Returns:
            TaskCandidate: 成功出队 + 资源锁定
            None: 队列空或 AGV 繁忙或资源冲突
        """
        with self._lock:
            if not self._queue:
                return None

            # 检查 AGV 可用性
            robot_id = self._robot_cache.get_idle_robot()
            if robot_id is None:
                self._log_debug("无空闲 AGV, 暂不出队")
                return None

            # 遍历队列找第一个可锁定的任务
            for i, candidate in enumerate(self._queue):
                if self._locker.lock(
                    robot_id, candidate.src_bay, candidate.dst_bay
                ):
                    # 锁定成功, 出队
                    self._queue.pop(i)
                    self._queued_src.discard(candidate.src_bay)
                    self._queued_dst.discard(candidate.dst_bay)
                    self._dequeue_count += 1
                    # 标记仓位在任务中
                    self._bay_cache.mark_in_task(candidate.src_bay, True)

                    if self._logger:
                        self._logger.info(
                            f"任务出队: {candidate.src_bay}→{candidate.dst_bay} "
                            f"type={candidate.cargo_type} robot={robot_id} "
                            f"(剩余队列={len(self._queue)})"
                        )
                    return candidate

            # 队列中有任务但都无法锁定 (资源冲突)
            self._log_debug("队列任务与当前锁定资源冲突, 等待释放")
            return None

    # ════════════════════════════════════════════════════
    #  队列维护
    # ════════════════════════════════════════════════════

    def remove_by_src(self, src_bay: str):
        """移除指定起始仓位的任务 (仓位被其他地方锁定)"""
        with self._lock:
            self._queue = [c for c in self._queue if c.src_bay != src_bay]
            self._queued_src.discard(src_bay)

    def remove_by_dst(self, dst_bay: str):
        """移除指定终点仓位的任务"""
        with self._lock:
            self._queue = [c for c in self._queue if c.dst_bay != dst_bay]
            self._queued_dst.discard(dst_bay)

    def get_queued_sets(self) -> tuple:
        """获取队列中的仓位集合 (供 BatchMatcher 排除用)"""
        with self._lock:
            return (set(self._queued_src), set(self._queued_dst))

    def is_empty(self) -> bool:
        with self._lock:
            return len(self._queue) == 0

    def size(self) -> int:
        with self._lock:
            return len(self._queue)

    def get_stats(self) -> dict:
        with self._lock:
            return {
                'queue_size': len(self._queue),
                'enqueue_count': self._enqueue_count,
                'dequeue_count': self._dequeue_count,
                'skip_duplicate_count': self._skip_duplicate_count,
                'queued_src': list(self._queued_src),
                'queued_dst': list(self._queued_dst),
            }

    # ════════════════════════════════════════════════════
    #  内部
    # ════════════════════════════════════════════════════

    def _is_duplicate(self, candidate: TaskCandidate) -> bool:
        """检查是否重复 (已在队列中)"""
        return (candidate.src_bay in self._queued_src or
                candidate.dst_bay in self._queued_dst)

    def _log_debug(self, msg: str):
        if self._logger:
            self._logger.debug(f"[TaskQueue] {msg}")
```

def batch_scan_all(self, exclude_src: set = None,
                   exclude_dst: set = None) -> ListType[TaskCandidate]:
    """批量扫描所有货物类型, 返回全部候选任务 (已排序)

    Args:
        exclude_src: 已锁定/已入队的起始仓位集合
        exclude_dst: 已锁定/已入队的终点仓位集合

    Returns:
        按优先级排序的 TaskCandidate 列表
    """
    if not self._schedule_checker.is_in_working_window():
        return []

    # 合并排除集合
    locked = self._locker.get_locked_count()
    locked_src = set(self._locker._locked_src_bays) if hasattr(self._locker, '_locked_src_bays') else set()
    locked_dst = set(self._locker._locked_dst_bays) if hasattr(self._locker, '_locked_dst_bays') else set()

    all_exclude_src = locked_src | (exclude_src or set())
    all_exclude_dst = locked_dst | (exclude_dst or set())

    return self._batch_matcher.batch_scan_all(
        max_tasks=self._max_tasks_per_scan,
        exclude_src=all_exclude_src,
        exclude_dst=all_exclude_dst,
    )

def generate_task_id(self, src_bay: str, cargo_type: int) -> str:
    """生成任务 ID (含仓位信息)"""
    import time
    return f"TASK_{src_bay}_{int(time.time())}"

#!/usr/bin/env python3
"""
smart_trigger_plugin — 智能触发器插件 (v3.0) — 批量编排 + 队列调度

升级要点:
  - 批量匹配: batch_scan_all() 一次扫描全部可用仓位对
  - 优先级排序: cargo_type → src_bay → dst_bay → bind_time
  - 任务队列: TaskQueue FIFO + AGV 感知的逐一下发
  - 事件驱动: 任务完成 → 自动 dispatch 下一个
"""

import asyncio
import time as _time_module
from typing import Dict, Any, Optional

from .base_plugin import BasePlugin
from app_mgr_object.components.trigger import (
    TriggerEngine, ScheduleChecker,
)
from app_mgr_object.components.trigger.batch_matcher import TaskCandidate
from app_mgr_object.components.trigger.task_queue import TaskQueue
from app_mgr_object.components.task_cache.config_cache import ConfigCache


class SmartTriggerPlugin(BasePlugin):
    PLUGIN_NAME = "smart_trigger"
    PLUGIN_VERSION = "3.0.0"

    def __init__(self, node, config: Dict[str, Any] = None):
        super().__init__(node, config)
        self._scan_interval = self.config.get('scan_interval', 2.0)
        self._enabled = self.config.get('enabled', True)
        self._max_queue_size = self.config.get('max_queue_size', 50)

        self._trigger_engine: Optional[TriggerEngine] = None
        self._task_queue: Optional[TaskQueue] = None
        self._config_cache: Optional[ConfigCache] = None

        self._running = False
        self._scan_task: Optional[asyncio.Task] = None
        self._scan_count: int = 0
        self._trigger_count: int = 0

    # ════════════════════════════════════════════════════
    #  生命周期
    # ════════════════════════════════════════════════════

    def _configure_impl(self) -> bool:
        self._scan_interval = self.config.get('scan_interval', 2.0)
        self._enabled = self.config.get('enabled', True)
        self._config_cache = ConfigCache(logger=self.logger)
        self.logger.info(f"SmartTrigger v3 配置: scan_interval={self._scan_interval}s")
        return True

    def _activate_impl(self) -> bool:
        if not self._enabled:
            return True

        work_schedule = self.config.get('work_schedule', {})
        schedules = work_schedule.get('schedules', [])

        bay_fusion = self._get_plugin('bay_status_fusion')
        status_poller = self._get_plugin('status_poller')

        if not bay_fusion or not bay_fusion.cache:
            return False
        if not status_poller or not status_poller.dest_cache:
            return False

        self._trigger_engine = TriggerEngine(
            bay_cache=bay_fusion.cache,
            dest_cache=status_poller.dest_cache,
            robot_cache=status_poller.robot_cache,
            config_cache=self._config_cache,
            logger=self.logger,
        )

        if schedules:
            self._trigger_engine._schedule_checker.set_schedules(schedules)

        # === NEW: 创建任务队列 ===
        self._task_queue = TaskQueue(
            resource_locker=self._trigger_engine._locker,
            robot_cache=status_poller.robot_cache,
            bay_cache=bay_fusion.cache,
            logger=self.logger,
        )
        self.logger.info(f"任务队列已创建 (max_size={self._max_queue_size})")
        # ===========================

        loop = asyncio.get_event_loop()
        self._scan_task = loop.create_task(self._scan_loop())

        # 事件订阅
        self.event_bus.subscribe('bay.bound', self._on_bay_bound)
        self.event_bus.subscribe('workflow.task_completed', self._on_task_completed)
        self.event_bus.subscribe('workflow.task_failed', self._on_task_failed)
        self.event_bus.subscribe('workflow.resources_released', self._on_resources_released)

        self._running = True
        self.logger.info(f"SmartTrigger v3 激活完成 (队列模式)")
        return True

    def _deactivate_impl(self) -> bool:
        self._running = False
        if self._scan_task:
            self._scan_task.cancel()
        return True

    def _cleanup_impl(self) -> bool:
        self._trigger_engine = None
        self._task_queue = None
        return True

    # ════════════════════════════════════════════════════
    #  扫描循环 (增强)
    # ════════════════════════════════════════════════════

    async def _scan_loop(self):
        """主扫描循环: 批量匹配 → 入队 → 尝试分发"""
        self.logger.info("扫描循环启动 (v3 批量模式)")

        while self._running:
            try:
                if not self._trigger_engine._schedule_checker.is_in_working_window():
                    await asyncio.sleep(self._scan_interval)
                    continue

                # === 1. 批量匹配 ===
                queued_src, queued_dst = self._task_queue.get_queued_sets()
                candidates = self._trigger_engine.batch_scan_all(
                    exclude_src=queued_src,
                    exclude_dst=queued_dst,
                )

                # === 2. 入队 ===
                if candidates:
                    added = self._task_queue.enqueue_all(candidates)
                    self._scan_count += 1

                # === 3. 尝试分发 ===
                self._dispatch_from_queue()

            except Exception as e:
                self.logger.error(f"扫描循环异常: {e}")

            await asyncio.sleep(self._scan_interval)

    # ════════════════════════════════════════════════════
    #  队列分发 (核心)
    # ════════════════════════════════════════════════════

    def _dispatch_from_queue(self):
        """从队列中尝试出队并下发任务

        出队条件:
          1. 队列非空
          2. 存在空闲 AGV
          3. 资源未锁定
        """
        dispatched = 0
        max_dispatch_per_round = 3  # 每轮最多下发 3 个任务, 避免冲垮引擎

        while dispatched < max_dispatch_per_round:
            candidate = self._task_queue.try_dequeue()
            if candidate is None:
                break  # 队列空 / AGV 繁忙 / 资源冲突

            # 生成 TaskContext 并发布
            task_id = self._trigger_engine.generate_task_id(
                candidate.src_bay, candidate.cargo_type
            )
            ctx = {
                'task_id': task_id,
                'src_bay': candidate.src_bay,
                'dst_bay': candidate.dst_bay,
                'cargo_type': candidate.cargo_type,
                'robot_id': self._get_idle_robot_id(),
            }

            self._trigger_count += 1
            self._publish_event('trigger.task_created', ctx)
            self.logger.info(
                f"队列下发 #{self._trigger_count}: {task_id} "
                f"{candidate.src_bay}→{candidate.dst_bay} "
                f"type={candidate.cargo_type}"
            )
            dispatched += 1

    # ════════════════════════════════════════════════════
    #  事件回调
    # ════════════════════════════════════════════════════

    def _on_bay_bound(self, data: dict):
        """仓位绑定 → 立即扫描 + 分发"""
        bay_id = data.get('bay_id', '')
        self.logger.info(f"绑定事件: {bay_id}, 触发扫描分发")
        loop = self.node.asyncio_loop
        asyncio.run_coroutine_threadsafe(self._scan_and_dispatch_once(), loop)

    def _on_task_completed(self, data: dict):
        """任务完成 → 释放资源 → 下发下一任务"""
        task_id = data.get('task_id', '')
        self.logger.info(f"任务完成: {task_id}, 释放并分发下一任务")
        self._trigger_engine.release_task_resources(data)
        # === NEW: 立即尝试分发 ===
        self._dispatch_from_queue()

    def _on_task_failed(self, data: dict):
        """任务失败 → 释放资源 → 下发下一任务"""
        task_id = data.get('task_id', '')
        self.logger.warning(f"任务失败: {task_id}, 释放并分发下一任务")
        self._trigger_engine.release_task_resources(data)
        self._dispatch_from_queue()

    def _on_resources_released(self, data: dict):
        self._trigger_engine.release_task_resources(data)
        self._dispatch_from_queue()

    async def _scan_and_dispatch_once(self):
        """事件触发的单次扫描+分发"""
        try:
            if not self._trigger_engine._schedule_checker.is_in_working_window():
                return
            queued_src, queued_dst = self._task_queue.get_queued_sets()
            candidates = self._trigger_engine.batch_scan_all(
                exclude_src=queued_src, exclude_dst=queued_dst
            )
            if candidates:
                self._task_queue.enqueue_all(candidates)
                self._scan_count += 1
            self._dispatch_from_queue()
        except Exception as e:
            self.logger.error(f"事件扫描异常: {e}")

    # ════════════════════════════════════════════════════
    #  辅助
    # ════════════════════════════════════════════════════

    def _get_idle_robot_id(self) -> int:
        """获取空闲 AGV 编号"""
        robot_id = self._trigger_engine._robot_cache.get_idle_robot()
        return robot_id or 0

    def _get_plugin(self, name: str):
        plugin = getattr(self.node, name, None)
        if plugin is None:
            plugin = self.node.plugin_manager.get_plugin(name)
        return plugin

    def get_status(self) -> Dict[str, Any]:
        base = super().get_status()
        queue_stats = self._task_queue.get_stats() if self._task_queue else {}
        base.update({
            'enabled': self._enabled,
            'scan_interval': self._scan_interval,
            'running': self._running,
            'scan_count': self._scan_count,
            'trigger_count': self._trigger_count,
            'queue': queue_stats,
            'locked_resources': self._trigger_engine.get_locked_count()
                if self._trigger_engine else {},
        })
        return base
