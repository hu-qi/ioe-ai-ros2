# app_mgr_object-0.1.8 运维控制页服务管理按钮统一 UI 改造指南

> 文档版本：v1.0
> 编写日期：2026-08-10
> 适用工程：`app_mgr_object-0.1.8(标准版)`
> 需求：运维控制页（`/control`）"服务管理"卡片的按钮（重启服务、执行服务操作等）改为与首页统一的前端 UI 风格。

---

## 0. 审查结论

- 改造文件：`app_mgr_object/components/web/templates/control.html`（唯一改动文件）
- 不一致点：服务管理卡片内共 **5 处**按钮使用 Bootstrap 默认黄色 `btn btn-warning w-100`，与首页深色主题的 `btn-accent / btn-outline` 风格不统一：

| 位置 | 按钮 | 现状 |
|---|---|---|
| L231（静态 HTML）| 重启推理服务 | `btn btn-warning w-100` |
| L245（静态 HTML）| 重启RCS管理器 | `btn btn-warning w-100` |
| L291（静态 HTML）| 执行服务操作 | `btn btn-warning w-100` |
| L1420（动态渲染 `renderServiceManagementCard`）| 重启服务 | `btn btn-warning w-100` |
| L1467（动态渲染 `renderServiceManagementCard`）| 执行服务操作 | `btn btn-warning w-100` |

- 统一目标样式（`custom.css` 已具备）：

```css
.btn-accent { background: var(--accent-blue); color: #fff; border: none;
              font-size: 12px; padding: 6px 14px; border-radius: 5px; }
.btn-outline { background: transparent; color: var(--text-secondary);
               border: 1px solid var(--border); font-size: 12px;
               padding: 6px 14px; border-radius: 5px; }
.btn-danger-sm  { font-size: 11px; padding: 4px 10px; }
```

- 卡片头/表单控件已统一（`custom.css` L510~L520 已有 `.card.status-card` 与 `.card-header h5` 归一化、`.form-select/.form-control` 深色主题），本次**仅需改按钮类名**，JS 逻辑（`controlServiceAction / controlService`）不动。

---

## 1. 统一规则

```text
主操作（重启服务 / 执行服务操作）：
  btn-warning w-100  →  btn-accent btn-sm w-100
  （与首页"执行触发/保存配置"一致的主按钮风格）

可选语义加强：
  如产品认为"重启服务"属高风险操作，可用
  btn-danger btn-sm w-100（红色警示），需先在 custom.css 补 .btn-danger 基础样式。
```

---

## 2. 修改步骤

```text
Step 1  打开 app_mgr_object/components/web/templates/control.html
Step 2  静态 HTML 3 处：L231、L245、L291 按钮类名替换
Step 3  动态渲染函数 2 处：renderServiceManagementCard() 内 L1420、L1467 模板字符串替换
Step 4  （可选）form-label → op-label、alert 提示框主题化，见第 4 章
Step 5  刷新 /control 页面（Ctrl+F5）验证
```

### 3.3 动态渲染函数 `renderServiceManagementCard()`（L1420）

```javascript
// 改造前
quickHtml += `
    ...
    <button class="btn btn-warning w-100" onclick="controlServiceAction('${serviceName}', 'restart')">
        <i class="fas fa-redo"></i> 重启服务
    </button>
    ...`;

// 改造后
quickHtml += `
    ...
    <button class="btn btn-accent btn-sm w-100" onclick="controlServiceAction('${serviceName}', 'restart')">
        <i class="fas fa-redo"></i> 重启服务
    </button>
    ...`;
```

### 3.4 动态渲染函数 `renderServiceManagementCard()`（L1467）

```javascript
// 改造前
<button class="btn btn-warning w-100" onclick="controlService()">
    <i class="fas fa-play"></i> 执行服务操作
</button>

// 改造后
<button class="btn btn-accent btn-sm w-100" onclick="controlService()">
    <i class="fas fa-play"></i> 执行服务操作
</button>
```

> 说明：`btn-sm` 与首页按钮尺寸一致（12px 字号）；`w-100` 保持卡片内通栏布局；`onclick` 处理函数与图标均不变。

## 4. 可选一致性优化（建议一并执行）

### 4.1 表单标签 `form-label` → `op-label`（与首页任务操作区一致）

```html
<!-- 改造前 -->
<label class="form-label">服务名称</label>

<!-- 改造后 -->
<label class="op-label">服务名称</label>
```

`renderServiceManagementCard()` 动态模板内的 3 处 `form-label`（服务名称/操作类型/服务参数）同步替换。

### 4.2 提示框 `alert alert-info` 主题化（Bootstrap 默认浅蓝在深色主题下突兀）

在 `custom.css` 追加统一提示框样式：

```css
/* 运维控制页信息提示框（统一深色风格） */
.alert-theme {
    background: var(--bg-tertiary);
    border: 1px solid var(--border);
    border-left: 3px solid var(--accent-blue);
    color: var(--text-primary);
    font-size: 12px;
    border-radius: var(--card-radius);
}
```

`control.html` 中两处（静态 L300、动态 L1480）替换：

```html
<!-- 改造前 -->
<div class="alert alert-info mt-3">...</div>

<!-- 改造后 -->
<div class="alert alert-theme mt-3">...</div>
```
