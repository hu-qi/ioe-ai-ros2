## 1. 概述：Phase 2 在整体架构中的位置

```
业务需求                               架构分层                  实现方式
────────────────────────────────────   ──────────────           ──────────────────────
AI 检测仓位有货 + 防抖确认             → 数据融合层             bay_status_fusion_plugin
                                                                  └─ 复用 AreaStatusFilter
                                                                  └─ 解析层级 BayStatus 消息

绑定操作 (bindCtnrAndBin)              → 数据融合层             bay_status_fusion_plugin
                                                                  └─ 调用 rcs_adapter

RCS 叉车状态 / 终点仓位状态实时获取     → 实时同步层             status_poller_plugin
                                                                  └─ 调用 rcs_adapter.query_*

RCS 回调接收 (agvCallback 等)           → 实时同步层             callback_handler_plugin
                                                                  └─ 复用 CallbackReceiver
                                                                  └─ 发布 rcs.* 事件到 EventBus
```

Phase 2 承担从"AI 原始信号"到"稳定业务事件"的数据融合任务：

- **自定义消息层**: 定义 `BayStatus` → `BayChannelStatus` → `BayArea` 三层嵌套消息
- **bay_status_fusion_plugin**: 订阅 `/ai_bay_status` 话题（`BayStatus` 类型），遍历通道和仓位 → 防抖滤波 → 触发 RCS 绑定 → 维护起始仓位缓存
- **status_poller_plugin**: 定时轮询 RCS → 获取叉车/终点仓位状态 → 维护内存缓存 → 补偿回调丢失
- **callback_handler_plugin 扩展**: 注册 `agvCallback` / `warnCallback` / `bindNotify` 三个 RCS 回调路由 → 接收 RCS 通知 → 发布 EventBus 事件

两个数据融合插件共享 `components/task_cache/` 缓存组件包作为数据存储层。

## 3. ROS2 自定义消息定义

**路径**: `app_mgr_object/custom_msgs/`

AI 检测结果采用三层嵌套消息结构：设备（BayStatus）→ 通道（BayChannelStatus）→ 仓位（BayArea）。这与实际 AI 推理节点的输出结构一致——一个设备有多个通道，每个通道覆盖若干仓位。

### 3.1 BayArea.msg — 仓位级状态

**路径**: `app_mgr_object/custom_msgs/BayArea.msg`

```
# BayArea.msg — 单个仓位的 AI 检测结果

string bay_id            # 仓位编号，如 "A1001"、"B1003"
bool has_cargo           # 是否有货物 (true: 有货, false: 无货)
int32 cargo_type         # 货物类型 (1~6, 0 表示未知)
float64 timestamp        # 该仓位检测时间戳 (秒, 可用 time.time())
```

### 3.2 BayChannelStatus.msg — 通道级状态

**路径**: `app_mgr_object/custom_msgs/BayChannelStatus.msg`

```
# BayChannelStatus.msg — 单个通道下所有仓位的状态列表

int32 channel_id                      # 通道编号 (0, 1, 2, ...)
bool signal_status                    # 通道信号状态 (true: 有信号, false: 无信号)
BayArea[] areas                       # 该通道下的仓位列表
```

### 3.3 BayStatus.msg — 顶层消息

**路径**: `app_mgr_object/custom_msgs/BayStatus.msg`

```
# BayStatus.msg — 顶层 AI 检测消息（携带设备级别信息）

std_msgs/Header header                # ROS2 标准头部（时间戳、frame_id）
string device_id                      # 设备 ID，如 "dev01"
BayChannelStatus[] channels           # 该设备下所有通道的状态
```

### 3.4 消息层级关系与订阅方式

```
BayStatus.msg (顶层)
├── Header header
├── string device_id
└── BayChannelStatus[] channels
    ├── [0] BayChannelStatus
    │   ├── int32 channel_id
    │   ├── bool signal_status
    │   └── BayArea[] areas
    │       ├── [0] BayArea { bay_id="A1001", has_cargo=True,  cargo_type=1, ... }
    │       ├── [1] BayArea { bay_id="A1002", has_cargo=False, cargo_type=1, ... }
    │       └── ...
    ├── [1] BayChannelStatus
    │   └── ...
    └── [2] BayChannelStatus
        └── ...
```

**bay_status_fusion_plugin 中的订阅方式**:

```python
# 订阅顶层 BayStatus 消息
from app_mgr_object.custom_msgs import BayStatus

self._subscription = self.node.create_subscription(
    BayStatus,                              # 消息类型
    '/ai_bay_status',                        # 话题名称
    self._on_bay_status,                     # 回调函数
    10                                       # 队列深度
)
```

**回调处理流程**: 收到 `BayStatus` 消息后 → 遍历 `msg.channels` → 遍历每个 `channel.areas` → 对每个 `BayArea` 执行防抖滤波 → 判断是否触发绑定。

> **编译自定义消息**: 在 `package.xml` 中添加 `<depend>std_msgs</depend>`，在 `CMakeLists.txt` 中添加 `rosidl_generate_interfaces()`。详见 ROS2 自定义消息编译文档。

## 4. 组件 B：task_cache 状态缓存组件包

**路径**: `app_mgr_object/components/task_cache/`

**设计要点**:
- 内存缓存为主（高频读写，微秒级延迟）
- 所有写操作加 `threading.RLock()` 保证线程安全
- 提供类型筛选、状态筛选等查询接口
- 支持 `reload_config()` 热加载（Web 配置更新后调用）

### 4.1 `bay_cache.py` — 起始仓位状态缓存

**职责**: 维护 24 个起始仓位（A1001~D1006）的实时状态

**数据模型（内存）**:

```
{
    "A1001": {
        "bay_id":       "A1001",
        "cargo_type":   1,             # 1~6 货物类型
        "ai_detected":  True,          # AI 当前检测结果（原始值）
        "bind_status":  1,             # 0=未绑定, 1=已绑定, 2=绑定中
        "debounce_count": 3,           # 防抖计数器
        "in_task":      False,         # 是否已被分配任务
        "last_seen":    1723456789.0,  # AI 最后一次检测时间戳
        "bind_time":    1723456790.0,  # 绑定成功时间戳
    },
    ...
}
```

**接口清单**:

| 方法 | 调用方 | 说明 |
|:---|:---|:---|
| `update_ai_result(bay_id, has_cargo, cargo_type)` | `bay_status_fusion` | 更新 AI 检测原始结果 |
| `set_bound(bay_id)` | `bay_status_fusion` | 标记仓位已绑定 |
| `set_binding(bay_id)` | `bay_status_fusion` | 标记仓位绑定中 |
| `set_unbound(bay_id)` | `bay_status_fusion` / `rcs_callback_receiver` | 标记仓位未绑定 |
| `mark_in_task(bay_id, value=True)` | `smart_trigger` / `workflow_engine` | 标记仓位被任务占用/释放 |
| `get_bound_bays_of_type(cargo_type)` | `smart_trigger` | 获取指定类型已绑定的仓位 |
| `get_any_bound_bay(cargo_type)` | `smart_trigger` | 获取任一可用仓位 |
| `get_bay_status(bay_id)` | Web / 其他 | 单个仓位完整状态 |
| `get_all_bay_status()` | Web | 所有仓位状态快照 |
| `reload_config(bay_configs)` | Web | 热加载仓位配置 |

**代码**（已在 `app_mgr_object-0.0.2(基础版)` 中完成）:

```python
#!/usr/bin/env python3
"""
起始仓位状态缓存 — 维护 24 个起始仓位（A1001~D1006）的实时状态
"""

import time
import threading
from typing import Dict, List, Optional


class BayCacheEntry:
    """单个仓位状态条目"""
    __slots__ = ('bay_id', 'cargo_type', 'ai_detected', 'bind_status',
                 'debounce_count', 'in_task', 'last_seen', 'bind_time')

    def __init__(self, bay_id: str, cargo_type: int):
        self.bay_id = bay_id
        self.cargo_type = cargo_type
        self.ai_detected = False
        self.bind_status = 0
        self.debounce_count = 0
        self.in_task = False
        self.last_seen = 0.0
        self.bind_time = 0.0

    def to_dict(self) -> dict:
        return {
            'bay_id': self.bay_id,
            'cargo_type': self.cargo_type,
            'ai_detected': self.ai_detected,
            'bind_status': self.bind_status,
            'debounce_count': self.debounce_count,
            'in_task': self.in_task,
            'last_seen': self.last_seen,
            'bind_time': self.bind_time,
        }


class BayCache:
    """起始仓位状态缓存"""

    def __init__(self, bay_configs: Dict[str, int] = None, logger=None):
        self._lock = threading.RLock()
        self._logger = logger
        self._bays: Dict[str, BayCacheEntry] = {}
        if bay_configs:
            for bay_id, cargo_type in bay_configs.items():
                self._bays[bay_id] = BayCacheEntry(bay_id, cargo_type)

    def update_ai_result(self, bay_id: str, has_cargo: bool, cargo_type: int = None):
        with self._lock:
            entry = self._ensure_entry(bay_id, cargo_type)
            entry.ai_detected = has_cargo
            entry.last_seen = time.time()

    def increment_debounce(self, bay_id: str):
        with self._lock:
            entry = self._ensure_entry(bay_id, None)
            entry.debounce_count += 1

    def reset_debounce(self, bay_id: str):
        with self._lock:
            entry = self._ensure_entry(bay_id, None)
            entry.debounce_count = 0

    def set_bound(self, bay_id: str):
        with self._lock:
            entry = self._ensure_entry(bay_id, None)
            entry.bind_status = 1
            entry.bind_time = time.time()

    def set_binding(self, bay_id: str):
        with self._lock:
            entry = self._ensure_entry(bay_id, None)
            entry.bind_status = 2

    def set_unbound(self, bay_id: str):
        with self._lock:
            entry = self._ensure_entry(bay_id, None)
            entry.bind_status = 0
            entry.bind_time = 0.0

    def mark_in_task(self, bay_id: str, value: bool = True):
        with self._lock:
            entry = self._ensure_entry(bay_id, None)
            entry.in_task = value

    def update_cargo_type(self, bay_id: str, cargo_type: int):
        with self._lock:
            if bay_id in self._bays:
                self._bays[bay_id].cargo_type = cargo_type

    def get_bound_bays_of_type(self, cargo_type: int, exclude_in_task: bool = True) -> List[str]:
        with self._lock:
            result = []
            for entry in self._bays.values():
                if entry.cargo_type != cargo_type:
                    continue
                if entry.bind_status != 1:
                    continue
                if exclude_in_task and entry.in_task:
                    continue
                result.append(entry.bay_id)
            return result

    def get_any_bound_bay(self, cargo_type: int) -> Optional[str]:
        bays = self.get_bound_bays_of_type(cargo_type, exclude_in_task=True)
        return bays[0] if bays else None

    def get_bay_status(self, bay_id: str) -> Optional[dict]:
        with self._lock:
            entry = self._bays.get(bay_id)
            return entry.to_dict() if entry else None

    def get_all_bay_status(self) -> Dict[str, dict]:
        with self._lock:
            return {bay_id: entry.to_dict() for bay_id, entry in self._bays.items()}

    def get_bay_count(self) -> int:
        return len(self._bays)

    def get_bound_count(self) -> int:
        with self._lock:
            return sum(1 for e in self._bays.values() if e.bind_status == 1)

    def has_bound_bay_of_type(self, cargo_type: int) -> bool:
        return len(self.get_bound_bays_of_type(cargo_type)) > 0

    def _ensure_entry(self, bay_id: str, cargo_type: Optional[int]) -> BayCacheEntry:
        if bay_id not in self._bays:
            ct = cargo_type if cargo_type is not None else 0
            self._bays[bay_id] = BayCacheEntry(bay_id, ct)
            if self._logger:
                self._logger.debug(f"新仓位注册: {bay_id} type={ct}")
        elif cargo_type is not None and cargo_type > 0:
            current = self._bays[bay_id]
            if current.cargo_type == 0:
                current.cargo_type = cargo_type
        return self._bays[bay_id]

    def reload_config(self, bay_configs: Dict[str, int]):
        with self._lock:
            for bay_id, cargo_type in bay_configs.items():
                if bay_id in self._bays:
                    self._bays[bay_id].cargo_type = cargo_type
                else:
                    self._bays[bay_id] = BayCacheEntry(bay_id, cargo_type)
```

**代码**（已在 `app_mgr_object-0.0.2(基础版)` 中完成）:

```python
#!/usr/bin/env python3
"""终点仓位状态缓存 — 维护终点仓位（T2001~T4006）的实时状态"""

import time
import threading
from typing import Dict, List, Optional


class DestBayCacheEntry:
    __slots__ = ('bay_id', 'cargo_type', 'floor_no', 'is_empty', 'update_time', 'source')

    def __init__(self, bay_id: str, cargo_type: int, floor_no: int = 0):
        self.bay_id = bay_id
        self.cargo_type = cargo_type
        self.floor_no = floor_no
        self.is_empty = True
        self.update_time = 0.0
        self.source = 'init'

    def to_dict(self) -> dict:
        return {
            'bay_id': self.bay_id, 'cargo_type': self.cargo_type,
            'floor_no': self.floor_no, 'is_empty': self.is_empty,
            'update_time': self.update_time, 'source': self.source,
        }


class DestBayCache:
    def __init__(self, bay_configs: Dict[str, dict] = None, logger=None):
        self._lock = threading.RLock()
        self._logger = logger
        self._bays: Dict[str, DestBayCacheEntry] = {}
        if bay_configs:
            for bay_id, cfg in bay_configs.items():
                self._bays[bay_id] = DestBayCacheEntry(
                    bay_id, cfg.get('cargo_type', 0), cfg.get('floor', 0))

    def update(self, bay_id: str, is_empty: bool, source: str = 'polling'):
        with self._lock:
            entry = self._bays.get(bay_id)
            if entry:
                entry.is_empty = is_empty
                entry.update_time = time.time()
                entry.source = source

    def get_empty_bays_of_type(self, cargo_type: int) -> List[str]:
        with self._lock:
            return [e.bay_id for e in self._bays.values()
                    if e.cargo_type == cargo_type and e.is_empty]

    def get_any_empty_bay(self, cargo_type: int) -> Optional[str]:
        bays = self.get_empty_bays_of_type(cargo_type)
        return bays[0] if bays else None

    def get_bay_status(self, bay_id: str) -> Optional[dict]:
        with self._lock:
            entry = self._bays.get(bay_id)
            return entry.to_dict() if entry else None

    def get_all_bay_status(self) -> Dict[str, dict]:
        with self._lock:
            return {e.bay_id: e.to_dict() for e in self._bays.values()}

    def get_all_bay_ids(self) -> List[str]:
        return list(self._bays.keys())

    def has_empty_bay_of_type(self, cargo_type: int) -> bool:
        return len(self.get_empty_bays_of_type(cargo_type)) > 0

    def reload_config(self, bay_configs: Dict[str, dict]):
        with self._lock:
            for bay_id, cfg in bay_configs.items():
                if bay_id in self._bays:
                    self._bays[bay_id].cargo_type = cfg.get('cargo_type', 0)
                    self._bays[bay_id].floor_no = cfg.get('floor', 0)
                else:
                    self._bays[bay_id] = DestBayCacheEntry(
                        bay_id, cfg.get('cargo_type', 0), cfg.get('floor', 0))
```

#!/usr/bin/env python3
"""叉车状态缓存 — 维护 AGV 叉车（1001, 1002）的实时状态"""

import time
import threading
from typing import Dict, List, Optional


class RobotCacheEntry:
    __slots__ = ('robot_id', 'status', 'current_task_id', 'battery', 'position_code', 'update_time')

    def __init__(self, robot_id: int):
        self.robot_id = robot_id
        self.status = 'OFFLINE'
        self.current_task_id = ''
        self.battery = 0
        self.position_code = ''
        self.update_time = 0.0

    def to_dict(self) -> dict:
        return {
            'robot_id': self.robot_id, 'status': self.status,
            'current_task_id': self.current_task_id, 'battery': self.battery,
            'position_code': self.position_code, 'update_time': self.update_time,
        }


class RobotCache:
    def __init__(self, robot_ids: List[int] = None, logger=None):
        self._lock = threading.RLock()
        self._logger = logger
        self._robots: Dict[int, RobotCacheEntry] = {}
        if robot_ids:
            for rid in robot_ids:
                self._robots[rid] = RobotCacheEntry(rid)

    def update_status(self, robot_id: int, status: str,
                      battery: int = None, position_code: str = None):
        with self._lock:
            entry = self._robots.get(robot_id)
            if not entry:
                return
            entry.status = status
            entry.update_time = time.time()
            if battery is not None:
                entry.battery = battery
            if position_code is not None:
                entry.position_code = position_code

    def set_busy(self, robot_id: int, task_id: str = ''):
        with self._lock:
            entry = self._robots.get(robot_id)
            if entry:
                entry.status = 'BUSY'
                entry.current_task_id = task_id
                entry.update_time = time.time()

    def set_idle(self, robot_id: int):
        with self._lock:
            entry = self._robots.get(robot_id)
            if entry:
                entry.status = 'IDLE'
                entry.current_task_id = ''
                entry.update_time = time.time()

    def get_idle_robot(self) -> Optional[int]:
        with self._lock:
            for entry in self._robots.values():
                if entry.status == 'IDLE':
                    return entry.robot_id
            return None

    def get_robot_status(self, robot_id: int) -> Optional[dict]:
        with self._lock:
            entry = self._robots.get(robot_id)
            return entry.to_dict() if entry else None

    def get_all_robot_status(self) -> Dict[int, dict]:
        with self._lock:
            return {rid: e.to_dict() for rid, e in self._robots.items()}

    def has_idle_robot(self) -> bool:
        return self.get_idle_robot() is not None

    def get_robot_count(self) -> int:

## 5. 插件 4.3：bay_status_fusion_plugin — 数据融合插件

### 5.1 设计规格

| 属性 | 值 |
|:---|:---|
| **PLUGIN_NAME** | `bay_status_fusion` |
| **文件路径** | `app_mgr_object/plugins/bay_status_fusion_plugin.py` |
| **依赖** | `rcs_adapter`（Phase 1 产出） |
| **职责** | 订阅 AI `/bay_status` 话题（`BayStatus` 类型）→ 遍历通道和仓位的层级消息 → 防抖滤波 → 触发 RCS 绑定 → 维护起始仓位缓存 |
| **使用的组件** | `AreaStatusFilter`（已有，复用）<br>`BayCache`（task_cache 组件包） |
| **订阅话题** | `/ai_bay_status`（自定义消息 `BayStatus` → `BayChannelStatus[]` → `BayArea[]`） |
| **发布事件** | `bay.status_changed`：仓位状态变化<br>`bay.bound`：仓位绑定成功 |

### 5.2 核心流程（层级消息解析）

```
收到 BayStatus 消息:
│
├─ 提取 device_id (如 "dev01")
├─ 遍历 msg.channels:
│   ├─ for channel in msg.channels:
│   │   ├─ channel_id = channel.channel_id
│   │   ├─ signal_status = channel.signal_status
│   │   │
│   │   └─ 遍历 channel.areas:
│   │       for area in channel.areas:
│   │       │
│   │       ├─ bay_id = area.bay_id        # 如 "A1001"
│   │       ├─ has_cargo = area.has_cargo   # AI 检测原始值
│   │       ├─ cargo_type = area.cargo_type # 货物类型
│   │       │
│   │       ├─ 获取/创建该仓位的 AreaStatusFilter 实例
│   │       │  filter = AreaStatusFilter(stable_threshold=3, timeout=2.0)
│   │       │
│   │       ├─ result = filter.update(has_cargo)
│   │       │
│   │       ├─ if result['changed'] and result['current_state'] == True:
│   │       │  │  → 稳定有货确认
│   │       │  │  → bay_cache.set_binding(bay_id)
│   │       │  │  → 调用 rcs_adapter.bind_ctnr_and_bin(bay_id, cargo_type)
│   │       │  │  → 成功后 bay_cache.set_bound(bay_id)
│   │       │  │  → 发布 event_bus.publish('bay.bound', {...})
│   │       │  │
│   │       │  ├─ if result['changed'] and result['current_state'] == False:
│   │       │  │  → 稳定无货（不主动解绑）
│   │       │  │  → 发布 bay.status_changed
│   │       │  │
│   │       │  └─ 同时更新 bay_cache.update_ai_result(bay_id, has_cargo, cargo_type)
```

**关键设计决策**:

1. **层级遍历**: 收到一条 `BayStatus` 消息可包含多个通道、多个仓位，一次回调完成全部处理
2. **防抖参数**: `stable_threshold=3, timeout=2.0` — 连续 3 帧有货 + 2 秒内无超时
3. **不主动解绑**: AI 检测到无货时仅更新缓存状态，不解绑 — 解绑由 RCS 回调 `bindNotify(indBind="0")` 或任务完成后处理
4. **AreaStatusFilter 按仓位实例化**: 每个 `bay_id` 维护独立的 `AreaStatusFilter` 实例

### 5.3 完整代码

**路径**: `app_mgr_object/plugins/bay_status_fusion_plugin.py`

```python
#!/usr/bin/env python3
"""
bay_status_fusion_plugin — 数据融合插件

职责：
  - 订阅 AI 检测 `/ai_bay_status` 话题（BayStatus 消息）
  - 遍历 BayStatus → BayChannelStatus[] → BayArea[] 层级结构
  - 使用 AreaStatusFilter 对每个仓位做防抖滤波
  - 稳定有货时触发 RCS 绑定 (bindCtnrAndBin)
  - 维护 BayCache 起始仓位状态
  - 通过 EventBus 发布 bay.status_changed / bay.bound 事件

依赖：
  - rcs_adapter (Phase 1)
  - AreaStatusFilter (复用已有组件)
  - BayCache (task_cache 组件包)
  - BayStatus / BayChannelStatus / BayArea (ROS2 自定义消息)
"""

from typing import Dict, Any, Optional
import threading

from .base_plugin import BasePlugin
from app_mgr_object.components.device_status.area_filter import AreaStatusFilter
from app_mgr_object.components.task_cache.bay_cache import BayCache

# ROS2 自定义消息类型（编译后自动生成）
# 若消息未编译，可先用 dict 模拟，部署时替换为正式 import
try:
    from app_mgr_object.custom_msgs.msg import BayStatus
    from app_mgr_object.custom_msgs.msg import BayChannelStatus
    from app_mgr_object.custom_msgs.msg import BayArea
    MSG_AVAILABLE = True
except ImportError:
    BayStatus = None
    BayChannelStatus = None
    BayArea = None
    MSG_AVAILABLE = False


class BayStatusFusionPlugin(BasePlugin):
    """数据融合插件 — AI 层级信号 → 稳定业务事件 → RCS 绑定"""

    PLUGIN_NAME = "bay_status_fusion"
    PLUGIN_VERSION = "1.0.0"

    def __init__(self, node, config: Dict[str, Any] = None):
        super().__init__(node, config)

        # 解析配置
        self._stable_threshold = self.config.get('stable_threshold', 3)
        self._filter_timeout = self.config.get('filter_timeout', 2.0)
        self._bind_enabled = self.config.get('bind_enabled', True)
        self._ai_topic = self.config.get('ai_topic', '/ai_bay_status')

        # 综合缓存
        self.cache: BayCache = None

        # 每个仓位独立的 AreaStatusFilter
        self._filters: Dict[str, AreaStatusFilter] = {}
        self._filters_lock = threading.Lock()

        # ROS2 订阅器
        self._subscription = None

    # ════════════════════════════════════════════════════
    #  生命周期
    # ════════════════════════════════════════════════════

    def _configure_impl(self) -> bool:
        bay_configs = self.config.get('bay_configs', None)
        self.cache = BayCache(bay_configs=bay_configs, logger=self.logger)
        self.logger.info(
            f"BayStatusFusion 配置完成: stable_threshold={self._stable_threshold}, "
            f"filter_timeout={self._filter_timeout}, bind_enabled={self._bind_enabled}, "
            f"topic={self._ai_topic}"
        )
        return True

    def _activate_impl(self) -> bool:
        """激活：订阅 AI 检测话题"""
        if not MSG_AVAILABLE:
            self.logger.warning(
                "BayStatus 自定义消息未编译，将使用通用订阅模式。"
                "请确保已执行 colcon build 编译 custom_msgs。"
            )
            # 降级：使用通用消息类型订阅
            from std_msgs.msg import String
            self._subscription = self.node.create_subscription(
                String,
                self._ai_topic,
                self._on_bay_status_fallback,
                10
            )
        else:
            self._subscription = self.node.create_subscription(
                BayStatus,
                self._ai_topic,
                self._on_bay_status,
                10
            )
        self.logger.info(f"BayStatusFusion 激活完成，订阅话题: {self._ai_topic}")
        return True

    def _deactivate_impl(self) -> bool:
        if self._subscription:
            self.node.destroy_subscription(self._subscription)
            self._subscription = None
        self._filters.clear()
        return True

    def _cleanup_impl(self) -> bool:
        self.cache = None
        self._filters.clear()
        return True

    # ════════════════════════════════════════════════════
    #  核心回调 — 正式消息（BayStatus）
    # ════════════════════════════════════════════════════

    def _on_bay_status(self, msg):
        """
        处理 BayStatus 层级消息

        BayStatus 结构:
            header:   std_msgs/Header
            device_id: string               # 如 "dev01"
            channels: BayChannelStatus[]    # 通道列表

        BayChannelStatus 结构:
            channel_id: int32              # 通道编号
            signal_status: bool            # 通道信号状态
            areas: BayArea[]               # 仓位列表

        BayArea 结构:
            bay_id: string                # 仓位编号，如 "A1001"
            has_cargo: bool               # 是否有货物
            cargo_type: int32             # 货物类型 (1~6)
            timestamp: float64            # 检测时间戳
        """
        device_id = msg.device_id
        self.logger.debug(f"收到 AI 检测消息: device={device_id}, "
                          f"channels={len(msg.channels)}")

        # 遍历通道
        for channel in msg.channels:
            channel_id = channel.channel_id
            signal_ok = channel.signal_status

            if not signal_ok:
                self.logger.debug(
                    f"通道 {channel_id} 无信号，跳过 {len(channel.areas)} 个仓位"
                )
                continue

            # 遍历该通道下的所有仓位
            for area in channel.areas:
                bay_id = area.bay_id
                has_cargo = area.has_cargo
                cargo_type = area.cargo_type

                self._process_single_bay(bay_id, has_cargo, cargo_type)

    def _on_bay_status_fallback(self, msg):
        """
        降级回调 — 当 BayStatus 消息未编译时使用
        预期 msg.data 为 JSON 格式的 dict
        """
        import json
        try:
            data = json.loads(msg.data)
            device_id = data.get('device_id', 'unknown')
            channels = data.get('channels', [])

            self.logger.debug(f"收到 AI 检测消息 (fallback): device={device_id}")

            for channel in channels:
                if not channel.get('signal_status', False):
                    continue
                for area in channel.get('areas', []):
                    bay_id = area.get('bay_id')
                    has_cargo = area.get('has_cargo', False)
                    cargo_type = area.get('cargo_type', 0)
                    if bay_id:
                        self._process_single_bay(bay_id, has_cargo, cargo_type)

        except Exception as e:
            self.logger.error(f"解析 AI 消息失败 (fallback): {e}")

    # ════════════════════════════════════════════════════
    #  单仓位处理逻辑
    # ════════════════════════════════════════════════════

    def _process_single_bay(self, bay_id: str, has_cargo: bool, cargo_type: int):
        """对单个仓位执行防抖滤波 → 判断绑定"""

        # 1. 获取或创建该仓位的滤波器
        flt = self._get_filter(bay_id)

        # 2. 更新滤波状态
        result = flt.update(has_cargo)

        # 3. 同步更新缓存中的 AI 原始结果
        self.cache.update_ai_result(bay_id, has_cargo, cargo_type)

        # 4. 处理状态变化
        if result.get('changed'):
            if result.get('current_state') is True:
                self._on_stable_cargo(bay_id, cargo_type, result)
            else:
                self._on_stable_empty(bay_id, result)

    def _on_stable_cargo(self, bay_id: str, cargo_type: int, result: dict):
        """稳定有货 → 触发 RCS 绑定"""
        self.logger.info(
            f"仓位 {bay_id} 稳定有货 (cargo_type={cargo_type}), 触发绑定"
        )

        status = self.cache.get_bay_status(bay_id)
        if status and status.get('bind_status') == 1:
            self.logger.debug(f"仓位 {bay_id} 已绑定，跳过")
            return

        self._publish_event('bay.status_changed', {
            'bay_id': bay_id,
            'has_cargo': True,
            'cargo_type': cargo_type,
            'action': 'stable_cargo_detected',
            'filter_info': result,
        })

        if not self._bind_enabled:
            self.logger.debug(f"绑定已禁用，跳过仓位 {bay_id}")
            return

        self.cache.set_binding(bay_id)

        try:
            rcs_adapter = self._get_rcs_adapter()
            ctnr_code = f"CTNR_{bay_id}"
            resp = rcs_adapter.bind_ctnr_and_bin(
                ctnr_code=ctnr_code,
                ctnr_typ=str(cargo_type),
                stg_bin_code=bay_id,
                ind_bind="1"
            )

            if resp.get('code') == '0':
                self.cache.set_bound(bay_id)
                self._publish_event('bay.bound', {
                    'bay_id': bay_id,
                    'cargo_type': cargo_type,
                    'ctnr_code': ctnr_code,
                    'rcs_response': resp,
                })
                self.logger.info(f"仓位 {bay_id} 绑定成功: {ctnr_code}")
            else:
                self.cache.set_unbound(bay_id)
                self.logger.error(
                    f"仓位 {bay_id} 绑定失败: {resp.get('msg', '未知错误')}"
                )
        except Exception as e:
            self.cache.set_unbound(bay_id)
            self.logger.error(f"仓位 {bay_id} 绑定异常: {e}")

    def _on_stable_empty(self, bay_id: str, result: dict):
        """稳定无货 → 仅更新缓存，发布事件"""
        self.logger.debug(f"仓位 {bay_id} 稳定无货")
        self._publish_event('bay.status_changed', {
            'bay_id': bay_id,
            'has_cargo': False,
            'action': 'stable_empty_detected',
            'filter_info': result,
        })

    # ════════════════════════════════════════════════════
    #  辅助方法
    # ════════════════════════════════════════════════════

    def _get_filter(self, bay_id: str) -> AreaStatusFilter:
        with self._filters_lock:
            if bay_id not in self._filters:
                self._filters[bay_id] = AreaStatusFilter(
                    stable_threshold=self._stable_threshold,
                    timeout=self._filter_timeout,
                    logger=self.logger
                )
                self.logger.debug(f"创建仓位 {bay_id} 的滤波器")
            return self._filters[bay_id]

    def _get_rcs_adapter(self):
        adapter = getattr(self.node, 'rcs_adapter', None)
        if adapter is None:
            adapter = self.node.plugin_manager.get_plugin('rcs_adapter')
        if adapter is None:
            raise RuntimeError("RCS 适配器未加载")
        return adapter

    # ════════════════════════════════════════════════════
    #  状态查询（Web / 运维用）
    # ════════════════════════════════════════════════════

    def get_status(self) -> Dict[str, Any]:
        base = super().get_status()
        base.update({
            'filter_count': len(self._filters),
            'bay_count': self.cache.get_bay_count() if self.cache else 0,
            'bound_count': self.cache.get_bound_count() if self.cache else 0,
            'bind_enabled': self._bind_enabled,
        })
        return base

    def get_all_bay_status(self) -> Dict[str, dict]:
        if self.cache:
            return self.cache.get_all_bay_status()
        return {}

    def get_filter_info(self, bay_id: str) -> Optional[dict]:
        flt = self._filters.get(bay_id)
        return flt.get_status_info() if flt else None
```

## 6. 插件 4.4：status_poller_plugin — 状态轮询同步插件

### 6.1 设计规格

| 属性 | 值 |
|:---|:---|
| **PLUGIN_NAME** | `status_poller` |
| **文件路径** | `app_mgr_object/plugins/status_poller_plugin.py` |
| **依赖** | `rcs_adapter`（Phase 1 产出） |
| **职责** | 定时轮询 RCS 获取叉车状态、终点仓位状态，维护内存缓存，补偿回调丢失 |
| **使用的组件** | `RobotCache`（task_cache 组件包）<br>`DestBayCache`（task_cache 组件包） |
| **定时器** | 叉车状态: 3s / 终点仓位: 60s / 任务状态: 5s（可配） |

### 6.2 核心流程

```
_activate_impl():
│
├─ 创建 RobotCache 实例（robot_ids=[1001, 1002]）
├─ 创建 DestBayCache 实例（bay_configs 来自配置）
│
├─ 创建 ROS2 Timer: 每 3s 调用 _poll_robot_status()
│  └─ 调用 rcs_adapter.query_agv_status([1001, 1002])
│     └─ 解析响应，批量更新 robot_cache.update_status()
│
├─ 创建 ROS2 Timer: 每 60s 调用 _poll_dest_bays()
│  └─ 获取 dest_cache.get_all_bay_ids()
│     └─ 调用 rcs_adapter.query_pod_berth_and_mat(bay_ids)
│        └─ 解析响应，批量更新 dest_cache.update()
│
└─ 启动时立即执行一次全量轮询
   └─ _initial_full_poll()
```

### 6.3 完整代码

**路径**: `app_mgr_object/plugins/status_poller_plugin.py`

```python
#!/usr/bin/env python3
"""
status_poller_plugin — 状态轮询同步插件

职责：
  - 定时轮询 RCS 获取叉车实时状态（3s 间隔）
  - 定时轮询 RCS 获取终点仓位状态（60s 间隔）
  - 维护 RobotCache 和 DestBayCache 内存缓存
  - 启动时执行一次全量加载
  - 补偿回调丢失

依赖：
  - rcs_adapter (Phase 1)
  - RobotCache, DestBayCache (task_cache 组件包)
"""

from typing import Dict, Any, List, Optional

from .base_plugin import BasePlugin
from app_mgr_object.components.task_cache.robot_cache import RobotCache
from app_mgr_object.components.task_cache.dest_bay_cache import DestBayCache


class StatusPollerPlugin(BasePlugin):
    """状态轮询同步插件"""

    PLUGIN_NAME = "status_poller"
    PLUGIN_VERSION = "1.0.0"

    def __init__(self, node, config: Dict[str, Any] = None):
        super().__init__(node, config)
        self._robot_ids: List[int] = self.config.get('robot_ids', [1001, 1002])
        self._robot_poll_interval: float = self.config.get('robot_poll_interval', 3.0)
        self._dest_poll_interval: float = self.config.get('dest_poll_interval', 60.0)
        self._enabled = self.config.get('enabled', True)

        self.robot_cache: RobotCache = None
        self.dest_cache: DestBayCache = None

        self._robot_timer = None
        self._dest_timer = None
        self._initial_poll_done = False
        self._last_robot_poll: float = 0.0
        self._last_dest_poll: float = 0.0
        self._robot_poll_errors: int = 0
        self._dest_poll_errors: int = 0

    def _configure_impl(self) -> bool:
        self.robot_cache = RobotCache(robot_ids=self._robot_ids, logger=self.logger)
        dest_configs = self.config.get('dest_bay_configs', None)
        self.dest_cache = DestBayCache(bay_configs=dest_configs, logger=self.logger)
        self.logger.info(
            f"StatusPoller 配置完成: robots={self._robot_ids}, "
            f"robot_interval={self._robot_poll_interval}s, "
            f"dest_interval={self._dest_poll_interval}s"
        )
        return True

    def _activate_impl(self) -> bool:
        if not self._enabled:
            self.logger.info("StatusPoller 已禁用")
            return True
        self._robot_timer = self.node.create_timer(self._robot_poll_interval, self._poll_robot_status)
        self._dest_timer = self.node.create_timer(self._dest_poll_interval, self._poll_dest_bays)
        self.node.create_timer(0.5, self._initial_full_poll, oneshot=True)
        self.logger.info(f"StatusPoller 激活完成")
        return True

    def _deactivate_impl(self) -> bool:
        for timer in [self._robot_timer, self._dest_timer]:
            if timer:
                self.node.destroy_timer(timer)
        self._robot_timer = None
        self._dest_timer = None
        return True

    def _cleanup_impl(self) -> bool:
        self.robot_cache = None
        self.dest_cache = None
        return True

    def _initial_full_poll(self):
        self.logger.info("执行初始全量加载...")
        self._poll_robot_status()
        self._poll_dest_bays()
        self._initial_poll_done = True
        self.logger.info("初始全量加载完成")

    def _poll_robot_status(self):
        try:
            adapter = self._get_rcs_adapter()
            resp = adapter.query_agv_status(self._robot_ids)
            if resp.get('code') != '0':
                self._robot_poll_errors += 1
                self.logger.warning(f"叉车状态轮询失败: {resp.get('msg')}")
                return
            for item in resp.get('data', []):
                robot_id = item.get('robotID')
                status = item.get('agvStatus', 'OFFLINE')
                self.robot_cache.update_status(
                    robot_id=int(robot_id) if robot_id else 0,
                    status=status,
                    battery=int(item.get('battery')) if item.get('battery') else None,
                    position_code=item.get('positionCode'),
                )
            self._last_robot_poll = self.node.get_clock().now().nanoseconds / 1e9
            self._robot_poll_errors = 0
        except Exception as e:
            self._robot_poll_errors += 1
            self.logger.warning(f"叉车状态轮询异常: {e}")

    def _poll_dest_bays(self):
        all_codes = self.dest_cache.get_all_bay_ids()
        if not all_codes:
            return
        try:
            adapter = self._get_rcs_adapter()
            resp = adapter.query_pod_berth_and_mat(all_codes)
            if resp.get('code') != '0':
                self._dest_poll_errors += 1
                self.logger.warning(f"终点仓位轮询失败: {resp.get('msg')}")
                return
            for item in resp.get('data', []):
                stg_code = item.get('stgBinCode')
                ctnr_code = item.get('ctnrCode')
                self.dest_cache.update(stg_code, is_empty=(not ctnr_code), source='polling')
            self._last_dest_poll = self.node.get_clock().now().nanoseconds / 1e9
            self._dest_poll_errors = 0
        except Exception as e:
            self._dest_poll_errors += 1
            self.logger.warning(f"终点仓位轮询异常: {e}")

    def _get_rcs_adapter(self):
        adapter = getattr(self.node, 'rcs_adapter', None)
        if adapter is None:
            adapter = self.node.plugin_manager.get_plugin('rcs_adapter')
        if adapter is None:
            raise RuntimeError("RCS 适配器未加载")
        return adapter

    def get_status(self) -> Dict[str, Any]:
        base = super().get_status()
        base.update({
            'robot_count': self.robot_cache.get_robot_count() if self.robot_cache else 0,
            'dest_bay_count': len(self.dest_cache.get_all_bay_ids()) if self.dest_cache else 0,
            'idle_robot': self.robot_cache.get_idle_robot() if self.robot_cache else None,
            'last_robot_poll': self._last_robot_poll,
            'last_dest_poll': self._last_dest_poll,
            'robot_poll_errors': self._robot_poll_errors,
            'dest_poll_errors': self._dest_poll_errors,
            'initial_poll_done': self._initial_poll_done,
        })
        return base

    def get_robot_status(self, robot_id: int) -> Optional[dict]:
        return self.robot_cache.get_robot_status(robot_id) if self.robot_cache else None

    def get_all_robot_status(self) -> Dict[int, dict]:
        return self.robot_cache.get_all_robot_status() if self.robot_cache else {}

    def get_dest_bay_status(self, bay_id: str) -> Optional[dict]:
        return self.dest_cache.get_bay_status(bay_id) if self.dest_cache else None
```

## 7. callback_handler_plugin 回调接口扩展

RCS 调度系统作为 HTTP 客户端，向本系统（作为 HTTP 服务端）推送以下三类通知。本系统复用已有的 `CallbackReceiver`（基于 FastAPI + uvicorn）来接收这些回调，在 `callback_handler_plugin.py` 中注册回调路由，将 RCS 通知转换为 EventBus 事件。

> **注意**: 本节描述的回调接口扩展是对已有 `callback_handler_plugin.py` 的**增强**。原始插件已具备 `CallbackReceiver` 的启动/停止能力和 `register_post()` 通用注册方法。本节在其基础上增加 RCS 专属的三个路由注册和事件发布。

### 7.1 回调接口一览

| 接口路径 | HTTP 方法 | 用途 | RCS 推送触发条件 |
|:---|:---|:---|:---|
| `/agvCallback` | POST | 任务执行状态通知 | 任务状态变更时（开始、完成、异常等） |
| `/warnCallback` | POST | 告警推送通知 | 发生告警事件时（超时、碰撞、离线等） |
| `/bindNotify` | POST | 绑定/解绑通知 | 仓位绑定或解绑完成时 |

### 7.2 agvCallback — 任务执行通知

**RCS 推送时机**: AGV 任务状态发生变更（开始执行、完成、暂停、异常等）

**请求体 JSON 结构**:

```json
{
    "taskCode": "TASK_1723456789_01",
    "agvCode": "1001",
    "taskStatus": "2",
    "positionCode": "T2001",
    "timestamp": "2026-07-28 10:30:00"
}
```

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `taskCode` | string | RCS 任务号 |
| `agvCode` | string | AGV 编号 |
| `taskStatus` | string | 任务状态码：1=开始执行, 2=执行完成, 3=执行失败, 4=暂停, 9=已结束 |
| `positionCode` | string | 当前位置编码 |
| `timestamp` | string | 状态变更时间 |

**发布事件**: `rcs.agv_callback`

**事件 data 结构**:

```python
{
    'task_code': 'TASK_1723456789_01',
    'agv_code': '1001',
    'task_status': '2',
    'position_code': 'T2001',
    'timestamp': '2026-07-28 10:30:00',
}
```

### 7.3 warnCallback — 告警推送通知

**RCS 推送时机**: 发生告警事件（AGV 超时、碰撞、离线等）

**请求体 JSON 结构**:

```json
{
    "warnCode": "W001",
    "warnMsg": "AGV 1001 超时未到达目标点",
    "agvCode": "1001",
    "taskCode": "TASK_1723456789_01",
    "warnLevel": "1",
    "timestamp": "2026-07-28 10:35:00"
}
```

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `warnCode` | string | 告警编码 |
| `warnMsg` | string | 告警描述 |
| `agvCode` | string | 关联 AGV 编号（可选） |
| `taskCode` | string | 关联任务号（可选） |
| `warnLevel` | string | 告警级别：0=信息, 1=警告, 2=严重 |
| `timestamp` | string | 告警时间 |

**发布事件**: `rcs.warn_callback`

### 7.4 bindNotify — 绑定/解绑通知

**RCS 推送时机**: 仓位绑定或解绑操作完成时

**请求体 JSON 结构**:

```json
{
    "stgBinCode": "A1001",
    "indBind": "0",
    "ctnrCode": "CTNR_A1001",
    "timestamp": "2026-07-28 10:28:00"
}
```

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `stgBinCode` | string | 仓位编码 |
| `indBind` | string | "1"=绑定, "0"=解绑 |
| `ctnrCode` | string | 容器编码（解绑时可能为空） |
| `timestamp` | string | 绑定/解绑时间 |

**发布事件**: `rcs.bind_notify`

> **重要**: 收到 `indBind="0"`（解绑）通知后，需要同步更新：
> - `BayCache.set_unbound(bay_id)` — 将起始仓位标记为未绑定
> - `DestBayCache.update(bay_id, is_empty=True)` — 将终点仓位标记为空

### 7.5 回调处理器插件更新代码

**路径**: `app_mgr_object/plugins/callback_handler_plugin.py`（在现有基础上新增以下方法）

以下为需要在 `CallbackHandlerPlugin` 类中**新增**的代码：

```python
# ═══════════════════════════════════════════════════════════════
#  RCS 回调路由注册（新增部分）
# ═══════════════════════════════════════════════════════════════

def register_rcs_callbacks(self) -> bool:
    """
    注册 RCS 三个回调路由。

    在 _activate_impl 中调用此方法，将 agvCallback / warnCallback / bindNotify
    三个路由注册到 CallbackReceiver 上。

    Returns:
        bool: 注册成功返回 True
    """
    if not self.receiver:
        self.logger.error("CallbackReceiver 未初始化，无法注册 RCS 回调")
        return False

    try:
        # 2-1. 任务执行状态通知
        self.receiver.register_json_post('/agvCallback', self._on_agv_callback)
        self.logger.info("已注册 RCS 回调路由: POST /agvCallback")

        # 2-2. 告警推送通知
        self.receiver.register_json_post('/warnCallback', self._on_warn_callback)
        self.logger.info("已注册 RCS 回调路由: POST /warnCallback")

        # 2-3. 绑定/解绑通知
        self.receiver.register_json_post('/bindNotify', self._on_bind_notify)
        self.logger.info("已注册 RCS 回调路由: POST /bindNotify")

        return True

    except Exception as e:
        self.logger.error(f"注册 RCS 回调路由失败: {e}")
        return False


def _on_agv_callback(self, data: dict) -> dict:
    """
    处理 agvCallback → 发布 rcs.agv_callback 事件

    Args:
        data: RCS 推送的 JSON body

    Returns:
        标准响应 {"code": "0", "msg": "ok"}
    """
    event_data = {
        'task_code': data.get('taskCode', ''),
        'agv_code': data.get('agvCode', ''),
        'task_status': data.get('taskStatus', ''),
        'position_code': data.get('positionCode', ''),
        'timestamp': data.get('timestamp', ''),
    }

    self.logger.info(
        f"收到 agvCallback: task={event_data['task_code']}, "
        f"status={event_data['task_status']}, agv={event_data['agv_code']}"
    )

    # 发布事件到 EventBus，供 workflow_engine / smart_trigger 订阅
    self._publish_event('rcs.agv_callback', event_data)

    return {'code': '0', 'msg': 'ok'}


def _on_warn_callback(self, data: dict) -> dict:
    """
    处理 warnCallback → 发布 rcs.warn_callback 事件

    Args:
        data: RCS 推送的 JSON body

    Returns:
        标准响应 {"code": "0", "msg": "ok"}
    """
    event_data = {
        'warn_code': data.get('warnCode', ''),
        'warn_msg': data.get('warnMsg', ''),
        'agv_code': data.get('agvCode', ''),
        'task_code': data.get('taskCode', ''),
        'warn_level': data.get('warnLevel', '0'),
        'timestamp': data.get('timestamp', ''),
    }

    level_label = {0: '信息', 1: '警告', 2: '严重'}.get(
        int(event_data['warn_level']) if event_data['warn_level'].isdigit() else 0, '未知'
    )
    self.logger.warning(
        f"收到 warnCallback [{level_label}]: {event_data['warn_msg']} "
        f"(code={event_data['warn_code']}, agv={event_data['agv_code']})"
    )

    self._publish_event('rcs.warn_callback', event_data)

    return {'code': '0', 'msg': 'ok'}


def _on_bind_notify(self, data: dict) -> dict:
    """
    处理 bindNotify → 发布 rcs.bind_notify 事件 + 同步更新缓存

    Args:
        data: RCS 推送的 JSON body

    Returns:
        标准响应 {"code": "0", "msg": "ok"}
    """
    stg_bin_code = data.get('stgBinCode', '')
    ind_bind = data.get('indBind', '1')
    ctnr_code = data.get('ctnrCode', '')

    event_data = {
        'stg_bin_code': stg_bin_code,
        'ind_bind': ind_bind,         # "1"=绑定, "0"=解绑
        'ctnr_code': ctnr_code,
        'timestamp': data.get('timestamp', ''),
    }

    action = "绑定" if ind_bind == "1" else "解绑"
    self.logger.info(
        f"收到 bindNotify: {action} 仓位 {stg_bin_code}, "
        f"容器={ctnr_code}"
    )

    # 发布事件到 EventBus
    self._publish_event('rcs.bind_notify', event_data)

    # 同步更新缓存（直接操作 BayCache / DestBayCache）
    self._sync_cache_on_bind_notify(stg_bin_code, ind_bind)

    return {'code': '0', 'msg': 'ok'}


def _sync_cache_on_bind_notify(self, bay_code: str, ind_bind: str):
    """
    根据 bindNotify 同步更新内存缓存

    Args:
        bay_code: 仓位编码
        ind_bind: "1"=绑定, "0"=解绑
    """
    try:
        # 尝试更新起始仓位缓存
        bay_fusion = getattr(self.node, 'bay_status_fusion', None)
        if bay_fusion and bay_fusion.cache:
            if ind_bind == "1":
                bay_fusion.cache.set_bound(bay_code)
            else:
                bay_fusion.cache.set_unbound(bay_code)
                bay_fusion.cache.mark_in_task(bay_code, False)

        # 尝试更新终点仓位缓存
        status_poller = getattr(self.node, 'status_poller', None)
        if status_poller and status_poller.dest_cache:
            if ind_bind == "0":
                # 解绑 → 终点仓位变为空
                status_poller.dest_cache.update(
                    bay_code, is_empty=True, source='rcs_callback'
                )
            elif ind_bind == "1":
                # 绑定 → 终点仓位变为非空
                status_poller.dest_cache.update(
                    bay_code, is_empty=False, source='rcs_callback'
                )

        self.logger.debug(f"缓存同步完成: {bay_code} ind_bind={ind_bind}")
    except Exception as e:
        self.logger.warning(f"缓存同步失败: {e}")
```
