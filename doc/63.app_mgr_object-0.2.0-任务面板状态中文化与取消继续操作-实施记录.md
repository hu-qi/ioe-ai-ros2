## 3. 代码变更说明（dashboard.js）

### 3.1 映射表（L293-330 区域）

- `STATUS_BADGE_MAP` 扩展（新增状态 → 既有色系：running 绿 / pending 橙 / completed 蓝 / failed 红 / idle 灰）；
- `STATE_CN`：calling_rcs=下发中、monitoring=执行中、compensating_query=补偿查询、warn_pause=警告暂停、releasing/releasing_and_done=释放中、manual_intervention=人工介入、auto_recovery=自动恢复、completed=已完成、failed=失败、cancelled=已取消；
- `STATUS_CN`：SUCCESS=已完成、FAILED=失败、RUNNING=执行中、DISPATCHING=下发中、MANUAL=人工介入、PENDING=待处理、CANCELLED=已取消。

### 3.2 活跃 Tab（renderActiveTasks，L371-387）

- 状态列：`STATE_CN[t.current_state] || STATE_CN[t.status] || t.status || '--'`；
- 操作列：查询按钮 + （`t.rcs_task_no` 存在时）继续按钮（绿，continueTaskInline）+ 取消按钮（红，cancelTaskInline）。

### 3.3 历史 Tab（renderHistoryTasks，L458）

- 状态列：`STATUS_CN[t.status] || t.status || '--'`。

### 3.4 行内操作函数（L1535-1544）

```js
window.cancelTaskInline = function(tid) {
    confirmTaskControl('cancel', { task_id: tid },
        '确定取消任务 ' + tid + ' 吗？\n取消后将释放该任务占用的资源。');
};
window.continueTaskInline = function(tid) {
    confirmTaskControl('continue', { task_id: tid },
        '确定继续执行任务 ' + tid + ' 吗？\n将调用 RCS continueTask 继续该任务。');
};
```

后端链路（复用）：`cancel → /api/task/control{operation:'cancel'} → 工作流 user_cancel → 释放资源`；`continue → {operation:'continue'} → rcs.continue_task(rcs_task_no)`（task_controller.py:49、103-111）。
