# app_mgr_object-0.1.8 业务监控页告警文字颜色修复指南

> 文档版本：v1.0
> 编写日期：2026-08-10
> 适用工程：`app_mgr_object-0.1.8(标准版)`
> 需求：业务监控页（首页 `/`）"告警信息栏"的告警内容文字显示为浅白色；当前文字呈黑色，与深色背景相近、难以辨认。

---

## 0. 结论摘要

- 问题文件：`app_mgr_object/components/web/static/css/custom.css`
- 问题位置：`.alarm-row`（L276~L280）与 `.alarm-msg`（L290）
- 根因：告警行只声明了 `background` 与 `font-size`，**未显式声明文字颜色**；文字颜色完全依赖继承链（body → card → alarm-list → alarm-row → alarm-msg），在深色主题下被解析为近黑色，与 `--bg-tertiary` 深色背景混为一体。
- 修复方式：在 `.alarm-row` / `.alarm-msg` 上显式声明 `color`（深色主题 → 浅白 `var(--text-primary)`；浅色主题 → 深色文字保证可读性），并同步补齐浅色主题覆盖。
- 涉及改动：仅 `custom.css` 一处（两段规则）；`dashboard.js`、`index.html` 无需改动（可选内联兜底见第 3 章方案 B）。

---

## 1. 问题定位

### 1.1 告警行渲染链路

```text
index.html（L199-201）：
  <div class="alarm-list" id="alarm-list">
      <div class="alarm-empty">✅ 暂无告警</div>     ← 初始占位
  </div>

dashboard.js renderAlarmList()（L309-315）动态生成：
  <div class="alarm-row warning" data-alarm-id="...">
      <span class="alarm-dot"></span>
      <span class="alarm-msg">告警内容...</span>      ← 无内联颜色
      <span class="alarm-time">...</span>
      <span class="alarm-actions">...</span>
  </div>
```

### 1.2 现有 CSS（custom.css）

```css
/* L275-294 深色主题默认 */
.alarm-list { display: flex; flex-direction: column; gap: 4px; }
.alarm-row {
    display: flex; align-items: center; gap: 10px;
    padding: 7px 10px; border-radius: 5px;
    background: var(--bg-tertiary); font-size: 12px;   /* ← 无 color */
}
.alarm-row.critical { border-left: 3px solid var(--accent-red); }
.alarm-row.warning  { border-left: 3px solid var(--accent-orange); }
.alarm-row.info     { border-left: 3px solid var(--accent-blue); }
.alarm-dot { width: 8px; height: 8px; border-radius: 50%; flex-shrink: 0; }
.alarm-row.critical .alarm-dot { background: var(--accent-red); }
.alarm-row.warning  .alarm-dot { background: var(--accent-orange); }
.alarm-row.info     .alarm-dot { background: var(--accent-blue); }
.alarm-msg   { flex: 1; }                               /* ← 无 color */
.alarm-time  { color: var(--text-muted); font-size: 11px; white-space: nowrap; }
.alarm-actions { display: flex; gap: 4px; }
.alarm-actions button { font-size: 10px; padding: 2px 8px; }

/* L461 浅色主题覆盖 */
[data-theme="light"] .alarm-row {
    background: #f8f9fb;                                /* ← 也无 color */
}
```

### 1.3 根因说明

`alarm-msg` 未声明颜色时，颜色按继承链向上查找。在深色主题下告警行背景为 `--bg-tertiary`（深蓝灰 `#243447`），而文字颜色受外部影响被解析为近黑色，形成"黑字配深底"的低对比度效果；浅色主题下 `[data-theme="light"] .alarm-row` 仅覆盖了背景，文字颜色同样未锁定，存在同源风险。

**修复原则**：告警行/告警内容显式声明颜色，不依赖继承；深色主题用浅白（`var(--text-primary)` = `#e8edf2`），浅色主题用深色文字（`#1a1a2e`）保证可读性。

## 2. 修改步骤

```text
Step 1  定位文件：app_mgr_object/components/web/static/css/custom.css
Step 2  在 .alarm-row 规则块内追加 color: var(--text-primary);
Step 3  在 .alarm-msg 规则块内追加 color: var(--text-primary);
Step 4  在 [data-theme="light"] .alarm-row 规则块内追加 color: #1a1a2e;
        （如需浅色主题下仍强制浅白，见 2.3 备注）
Step 5  刷新业务监控页（Ctrl+F5 强制刷新），验证告警文字对比度
```

### 2.1 修改后代码（custom.css）

```css
/* ===== 告警信息栏 ===== */
.alarm-list { display: flex; flex-direction: column; gap: 4px; }
.alarm-row {
    display: flex; align-items: center; gap: 10px;
    padding: 7px 10px; border-radius: 5px;
    background: var(--bg-tertiary); font-size: 12px;
    color: var(--text-primary);          /* ← 新增：深色主题浅白文字 */
}
.alarm-row.critical { border-left: 3px solid var(--accent-red); }
.alarm-row.warning  { border-left: 3px solid var(--accent-orange); }
.alarm-row.info     { border-left: 3px solid var(--accent-blue); }
.alarm-dot {
    width: 8px; height: 8px; border-radius: 50%; flex-shrink: 0;
}
.alarm-row.critical .alarm-dot { background: var(--accent-red); }
.alarm-row.warning  .alarm-dot { background: var(--accent-orange); }
.alarm-row.info     .alarm-dot { background: var(--accent-blue); }
.alarm-msg   { flex: 1; color: var(--text-primary); }  /* ← 新增 */
.alarm-time  { color: var(--text-muted); font-size: 11px; white-space: nowrap; }
.alarm-actions { display: flex; gap: 4px; }
.alarm-actions button { font-size: 10px; padding: 2px 8px; }
.alarm-empty { text-align: center; color: var(--accent-green); padding: 12px; font-size: 13px; }
```

浅色主题覆盖同步补充：

```css
[data-theme="light"] .alarm-row {
    background: #f8f9fb;
    color: #1a1a2e;                      /* ← 新增：浅色主题深色文字 */
}
[data-theme="light"] .alarm-msg {
    color: #1a1a2e;                      /* ← 新增 */
}
```

### 2.2 效果说明

| 主题 | 修改前 | 修改后 |
|---|---|---|
| 深色（默认）| 近黑色文字 + 深蓝灰背景（低对比）| 浅白 `#e8edf2` + 深蓝灰背景（高对比）|
| 浅色 | 未锁定，继承链风险 | 深色 `#1a1a2e` + 浅灰 `#f8f9fb` 背景（高对比）|

### 2.3 备注（如需浅色主题也强制浅白）

如果产品要求"无论深浅主题，告警文字一律浅白"，可将浅色主题覆盖改为：

```css
[data-theme="light"] .alarm-row {
    background: #f8f9fb;
    color: #e8edf2;                      /* 强制浅白（浅色底上对比度较低，谨慎使用）*/
}
```

> 建议：保持"深色主题浅白、浅色主题深色"的语义化方案，可读性最佳。

## 3. 可选方案 B：前端渲染内联兜底（不推荐，仅应急）

如需在**不修改 CSS** 的情况下应急修复，可改 `static/js/dashboard.js` 的 `renderAlarmList()`，给 `.alarm-msg` 追加内联颜色：

```javascript
return '<div class="alarm-row ' + levelClass + '" data-alarm-id="' + (a.id || '') + '">' +
    '<span class="alarm-dot"></span>' +
    '<span class="alarm-msg" style="color:var(--text-primary);">' +
        escapeHtml(a.message || '未知告警') + '</span>' +
    '<span class="alarm-time">' + timeStr + '</span>' +
    ...
```

> 缺点：内联样式优先级最高，会覆盖浅色主题适配，且与"样式集中在 CSS"的工程规范相悖；仅在无法发布 CSS 时应急使用。推荐采用第 2 章 CSS 方案。
