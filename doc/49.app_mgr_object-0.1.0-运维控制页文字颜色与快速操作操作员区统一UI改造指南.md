# app_mgr_object-0.1.0 运维控制页文字颜色与快速操作操作员区统一 UI 改造指南

> 文档版本：v1.0
> 编写日期：2026-08-11
> 适用工程：`app_mgr_object-0.1.0(标准版)`
> 需求：运维控制页（`/control`）
>   1. "服务管理"卡片文字为黑色、与深色背景相近 → 改为主题浅灰系文字；
>   2. "自定义命令"卡片栏文字颜色统一；
>   3. "最近操作"卡片文字颜色统一；
>   4. "快速操作"卡的操作员信息区（operator 输入框）与"切换"按钮改为当前统一 UI 风格。

## 0. 审查结论（根因）

改造文件（2 个，JS 零改动）：

- `app_mgr_object/components/web/static/css/custom.css`（末尾追加样式段，做根因兜底）
- `app_mgr_object/components/web/templates/control.html`（类名/结构替换）

### 0.1 根因：Bootstrap 默认文字色未被深色主题覆盖

| 根因 | Bootstrap 默认值（bootstrap.min.css 证据） | 现象 |
|---|---|---|
| `.card` 自带文字颜色 | `.card{color:var(--bs-body-color)}`，`--bs-body-color:#212529`（近黑） | 服务管理卡内 `<h6>` 标题、未显式设色的文字为黑色，深色底上看不清 |
| `.text-muted` 是深灰 | `.text-muted{color:var(--bs-secondary-color)!important}`，值为 `rgba(33,37,41,.75)` | 服务描述、提示文字、"操作员: xxx"、"暂无操作记录"全部近黑 |
| `.form-label` 继承 body 色 | 近黑 `#212529` | 服务管理/自定义命令表单标签为黑色 |
| `.input-group-text` 白底黑字 | Bootstrap 默认浅灰底 + body 黑字 | 命令输入 `$` 前缀、操作员人像图标块突兀 |
| `.btn` / `.btn-outline-secondary` | 默认色 `--bs-btn-color:#212529` | "执行命令"按钮文字黑色；"切换"按钮与统一 `btn-outline` 风格不符 |
| `.alert-warning/info/danger` | 浅色底 + 黑色文字 | 自定义命令"安全限制"、运行模式等提示框浅底黑字 |

> custom.css 已具备、无需重复定义的统一样式：`.card.status-card`、`.card-header h5`、`.op-label`、`.btn-accent`、`.btn-outline`、`.form-control/.form-select`（深色）、`.alert-theme`、`.quick-action-btn`、`.recent-operation-item`、`.op-badge`、`.accordion-*`、`.help-note`。

## 1. 统一规则

```text
卡片主文字：      var(--text-primary)（#e8edf2 浅白灰）  —— 服务卡 h6 标题、卡片正文
次要/说明文字：   var(--text-muted)（#5a6f85 浅灰蓝）    —— text-muted、时间、操作员行、标签
表单标签：        form-label → op-label（11px 浅灰，与首页操作区一致）
输入框前缀/后缀： input-group-text 深色化（bg-tertiary 底 + text-secondary 图标）
主操作按钮：      执行命令 → btn-accent（与"重启服务/执行服务操作"一致）
切换按钮：        btn-outline-secondary → btn-outline btn-sm（与"查看更多"一致）
操作员信息区：    operator-panel（bg-tertiary 底 + 左侧强调色条，与快速操作按钮同族）
提示框：          alert-info/warning/danger 统一深色化（深底 + 左侧语义色条）
JS 逻辑：         switchOperator() / controlService* / loadMoreOperations() 等全部不动
```

## 3. 修改代码

### 3.1 `static/css/custom.css` 末尾追加

```css
/* ============================================================
   运维控制页 — 卡片文字颜色兜底 / 操作员区统一（0.1.0 修复）
   根因：Bootstrap .card color=#212529、.text-muted=rgba(33,37,41,.75)
   ============================================================ */

/* 1) 卡片文字颜色兜底：覆盖 Bootstrap .card 的黑色 body color */
.control-page .card {
    color: var(--text-primary);
}
.control-page .card-body {
    color: var(--text-primary);
}
.control-page .card-body h5,
.control-page .card-body h6 {
    color: var(--text-primary);
}

/* 2) text-muted 兜底：覆盖 Bootstrap 深灰（工具类带 !important，此处同样需要） */
.control-page .text-muted {
    color: var(--text-muted) !important;
}

/* 3) form-label 兜底：HTML 已统一换 op-label，此处防漏改 */
.control-page .form-label {
    font-size: 11px;
    color: var(--text-muted);
    margin-bottom: 3px;
    letter-spacing: 0.5px;
}

/* 4) input-group 前缀/后缀深色化（Bootstrap 默认浅底黑字） */
.control-page .input-group-text {
    background: var(--bg-tertiary);
    color: var(--text-secondary);
    border-color: var(--border);
    font-size: 12px;
}

/* 5) alert 提示框深色化（替代 Bootstrap alert-info/warning/danger 浅底黑字） */
.control-page .alert-info,
.control-page .alert-warning,
.control-page .alert-danger {
    background: var(--bg-tertiary);
    border: 1px solid var(--border);
    color: var(--text-primary);
    font-size: 12px;
    border-radius: var(--card-radius);
}
.control-page .alert-info    { border-left: 3px solid var(--accent-blue); }
.control-page .alert-warning { border-left: 3px solid var(--accent-orange); }
.control-page .alert-danger  { border-left: 3px solid var(--accent-red); }

/* alert-theme 语义色变体（配合已有 .alert-theme 使用） */
.control-page .alert-theme.info    { border-left-color: var(--accent-blue); }
.control-page .alert-theme.warning { border-left-color: var(--accent-orange); }
.control-page .alert-theme.danger  { border-left-color: var(--accent-red); }

/* 6) 快速操作 — 操作员信息区（与快速操作卡同族：深色面板 + 左侧强调色条） */
.operator-panel {
    margin-top: 16px;
    padding: 10px 12px;
    background: var(--bg-tertiary);
    border: 1px solid var(--border);
    border-left: 3px solid var(--accent-teal);
    border-radius: 6px;
}
.operator-panel h6 {
    font-size: 12px;
    font-weight: 600;
    color: var(--text-primary);
    margin-bottom: 8px;
}
.operator-panel .operator-role {
    font-size: 11px;
    color: var(--text-muted);
}
```

> 说明：选择器统一挂在 `.control-page` 容器下（control.html L105 已具备该 class，模态框也在容器内），不影响首页/其他页面；浅色主题通过 CSS 变量自动适配，无需追加 `[data-theme="light"]` 覆盖。
