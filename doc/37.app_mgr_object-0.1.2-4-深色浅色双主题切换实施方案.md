# app_mgr_object-0.1.2-4 前端双主题（深色/浅色）切换实施方案

> 需求：默认深色主题，导航栏顶部提供主题切换按钮，可切换为浅色主题
> 技术路线：CSS 自定义属性双层定义 + `data-theme` 属性 + localStorage 记忆

| 文件 | 行数 | 主题相关状态 |
|---|---|---|

| `templates/monitor.html` | ~80 | 全部依赖 CSS 变量 |

| `static/js/monitor.js` | ~150 | Chart.js 颜色硬编码（需适配） |

### 0.2 关键发现

**好消息**：全工程的前端样式 100% 使用 `var(--bg-primary)` / `var(--text-primary)` 等 CSS 自定义属性，无硬编码的 `#0f1923` 深色值出现在 HTML 或内联样式中（除了 chart.js 的 scale 颜色和 cargo_type 业务色）。

这意味着**只需在 `:root` 旁边加一个 `[data-theme="light"]` 变量覆盖块**，整个 UI 自动切换。

**唯一需要额外适配的位置**：
- `monitor.js` 中 Chart.js 的 `ticks.color` 和 `grid.color` 是硬编码的 `#5a6f85` / `#1e2d3d`
- 解决：改为读取 CSS 变量或 JS 判断 `data-theme` 属性

### Step 1 — custom.css 追加浅色主题变量块

**文件**: `app_mgr_object/components/web/static/css/custom.css`

   通过 CSS 属性选择器覆盖 :root 变量

    --bg-primary:    #f4f6f9;
    --bg-secondary:  #ffffff;

### Step 3 — base.html 底部 JS 追加主题切换逻辑

**文件**: `app_mgr_object/components/web/templates/base.html`

在 `</body>` 前的 `<script>` 区域中，`updateClock()` 之后追加主题切换代码：

```javascript
        // ===== 主题切换 =====
        (function() {
            var THEME_KEY = 'app-theme';
            var html = document.documentElement;
            var toggleBtn = document.getElementById('theme-toggle');
            var icon = document.getElementById('theme-icon');

            // 读取本地存储中的主题，默认 dark
            var saved = localStorage.getItem(THEME_KEY);
            var currentTheme = saved || 'dark';
            applyTheme(currentTheme);

            // 点击切换
            if (toggleBtn) {
                toggleBtn.addEventListener('click', function() {
                    var next = (html.getAttribute('data-theme') === 'dark') ? 'light' : 'dark';
                    applyTheme(next);
                    localStorage.setItem(THEME_KEY, next);
                });
            }

            function applyTheme(theme) {
                if (theme === 'light') {
                    html.setAttribute('data-theme', 'light');
                    if (icon) { icon.className = 'fas fa-moon'; }
                    if (toggleBtn) { toggleBtn.title = '切换到深色主题'; }
                } else {
                    html.removeAttribute('data-theme');
                    if (icon) { icon.className = 'fas fa-sun'; }
                    if (toggleBtn) { toggleBtn.title = '切换到浅色主题'; }
                }
            }
        })();
        // ===== 主题切换结束 =====
```

### Step 4 — monitor.js Chart.js 颜色适配

**文件**: `app_mgr_object/components/web/static/js/monitor.js`

将 `updateHealthChart` 函数中硬编码的 chart 颜色改为根据主题动态取值：

```javascript
function getChartColors() {
    var isLight = document.documentElement.getAttribute('data-theme') === 'light';
    return {
        lineColor: '#27ae60',
        gridColor:   isLight ? '#e0e4e8' : '#1e2d3d',
        tickColor:   isLight ? '#8896a6' : '#5a6f85',
        fillStart:   isLight ? 'rgba(39,174,96,0.08)' : 'rgba(39,174,96,0.3)',
        fillEnd:     isLight ? 'rgba(39,174,96,0)'     : 'rgba(39,174,96,0)',
    };
}

function updateHealthChart(score) {
    var colors = getChartColors();
    var now = new Date().toLocaleTimeString('zh-CN', {hour12: false});
    healthData.push({ x: now, y: score });
    if (healthData.length > 30) healthData.shift();

    var ctx = document.getElementById('healthChart').getContext('2d');
    if (healthChart) healthChart.destroy();

    var gradient = ctx.createLinearGradient(0, 0, 0, 200);
    gradient.addColorStop(0, colors.fillStart);
    gradient.addColorStop(1, colors.fillEnd);

    healthChart = new Chart(ctx, {
        type: 'line',
        data: {
            datasets: [{
                label: '健康度 %',
                data: healthData,
                borderColor: colors.lineColor,
                backgroundColor: gradient,
                fill: true,
                tension: 0.3,
                pointRadius: 2,
                pointBackgroundColor: colors.lineColor,
            }]
        },
        options: {
            responsive: true,
            maintainAspectRatio: false,
            scales: {
                x: { ticks: { color: colors.tickColor, font: { size: 10 } }, grid: { color: colors.gridColor } },
                y: { min: 0, max: 100, ticks: { color: colors.tickColor, font: { size: 10 }, callback: function(v) { return v + '%'; } }, grid: { color: colors.gridColor } }
            },
            plugins: { legend: { display: false } }
        }
    });
}
```

**已有调用点无需修改**：`updateHealthChart(score)` 接口不变，内部已自动根据主题取色。

## 6. 注意事项

1. **Bootstrap 默认样式**：浅色主题下 Bootstrap 的 `.navbar-dark` 会与 `[data-theme="light"]` 产生冲突。base.html 当前未使用 `.navbar-dark` 类，而是通过 custom.css 的 `.navbar` 规则控制颜色，因此无冲突。如果未来有人添加了 `.navbar-dark`，需在 `[data-theme="light"]` 中覆盖。

2. **CARGO_COLORS 不变**：仓位 6 种 cargo_type 的颜色（蓝/绿/橙/紫/青/红）是业务语义色，不是主题色，深浅主题下保持不变。

3. **图表重绘**：Chart.js 实例在切换主题时不会自动更新（因为 chart 数据只在页面加载和周期刷新时更新）。如需立即响应主题切换，可在 `applyTheme()` 中触发 `window.dispatchEvent(new Event('theme-changed'))`，monitor.js 监听该事件后调用 `updateHealthChart` 重绘。本方案不包含此优化（因为切换主题后 10s 内周期刷新会触发重绘）。

4. **localStorage 键名**：使用 `app-theme` 作为键名，避免与其他应用冲突。
