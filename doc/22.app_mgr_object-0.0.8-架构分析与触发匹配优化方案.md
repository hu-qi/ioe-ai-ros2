## 3. 触发决策机制分析（当前实现）

### 3.1 当前触发流程

```
_scan_loop() 每 2s 运行一次:
  │
  ├─ batch_scan_all(exclude_src, exclude_dst)
  │    │
  │    ├─ 对 cargo_priority=[1,2,3,4,5,6] 遍历
  │    │    │
  │    │    ├─ bay_cache.get_bound_bays_of_type(cargo_type)
  │    │    │    → available_src = [A1001, A1002, B1001]  (去重后)
  │    │    │
  │    │    ├─ dest_cache.get_empty_bays_of_type(cargo_type)
  │    │    │    → empty_dst = [T2001, T2002]  (去重后)
  │    │    │
  │    │    └─ ★ 笛卡尔积: for src in available_src:
  │    │                     for dst in empty_dst:
  │    │                         candidates.append(TaskCandidate(src, dst))
  │    │
  │    └─ sort(candidates, key=priority_key)
  │
  ├─ task_queue.enqueue_all(candidates)
  │    └─ 去重: 跳过 _queued_src 或 _queued_dst 已存在的
  │
  └─ _dispatch_from_queue()
       └─ try_dequeue()
            ├─ 检查 AGV 可用
            ├─ 遍历队列 → 尝试 lock(robot, src, dst)
            └─ 锁定成功 → 出队 → 发布 trigger.task_created
```

### 3.2 笛卡尔积匹配的问题分析

**当前 `batch_matcher.py` 核心代码**:

```python
# batch_matcher.py: batch_scan_all()
for src_bay in available_src:
    for dst_bay in empty_dst:
        candidate = TaskCandidate(
            src_bay=src_bay,
            dst_bay=dst_bay,
            cargo_type=cargo_type,
            bind_time=bind_time,
        )
        all_candidates.append(candidate)
```

**问题示例**:

```
假设 cargo_type=1:
  available_src = [A1001, A1002, B1001]   (3 个)
  empty_dst     = [T2001, T2002]          (2 个)

笛卡尔积生成: 3 × 2 = 6 个候选任务
  A1001→T2001, A1001→T2002,
  A1002→T2001, A1002→T2002,
  B1001→T2001, B1001→T2002

实际可执行: 最多 min(3, 2) = 2 个任务
  (每个 src 只能去一个 dst, 每个 dst 只能接一个 src)

冗余: 6 - 2 = 4 个虚拟候选 (66.7% 冗余)
```

**四个层面上的浪费**:

| 层面 | 笛卡尔积行为 | 浪费 |
|:---|:---|:---|
| **生成** | m×n 个候选 | 生成无效组合 |
| **排序** | 对全部 m×n 排序 | O(mn·log(mn)) 中大量无意义排序 |
| **入队** | 全部入队后被去重 | _queued_src/_queued_dst 碰撞丢弃 |
| **出队** | 遍历队列找第一个可锁定 | 遍历大量无效条目才找到有效对 |

**量化分析（峰值场景）**:

```
最坏情况 (cargo_type=1 集中):
  6 个已绑定 src × 2 个空 dst = 12 候选
  实际有效: min(6, 2) = 2
  冗余率: 83.3%

典型场景 (均匀分布):
  每类型 2 个 src × 2 个 dst = 4 候选/类型
  6 类型 × 4 = 24 候选
  实际有效: 12 (每类型最多 2 对)
  冗余率: 50%
```

### 3.3 当前去重机制（后置过滤）

当前队列通过以下机制补偿笛卡尔积的冗余:

```python
# task_queue.py: enqueue_all()
def _is_duplicate(self, candidate):
    return (candidate.src_bay in self._queued_src or
            candidate.dst_bay in self._queued_dst)
```

**问题**: 这是后置过滤——候选已经生成、排序、遍历，只是在入队时丢弃。浪费已经发生。

## 5. 优化方案：笛卡尔积 → 贪婪匹配

### 5.1 算法设计

**核心思想**: 对于同一 cargo_type，将已绑定起始仓位和空终点仓位分别排序后，按顺序一对一配对。每个仓位只参与一次匹配。

```
输入 (cargo_type=1):
  sorted_src = [A1001 (bind_time=1000), A1002 (bind_time=800), B1001 (bind_time=500)]
  sorted_dst = [T2001, T2002]

贪婪配对:
  idx=0: A1001 → T2001  ✓
  idx=1: A1002 → T2002  ✓
  idx=2: B1001 → (无 dst)  ✗

输出: 2 个候选 (vs 笛卡尔积 6 个)
```

**排序规则**（保持与现有优先级一致）:

| 排序维度 | 起始仓位 | 终点仓位 |
|:---|:---|:---|
| 主键 | bind_time 降序（最新绑定优先） | bay_id 字典序 |
| 次键 | src_bay 字典序 | — |
| 三级键 | cargo_type 优先级 | — |

**贪婪匹配伪代码**:

```
greedy_match(cargo_type):
    src_bays = bay_cache.get_bound_bays_of_type(cargo_type)
    dst_bays = dest_cache.get_empty_bays_of_type(cargo_type)
    
    # 排序
    src_bays.sort(key=lambda b: (-bind_time(b), b))
    dst_bays.sort()
    
    # 过滤锁定
    src_bays = [b for b in src_bays if b not in exclude_src]
    dst_bays = [b for b in dst_bays if b not in exclude_dst]
    
    # 贪婪配对
    n = min(len(src_bays), len(dst_bays), remaining_quota)
    for i in range(n):
        candidates.append(TaskCandidate(src_bays[i], dst_bays[i], cargo_type))
    
    return candidates
```

### 5.2 与笛卡尔积对比

| 维度 | 笛卡尔积 (当前) | 贪婪匹配 (优化) |
|:---|:---|:---|
| **候选数** | O(m × n) | O(min(m, n)) |
| **冗余率** | 50%~83% | 0% |
| **排序复杂度** | O(mn·log(mn)) | O(m·log m + n·log n) |
| **去重依赖** | 必须（后置过滤） | 天然无冲突 |
| **仓位利用率** | 由队列后置筛选 | 前置最优分配 |
| **AGV 负载均衡** | 仍依赖队列 try_dequeue | 同样依赖队列 |

**场景对比**:

```
场景: cargo_type=1, 3 src, 2 dst, 2 AGV

笛卡尔积:
  生成 6 候选 → 排序 6 条 → 入队 (去重后 2 条) → 出队 2 条
  候选中 4 条进入队列后立即被标记为重复

贪婪匹配:
  排序 src(3) + dst(2) → 配对 2 条 → 入队 2 条 → 出队 2 条
  无冗余，队列全程精确
```

### 5.4 代码实现

#### 5.4.1 `batch_matcher.py` — 新增 `greedy_scan_type()` 方法

```python
# batch_matcher.py — 在 TaskBatchMatcher 类中新增方法

def greedy_scan_type(self,
                     cargo_type: int,
                     exclude_src: set = None,
                     exclude_dst: set = None) -> List[TaskCandidate]:
    """贪婪匹配单个货物类型: 一对一配对, 每个仓位只参与一次

    Args:
        cargo_type: 货物类型
        exclude_src: 已锁定/已入队的起始仓位集合
        exclude_dst: 已锁定/已入队的终点仓位集合

    Returns:
        按优先级排序的候选任务列表 (≤ min(|src|, |dst|))
    """
    exclude_src = exclude_src or set()
    exclude_dst = exclude_dst or set()

    # 1. 获取该类型所有可用起始仓位
    available_src = self._bay_cache.get_bound_bays_of_type(
        cargo_type, exclude_in_task=True
    )
    available_src = [b for b in available_src if b not in exclude_src]
    if not available_src:
        return []

    # 2. 获取该类型所有空终点仓位
    empty_dst = self._dest_cache.get_empty_bays_of_type(cargo_type)
    empty_dst = [b for b in empty_dst if b not in exclude_dst]
    if not empty_dst:
        return []

    # 3. 分别排序
    #    起始仓位: bind_time 降序（最新绑定优先）→ bay_id 字典序
    src_with_times = []
    for src_bay in available_src:
        bay_status = self._bay_cache.get_bay_status(src_bay)
        bind_time = bay_status.get('bind_time', 0.0) if bay_status else 0.0
        src_with_times.append((src_bay, bind_time))
    src_with_times.sort(key=lambda x: (-x[1], x[0]))  # -bind_time 降序, bay_id 升序

    #    终点仓位: bay_id 字典序
    empty_dst.sort()

    # 4. 贪婪配对: src[i] ↔ dst[i]
    n = min(len(src_with_times), len(empty_dst))
    candidates = []
    for i in range(n):
        src_bay, bind_time = src_with_times[i]
        dst_bay = empty_dst[i]
        candidates.append(TaskCandidate(
            src_bay=src_bay,
            dst_bay=dst_bay,
            cargo_type=cargo_type,
            bind_time=bind_time,
        ))

    if self._logger and candidates:
        self._logger.debug(
            f"贪婪匹配 type={cargo_type}: "
            f"{len(available_src)} src × {len(empty_dst)} dst "
            f"→ {len(candidates)} 配对 "
            f"(排除 src={len(exclude_src)}, dst={len(exclude_dst)})"
        )

    return candidates
```

```python
# batch_matcher.py — 修改 batch_scan_all() 核心循环

def batch_scan_all(self,
                   max_tasks: int = 10,
                   exclude_src: set = None,
                   exclude_dst: set = None) -> List[TaskCandidate]:
    """批量扫描所有货物类型, 返回全部候选任务 (已排序)

    v2.0: 使用贪婪匹配替代笛卡尔积, 消除冗余候选。
    """
    exclude_src = exclude_src or set()
    exclude_dst = exclude_dst or set()
    all_candidates: List[TaskCandidate] = []

    for cargo_type in self._cargo_priority:
        if len(all_candidates) >= max_tasks:
            break

        # ★ 使用贪婪匹配代替笛卡尔积
        type_candidates = self.greedy_scan_type(
            cargo_type,
            exclude_src=exclude_src,
            exclude_dst=exclude_dst,
        )

        remaining = max_tasks - len(all_candidates)
        all_candidates.extend(type_candidates[:remaining])

    # 全局排序: 按 cargo_type 优先级
    all_candidates.sort(key=lambda c: c.key(self._cargo_priority))

    if self._logger:
        total_src = sum(1 for _ in all_candidates)  # 每个 candidate 一个 src
        self._logger.info(
            f"批量匹配完成 (贪婪): {len(all_candidates)} 候选任务 "
            f"(exclude_src={len(exclude_src)}, exclude_dst={len(exclude_dst)})"
        )

    return all_candidates[:max_tasks]
```

### 6.3 完整 `batch_matcher.py` 修改后文件

```python
#!/usr/bin/env python3
"""
TaskBatchMatcher — 批量仓位匹配器 (v2.0)

v2.0 升级:
  - 匹配算法: 笛卡尔积 → 贪婪匹配 (greedy)
  - 消除冗余候选, 每个仓位只参与一次配对
  - 保持优先级排序规则不变

职责:
  - 扫描所有已绑定起始仓位和空终点仓位
  - 贪婪匹配生成候选任务列表 (1:1 配对)
  - 按优先级规则排序
  - 去重 (排除已锁定/已在队列)
"""

import logging
from typing import List, Dict, Optional
from dataclasses import dataclass, field


@dataclass
class TaskCandidate:
    """候选任务 — 尚未锁定的匹配对"""
    src_bay: str
    dst_bay: str
    cargo_type: int
    bind_time: float = 0.0

    def key(self, cargo_priority: List[int]) -> tuple:
        """生成排序键"""
        try:
            type_rank = cargo_priority.index(self.cargo_type)
        except ValueError:
            type_rank = 99

        return (
            type_rank,         # 类型优先级
            self.src_bay,      # 起始仓位字母序
            self.dst_bay,      # 终点仓位字母序
            -self.bind_time,   # 绑定时戳大的优先 (负值 = 最新优先)
        )


class TaskBatchMatcher:
    """批量仓位匹配器 (v2.0 — 贪婪匹配)"""

    def __init__(self,
                 bay_cache,
                 dest_cache,
                 cargo_priority: List[int] = None,
                 logger: logging.Logger = None):
        """
        Args:
            bay_cache:     BayCache 实例
            dest_cache:    DestBayCache 实例
            cargo_priority: 货物类型优先级列表, 如 [1,2,3,4,5,6]
            logger:        日志记录器
        """
        self._bay_cache = bay_cache
        self._dest_cache = dest_cache
        self._cargo_priority = cargo_priority or list(range(1, 7))
        self._logger = logger

    # ════════════════════════════════════════════════════
    #  贪婪匹配
    # ════════════════════════════════════════════════════

    def greedy_scan_type(self,
                         cargo_type: int,
                         exclude_src: set = None,
                         exclude_dst: set = None) -> List[TaskCandidate]:
        """贪婪匹配单个货物类型: 一对一配对, 每个仓位只参加一次

        排序规则:
          起始仓位: bind_time 降序 (最新优先) → bay_id 字典序
          终点仓位: bay_id 字典序

        配对规则: src[i] ↔ dst[i]  (i = 0..min(|src|,|dst|)-1)

        Args:
            cargo_type: 货物类型
            exclude_src: 已锁定/已入队的起始仓位集合
            exclude_dst: 已锁定/已入队的终点仓位集合

        Returns:
            已排序的候选任务列表
        """
        exclude_src = exclude_src or set()
        exclude_dst = exclude_dst or set()

        # 1. 获取可用起始仓位
        available_src = self._bay_cache.get_bound_bays_of_type(
            cargo_type, exclude_in_task=True
        )
        available_src = [b for b in available_src if b not in exclude_src]
        if not available_src:
            return []

        # 2. 获取空终点仓位
        empty_dst = self._dest_cache.get_empty_bays_of_type(cargo_type)
        empty_dst = [b for b in empty_dst if b not in exclude_dst]
        if not empty_dst:
            return []

        # 3. 分别排序
        src_with_times = []
        for src_bay in available_src:
            bay_status = self._bay_cache.get_bay_status(src_bay)
            bind_time = bay_status.get('bind_time', 0.0) if bay_status else 0.0
            src_with_times.append((src_bay, bind_time))
        src_with_times.sort(key=lambda x: (-x[1], x[0]))

        empty_dst.sort()

        # 4. 贪婪配对
        n = min(len(src_with_times), len(empty_dst))
        candidates = []
        for i in range(n):
            src_bay, bind_time = src_with_times[i]
            dst_bay = empty_dst[i]
            candidates.append(TaskCandidate(
                src_bay=src_bay,
                dst_bay=dst_bay,
                cargo_type=cargo_type,
                bind_time=bind_time,
            ))

        if self._logger and candidates:
            self._logger.debug(
                f"贪婪匹配 type={cargo_type}: "
                f"{len(available_src)} src × {len(empty_dst)} dst "
                f"→ {len(candidates)} 配对"
            )

        return candidates

    # ════════════════════════════════════════════════════
    #  批量扫描 (v2.0)
    # ════════════════════════════════════════════════════

    def batch_scan_all(self,
                       max_tasks: int = 10,
                       exclude_src: set = None,
                       exclude_dst: set = None) -> List[TaskCandidate]:
        """批量扫描所有货物类型, 返回全部候选任务 (已排序)

        v2.0: 使用贪婪匹配替代笛卡尔积。
        """
        exclude_src = exclude_src or set()
        exclude_dst = exclude_dst or set()
        all_candidates: List[TaskCandidate] = []

        for cargo_type in self._cargo_priority:
            if len(all_candidates) >= max_tasks:
                break

            type_candidates = self.greedy_scan_type(
                cargo_type,
                exclude_src=exclude_src,
                exclude_dst=exclude_dst,
            )

            remaining = max_tasks - len(all_candidates)
            all_candidates.extend(type_candidates[:remaining])

        # 全局排序
        all_candidates.sort(key=lambda c: c.key(self._cargo_priority))

        if self._logger:
            self._logger.info(
                f"批量匹配完成 (贪婪): {len(all_candidates)} 候选任务 "
                f"(exclude_src={len(exclude_src)}, exclude_dst={len(exclude_dst)})"
            )

        return all_candidates[:max_tasks]

    def get_exclusion_sets(self, locked_src: set, locked_dst: set,
                           queued_src: set, queued_dst: set) -> tuple:
        """合并排除集合"""
        return (
            locked_src | queued_src,
            locked_dst | queued_dst,
        )
```
