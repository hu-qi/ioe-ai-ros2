### 1.2 插件依赖与加载顺序

`web_monitor` 依赖全部业务插件，必须最后加载：

```yaml
plugin_load_order: ["network", "callback_handler", "rcs_adapter", "bay_status_fusion",
                  "status_poller", "workflow_engine", "task_status_monitor", "smart_trigger",
                  "web_monitor"]
```

激活时 `web_monitor` 通过 `_get_plugin()` 延迟获取业务插件，避免启动顺序耦合；数据采集统一走公开方法，不访问私有成员（遵循 27 号文档约定）。

### 1.3 插件挂载与访问约定

```python

```python
# web_monitor_plugin.py — 新增辅助方法
def _get_plugin(self, name: str):
    """安全获取业务插件实例（优先节点挂载，其次插件管理器）"""
    plugin = getattr(self.node, name, None)
    if plugin is None and hasattr(self.node, 'plugin_manager'):
        plugin = self.node.plugin_manager.get_plugin(name)
    return plugin
```

### 2.3 web_server.py 新增路由代码

文件：`app_mgr_object/components/web/web_server.py`

在 `__init__` 末尾调用 `self._setup_business_routes()`，并新增方法（沿用本文件"嵌套函数 + @self.app 装饰器"风格）：

```python
    # ═══════════════════════════════════════════════════════
    # 业务可视化 / 配置热加载 / 任务操作 路由（v3.0）
    # ═══════════════════════════════════════════════════════
    def _setup_business_routes(self):
        """业务路由（在 __init__ 末尾调用一次）"""

        def _wm():
            """获取 web_monitor 插件实例"""
            wm = getattr(self.node, 'web_monitor', None)
            if wm is None and hasattr(self.node, 'plugin_manager'):
                wm = self.node.plugin_manager.get_plugin('web_monitor')
            return wm

        def _not_loaded():
            return JSONResponse(content={'success': False, 'error': 'web_monitor 未加载'})

        # ── 只读业务状态 ──
        @self.app.get("/api/bay/status")
        def api_bay_status():
            wm = _wm()
            return JSONResponse(content=wm.get_bay_status() if wm else _not_loaded())

        @self.app.get("/api/dest/status")
        def api_dest_status():
            wm = _wm()
            return JSONResponse(content=wm.get_dest_status() if wm else _not_loaded())

        @self.app.get("/api/agv/status")
        def api_agv_status():
            wm = _wm()
            return JSONResponse(content=wm.get_agv_status() if wm else _not_loaded())

        @self.app.get("/api/task/queue")
        def api_task_queue():
            wm = _wm()
            return JSONResponse(content=wm.get_task_queue() if wm else _not_loaded())

        @self.app.get("/api/task/instances")
        def api_task_instances():
            wm = _wm()
            return JSONResponse(content=wm.get_workflow_instances() if wm else _not_loaded())

        @self.app.get("/api/task/stats")
        def api_task_stats():
            wm = _wm()
            return JSONResponse(content=wm.get_task_stats() if wm else _not_loaded())

        @self.app.get("/api/task/history")
        def api_task_history(limit: int = 50, offset: int = 0, state: str = ''):
            wm = _wm()
            if not wm:
                return _not_loaded()
            return JSONResponse(content=wm.get_task_history(limit, offset, state))

        @self.app.get("/api/trigger/status")
        def api_trigger_status():
            wm = _wm()
            return JSONResponse(content=wm.get_trigger_status() if wm else _not_loaded())

        @self.app.get("/api/business/summary")
        def api_business_summary():
            wm = _wm()
            return JSONResponse(content=wm.collect_business_status() if wm else _not_loaded())

        # ── 配置读写（热加载） ──
        CONFIG_GETTERS = {
            'bay': 'get_bay_config',
            'dest': 'get_dest_config',
            'schedule': 'get_schedule_config',
            'pairs': 'get_pair_overrides',
            'params': 'get_params_config',
        }
        CONFIG_SECTIONS = {
            'bay': 'bay_configs',
            'dest': 'dest_bay_configs',
            'schedule': 'work_schedule',
            'pairs': 'pair_overrides',
        }

        @self.app.get("/api/config/{name}")
        def api_get_config(name: str):
            wm = _wm()
            if not wm:
                return _not_loaded()
            getter = CONFIG_GETTERS.get(name)
            if not getter or not hasattr(wm, getter):
                return JSONResponse(content={'success': False, 'error': f'未知配置: {name}'})
            return JSONResponse(content=getattr(wm, getter)())

        @self.app.put("/api/config/{name}")
        async def api_put_config(name: str, request: Request):
            wm = _wm()
            if not wm:
                return _not_loaded()
            section = CONFIG_SECTIONS.get(name)
            if not section:
                return JSONResponse(content={'success': False, 'error': f'未知配置: {name}'})
            data = await request.json()
            value = data.get('mappings', data) if name != 'params' else data.get('params', {})
            result = wm.apply_config(section, value)
            return JSONResponse(content=result)

        # ── 任务人工操作 ──
        @self.app.post("/api/task/control")
        async def api_task_control(request: Request):
            wm = _wm()
            if not wm:
                return _not_loaded()
            data = await request.json()
            result = wm.task_control(
                operation=data.get('operation', ''),
                task_id=data.get('task_id', ''),
                src_bay=data.get('src_bay', ''),
                dst_bay=data.get('dst_bay', ''),
                robot_id=int(data.get('robot_id') or 0),
                cargo_type=int(data.get('cargo_type') or 1),
            )
            return JSONResponse(content=result)
```

> 说明：通用参数 PUT `/api/config/params` 走 `apply_config('params', ...)`，见 3.2。

### 2.4 web_monitor_plugin.py 业务采集方法

文件：`app_mgr_object/plugins/web_monitor_plugin.py`（新增以下方法）

```python
    # ═══════════════════════════════════════════════════════
    # 业务数据采集（v3.0，全部走公开接口）
    # ═══════════════════════════════════════════════════════

    def get_bay_status(self) -> dict:
        """采集起始仓位状态（BayCache）"""
        try:
            fusion = self._get_plugin('bay_status_fusion')
            if not fusion or not fusion.cache:
                return {'bays': [], 'total': 0}
            bays = fusion.cache.get_all_bay_status()
            now = time.time()
            result, by_type = [], {}
            for bid, bay in bays.items():
                ct = bay.get('cargo_type', 0)
                by_type.setdefault(str(ct), {'total': 0, 'bound': 0, 'available': 0})
                by_type[str(ct)]['total'] += 1
                if bay.get('bind_status') == 1:
                    by_type[str(ct)]['bound'] += 1
                    if not bay.get('in_task'):
                        by_type[str(ct)]['available'] += 1
                result.append({
                    'bay_id': bay['bay_id'],
                    'cargo_type': ct,
                    'bind_status': bay.get('bind_status', 0),
                    'bind_status_label': {0: '未绑定', 1: '已绑定', 2: '绑定中'}.get(
                        bay.get('bind_status', 0), '未知'),
                    'ai_detected': bay.get('ai_detected', False),
                    'in_task': bay.get('in_task', False),
                    'bind_time': bay.get('bind_time', 0),
                    'bind_duration': round(now - bay.get('bind_time', now), 1)
                        if bay.get('bind_status') == 1 else 0,
                    'last_seen': bay.get('last_seen', 0),
                })
            return {
                'timestamp': now, 'total': len(result),
                'bound_count': sum(1 for b in result if b['bind_status'] == 1),
                'in_task_count': sum(1 for b in result if b['in_task']),
                'by_type': by_type, 'bays': result,
            }
        except Exception as e:
            self.logger.error(f"采集起始仓位状态失败: {e}")
            return {'bays': [], 'total': 0, 'error': str(e)}

    def get_dest_status(self) -> dict:
        """采集终点仓位状态（DestBayCache）"""
        try:
            poller = self._get_plugin('status_poller')
            if not poller or not poller.dest_cache:
                return {'bays': [], 'total': 0}
            bays = poller.dest_cache.get_all_bay_status()
            result, by_floor = [], {}
            for bid, bay in bays.items():
                floor = bay.get('floor_no', 0)
                by_floor.setdefault(str(floor), {'total': 0, 'empty': 0})
                by_floor[str(floor)]['total'] += 1
                if bay.get('is_empty'):
                    by_floor[str(floor)]['empty'] += 1
                result.append({
                    'bay_id': bay['bay_id'],
                    'cargo_type': bay.get('cargo_type', 0),
                    'floor_no': floor,
                    'is_empty': bay.get('is_empty', True),
                    'update_time': bay.get('update_time', 0),
                })
            return {
                'timestamp': time.time(), 'total': len(result),
                'empty_count': sum(1 for b in result if b['is_empty']),
                'by_floor': by_floor, 'bays': result,
            }
        except Exception as e:
            self.logger.error(f"采集终点仓位状态失败: {e}")
            return {'bays': [], 'total': 0, 'error': str(e)}

    def get_agv_status(self) -> dict:
        """采集 AGV 状态（RobotCache）"""
        try:
            poller = self._get_plugin('status_poller')
            if not poller or not poller.robot_cache:
                return {'robots': [], 'available_count': 0}
            robots = poller.robot_cache.get_all_robot_status()
            result = [{
                'robot_id': rid, 'status': r.get('status', 'OFFLINE'),
                'battery': r.get('battery', 0), 'position_code': r.get('position_code', ''),
                'current_task_id': r.get('current_task_id', ''),
                'update_time': r.get('update_time', 0),
            } for rid, r in robots.items()]
            return {
                'timestamp': time.time(),
                'available_count': sum(1 for r in result if r['status'] == 'AVAILABLE'),
                'busy_count': sum(1 for r in result if r['status'] == 'BUSY'),
                'robots': result,
            }
        except Exception as e:
            self.logger.error(f"采集 AGV 状态失败: {e}")
            return {'robots': [], 'available_count': 0}

    def get_task_queue(self) -> dict:
        """采集任务队列状态（TaskQueue + 资源锁）"""
        try:
            trigger = self._get_plugin('smart_trigger')
            if not trigger or not getattr(trigger, '_task_queue', None):
                return {'queue_size': 0, 'queued_tasks': []}
            stats = trigger._task_queue.get_stats()
            engine = trigger._trigger_engine
            return {
                'queue_size': stats.get('queue_size', 0),
                'enqueue_count': stats.get('enqueue_count', 0),
                'dequeue_count': stats.get('dequeue_count', 0),
                'skip_duplicate_count': stats.get('skip_duplicate_count', 0),
                'aged_out_count': stats.get('aged_out_count', 0),
                'oldest_wait': stats.get('oldest_wait', 0),
                'queued_tasks': [
                    {'src_bay': c.src_bay, 'dst_bay': c.dst_bay,
                     'cargo_type': c.cargo_type, 'enqueue_time': c.enqueue_time}
                    for c in trigger._task_queue._queue
                ],
                'locked_resources': engine.get_locked_count() if engine else {},
            }
        except Exception as e:
            self.logger.error(f"采集任务队列失败: {e}")
            return {'queue_size': 0, 'queued_tasks': []}

    def get_workflow_instances(self) -> dict:
        """采集活跃工作流实例（WorkflowEngine 公开 API）"""
        try:
            wf = self._get_plugin('workflow_engine')
            if not wf:
                return {'active_count': 0, 'by_state': {}, 'instances': []}
            engine = wf.get_engine()
            by_state, instances = {}, []
            for task_id, snap in engine.get_active_instances().items():
                state = snap['current_state']
                by_state[state] = by_state.get(state, 0) + 1
                instances.append({

## 3. 参数热加载机制设计

### 3.1 热加载链路

```
Web 配置页 ──PUT /api/config/{name}──▶ web_monitor.apply_config()
    │  ① 业务校验（类型/取值/仓位存在性）
    ▼
param_manager.update_plugin_config_section(section, value)
    │  ② 备份 params.yaml → 更新 plugin_configs 段 → 写回
    │  ③ ROS2 set_parameters('plugin_configs') ──▶ _on_parameters_changed
    │                                              └─▶ 分发注册回调（热加载基础）
    ▼
web_monitor reload_handlers（内存应用）
    │  bay_cache.reload_config / dest_cache.reload_config
    │  trigger_engine.set_schedules / set_pair_overrides / set_cargo_priority
    ▼
EventBus: config.updated ──▶ WebSocket: config_updated（前端提示）
```

两条热加载路径：

1. **plugin_configs 段级热加载**（仓位映射/工作时段/配对/优先级）：`update_plugin_config_section` 持久化 + `apply_config` 内存应用；
2. **顶层 ROS2 参数热加载**（log_level/超时/轮询间隔等）：`set_param_and_persist` + `_on_parameters_changed` 分发回调，消费方在每轮循环 `get_param` 自动生效；需要重建资源（如轮询定时器）的参数，由插件注册回调处理。

```python
    # ---------- 配置热加载（v3.0） ----------

    def _get_params_yaml_path(self) -> str:
        """获取 params.yaml 绝对路径（支持 config_file 参数覆盖）"""
        import os
        override = self.get_param('config_file', '')
        if override:
            return override
        try:
            from ament_index_python.packages import get_package_share_directory
            pkg_share = get_package_share_directory('app_mgr_object')
            return os.path.join(pkg_share, 'config', 'params.yaml')
        except Exception:
            return os.path.join(os.getcwd(), 'config', 'params.yaml')

    def _read_yaml(self, path: str) -> dict:
        with open(path, 'r', encoding='utf-8') as f:
            return yaml.safe_load(f) or {}

    def _backup_and_write_yaml(self, path: str, config: dict) -> None:
        """写回前备份，避免写坏导致重启失败"""
        import shutil
        bak = f"{path}.bak"
        try:
            shutil.copyfile(path, bak)
        except Exception:
            pass
        with open(path, 'w', encoding='utf-8') as f:
            yaml.dump(config, f, allow_unicode=True, default_flow_style=False)

    def update_plugin_config_section(self, section: str, new_value: Any) -> bool:
        """更新 plugin_configs 指定段并写回 params.yaml，同时同步 ROS2 参数。

        Args:
            section: plugin_configs 下的配置段名，如 bay_configs / work_schedule
            new_value: 新配置值（dict/list）
        """
        try:
            path = self._get_params_yaml_path()
            config = self._read_yaml(path)
            app = config.setdefault('app_mgr_object', {}) \
                        .setdefault('ros__parameters', {})
            raw = app.get('plugin_configs', '{}')
            if isinstance(raw, str):
                plugin_configs = yaml.safe_load(raw) or {}
            else:
                plugin_configs = raw or {}
            plugin_configs[section] = new_value

            new_plugin_str = yaml.dump(plugin_configs, allow_unicode=True,
                                       default_flow_style=False)
            app['plugin_configs'] = new_plugin_str
            self._backup_and_write_yaml(path, config)

            # 同步 ROS2 参数，触发 _on_parameters_changed（含回调分发）
            param = rclpy.Parameter('plugin_configs', value=new_plugin_str)
            self.node.set_parameters([param])
            self._params['plugin_configs'] = plugin_configs
            self.logger.info(f"配置段热加载已触发: {section}")
            return True
        except Exception as e:
            self.logger.error(f"更新配置段 {section} 失败: {e}")
            return False

    def set_param_and_persist(self, name: str, value: Any) -> bool:
        """设置顶层 ROS2 参数（运行时生效）并持久化到 params.yaml（重启保留）"""
        try:
            if not self.update_param(name, value):
                return False
            path = self._get_params_yaml_path()
            config = self._read_yaml(path)
            app = config.setdefault('app_mgr_object', {}) \
                        .setdefault('ros__parameters', {})
            app[name] = value
            self._backup_and_write_yaml(path, config)
            return True
        except Exception as e:
            self.logger.error(f"参数持久化失败 {name}: {e}")
            return False
```

    def _register_reload_handlers(self):
        """配置段 → 内存应用函数 注册表"""
        self._reload_handlers = {
            'bay_configs': self._apply_bay_configs,
            'dest_bay_configs': self._apply_dest_configs,
            'work_schedule': self._apply_work_schedule,
            'pair_overrides': self._apply_pair_overrides,
            'cargo_priority': self._apply_cargo_priority,
        }

    def apply_config(self, section: str, value: Any) -> dict:
        """通用配置热加载入口：校验 → 持久化 → 内存应用 → 广播"""
        try:
            handler = self._reload_handlers.get(section)
            if not handler:
                return {'success': False, 'error': f'不支持的配置段: {section}'}

            error = self._validate_section(section, value)
            if error:
                return {'success': False, 'error': error}

            pm = getattr(self.node, 'param_manager', None)
            if pm is None or not pm.update_plugin_config_section(section, value):
                return {'success': False, 'error': '配置持久化失败（已保留原值）'}

            handler(value)
            self._publish_event('config.updated', {'section': section})
            self._broadcast_message({
                'type': 'config_updated', 'section': section,
                'timestamp': time.time(),
            })
            return {'success': True, 'message': f'配置段 {section} 已更新并热加载',
                    'hot_reload': True}
        except Exception as e:
            self.logger.error(f"apply_config 失败 [{section}]: {e}")
            return {'success': False, 'error': str(e)}

    def _validate_section(self, section: str, value: Any) -> str:
        """配置业务校验，返回错误信息（空串=通过）"""
        if section == 'bay_configs':
            if not isinstance(value, dict):
                return 'bay_configs 必须是 {bay_id: cargo_type} 字典'
            for bid, ct in value.items():
                if int(ct) not in range(1, 7):
                    return f'{bid}: cargo_type 必须为 1~6，收到 {ct}'
            return ''
        if section == 'dest_bay_configs':
            if not isinstance(value, dict):
                return 'dest_bay_configs 必须是 {bay_id: {cargo_type, floor}} 字典'
            for bid, cfg in value.items():
                if int(cfg.get('cargo_type', 0)) not in range(1, 7):
                    return f'{bid}: cargo_type 必须为 1~6'
            return ''
        if section == 'work_schedule':
            if not isinstance(value, list):
                return 'work_schedule 必须是列表'
            for s in value:
                if not all(k in s for k in ('day_of_week', 'start_time', 'end_time')):
                    return f'工作时段缺少字段: {s}'
            return ''
        if section == 'pair_overrides':
            if not isinstance(value, dict):
                return 'pair_overrides 必须是 {src_bay: dst_bay} 字典'
            return ''
        if section == 'cargo_priority':
            if not isinstance(value, list) or not value:
                return 'cargo_priority 必须是非空列表'
            return ''
        return ''

    def _apply_bay_configs(self, mappings: dict):
        """内存应用：起始仓位映射（cargo_type）"""
        fusion = self._get_plugin('bay_status_fusion')
        if fusion and fusion.cache:
            fusion.cache.reload_config(mappings)
        trigger = self._get_plugin('smart_trigger')
        if trigger and getattr(trigger, '_config_cache', None):
            trigger._config_cache.set_source_mapping(mappings)
        self.logger.info(f"起始仓位映射热加载: {len(mappings)} 个")

    def _apply_dest_configs(self, mappings: dict):
        """内存应用：终点仓位映射（cargo_type/floor）"""
        poller = self._get_plugin('status_poller')
        if poller and poller.dest_cache:
            poller.dest_cache.reload_config(mappings)
        trigger = self._get_plugin('smart_trigger')
        if trigger and getattr(trigger, '_config_cache', None):
            trigger._config_cache.set_dest_mapping(mappings)
        self.logger.info(f"终点仓位映射热加载: {len(mappings)} 个")

    def _apply_work_schedule(self, schedules: list):
        """内存应用：工作时段"""
        trigger = self._get_plugin('smart_trigger')
        if trigger and trigger._trigger_engine:
            trigger._trigger_engine.set_schedules(schedules)
        if trigger and getattr(trigger, '_config_cache', None):
            trigger._config_cache.set_schedules(schedules)
        self.logger.info(f"工作时段热加载: {len(schedules)} 条")

    def _apply_pair_overrides(self, overrides: dict):
        """内存应用：源→目的显式配对覆盖"""
        trigger = self._get_plugin('smart_trigger')
        if trigger and trigger._trigger_engine:
            trigger._trigger_engine.set_pair_overrides(overrides)
        self.logger.info(f"配对覆盖热加载: {len(overrides)} 条")

    def _apply_cargo_priority(self, priority: list):

        if trigger and trigger._trigger_engine:
            trigger._trigger_engine.set_cargo_priority(priority)
        self.logger.info(f"货物优先级热加载: {priority}")

### 3.4 仓位配对覆盖（pair_overrides）

业务语义：生产按批调整时，指定"起始仓位 X 只配目的仓位 Y"；未覆盖的仓位仍按 cargo_type 贪婪匹配。

#### 3.4.1 batch_matcher.py 支持显式配对

```python
class TaskBatchMatcher:
    def __init__(self, bay_cache, dest_cache,
                 cargo_priority: List[int] = None,
                 logger: logging.Logger = None,
                 pair_overrides: Dict[str, str] = None):
        ...
        self._pair_overrides: Dict[str, str] = dict(pair_overrides or {})

    def set_pair_overrides(self, pair_overrides: dict):
        """热加载：源→目的显式配对覆盖（空字典 = 全部按类型贪婪匹配）"""
        self._pair_overrides = dict(pair_overrides or {})

    def set_cargo_priority(self, cargo_priority: list):
        self._cargo_priority = list(cargo_priority or range(1, 7))

    def greedy_scan_type(self, cargo_type, exclude_src=None, exclude_dst=None):
        exclude_src = exclude_src or set()
        exclude_dst = exclude_dst or set()

        available_src = self._bay_cache.get_bound_bays_of_type(
            cargo_type, exclude_in_task=True)
        available_src = [b for b in available_src if b not in exclude_src]
        empty_dst = self._dest_cache.get_empty_bays_of_type(cargo_type)
        empty_dst = [d for d in empty_dst if d not in exclude_dst]
        if not available_src or not empty_dst:
            return []

        candidates = []
        used_src, used_dst = set(), set()

        # 1) 显式配对覆盖（源→目的，按用户配置）
        for src_bay in list(available_src):
            override_dst = self._pair_overrides.get(src_bay)
            if (override_dst and override_dst in empty_dst
                    and override_dst not in used_dst):
                bay_status = self._bay_cache.get_bay_status(src_bay) or {}
                candidates.append(TaskCandidate(
                    src_bay=src_bay, dst_bay=override_dst,
                    cargo_type=cargo_type,
                    bind_time=bay_status.get('bind_time', 0.0)))
                used_src.add(src_bay)
                used_dst.add(override_dst)

        # 2) 剩余仓位贪婪配对（原有逻辑）
        remaining_src = [s for s in available_src if s not in used_src]
        remaining_dst = [d for d in empty_dst if d not in used_dst]
        src_with_times = []
        for src_bay in remaining_src:
            bay_status = self._bay_cache.get_bay_status(src_bay) or {}
            src_with_times.append((src_bay, bay_status.get('bind_time', 0.0)))
        src_with_times.sort(key=lambda x: (-x[1], x[0]))
        remaining_dst.sort()
        for i in range(min(len(src_with_times), len(remaining_dst))):
            src_bay, bind_time = src_with_times[i]
            dst_bay = remaining_dst[i]
            candidates.append(TaskCandidate(
                src_bay=src_bay, dst_bay=dst_bay,
                cargo_type=cargo_type, bind_time=bind_time))
        return candidates
```

    # ═══════════════════════════════════════════════════════
    def task_control(self, operation: str, task_id: str = '',
                     src_bay: str = '', dst_bay: str = '',
                     robot_id: int = 0, cargo_type: int = 1) -> dict:
        """Web 人工操作：retry / cancel / force_trigger / continue / query"""
        import asyncio
        wf = self._get_plugin('workflow_engine')
        if not wf:
            return {'success': False, 'error': '工作流引擎未加载'}
        engine = wf.get_engine()
        loop = self.node.asyncio_loop

            if operation == 'query':

                    return {'success': True, 'task_id': task_id, **snap}

                    engine.inject_event(task_id, event, {'source': 'web'}), loop)
                future.result(timeout=5)
                return {'success': True, 'task_id': task_id,
                        'operation': operation,
                        'message': f'{operation} 命令已发送: {task_id}'}

            if operation == 'force_trigger':
                if not src_bay or not dst_bay:
                    return {'success': False, 'error': 'force_trigger 需要 src_bay 和 dst_bay'}
                import time as _t
                new_id = f"WEB_{int(_t.time() * 1000)}"
                ctx = {'task_id': new_id, 'src_bay': src_bay, 'dst_bay': dst_bay,
                       'robot_id': robot_id or 0, 'cargo_type': cargo_type or 1}
                future = asyncio.run_coroutine_threadsafe(
                    engine.create_instance('agv_transport_atomic', ctx), loop)
                future.result(timeout=5)
                return {'success': True, 'task_id': new_id,
                        'operation': 'force_trigger'}

            if operation == 'continue':
                snap = engine.get_instance_snapshot(task_id) or {}
                rcs_no = snap.get('rcs_task_no', '')
                if not rcs_no:
                    return {'success': False, 'error': f'无 RCS 任务号: {task_id}'}
                rcs = self._get_plugin('rcs_adapter')
                if not rcs:
                    return {'success': False, 'error': 'RCS 适配器未加载'}
                resp = rcs.continue_task(rcs_no)
                return {'success': resp.get('code') == '0',
                        'message': resp.get('msg', ''), 'task_id': task_id}

            return {'success': False, 'error': f'不支持的操作: {operation}'}
        except Exception as e:
            return {'success': False, 'error': str(e)}
```

### 3.7 安全与健壮性

- **部署环境强制认证**：`auth_required: true` 时，配置写入与任务操作端点要求登录（现有 WebServer 认证扩展点接入）；
- **操作白名单**：`/api/task/control` 仅允许 retry/cancel/force_trigger/continue/query，force_trigger 需二次确认；
- **写前备份**：每次写 params.yaml 前自动生成 `.bak`，写坏可回滚；
- **校验前置**：cargo_type 1~6、仓位存在性、工作时段字段完整性在持久化前校验；
- **失败降级**：内存应用失败时保留 YAML 原值并在响应中返回错误（由前端 Toast 提示）。

// api.js — 统一 API 客户端 + WebSocket 订阅
const Api = {
    async get(url) {
        const resp = await fetch(url);
        return resp.json();
    },
    async put(url, body) {
        const resp = await fetch(url, {
            method: 'PUT',
            headers: {'Content-Type': 'application/json'},
            body: JSON.stringify(body)
        });
        return resp.json();
    },
    async post(url, body) {
        const resp = await fetch(url, {
            method: 'POST',
            headers: {'Content-Type': 'application/json'},
            body: JSON.stringify(body)
        });
        return resp.json();
    },
    // WebSocket 订阅：type 为 'business_update' / 'full_status' / 'config_updated'
    connectWS(handlers) {
        const ws = new WebSocket(`ws://${location.host}/ws`);
        ws.onmessage = (evt) => {
            try {
                const msg = JSON.parse(evt.data);
                const fn = handlers[msg.type];
                if (fn) fn(msg.data || msg);
            } catch (e) { /* ignore malformed */ }
        };
        ws.onopen = () => setInterval(() => ws.send('ping'), 30000);
        return ws;
    }
};
```

### 6.3 回滚说明

- 实施前对上述 16 个文件保存基线；
- Phase 1 可独立合入并单独回归（纯只读展示，无风险）；
- Phase 2 涉及写 params.yaml：启用自动备份 `.bak`，写坏时用备份恢复后重启；
- Phase 3 操作均需二次确认，且只通过引擎公开 API 注入事件，不影响状态机一致性；
- 全部新 API 在 `web_monitor` 未启用时返回 `{"success": false, "error": "web_monitor 未加载"}`，不影响既有功能。
