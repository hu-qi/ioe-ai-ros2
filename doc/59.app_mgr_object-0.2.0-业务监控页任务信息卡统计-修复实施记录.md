## 3. 代码变更说明

### 3.1 后端（business_collector.py `get_task_statistics`）

- 新增返回字段：`ready`（bool，数据源是否就绪）、`source`（'workflow_engine'）、`last_error`（未就绪/异常原因）；
- 未加载：`return dict(empty, ready=False, source='workflow_engine', last_error='workflow_engine 未加载')` + `logger.warning`；
- 未激活：`last_error='workflow_engine 未激活'` + `logger.warning`；
- 异常：`return dict(empty, ready=False, source='workflow_engine', last_error=str(e))` + `logger.error`；
- 正常：`return {..., 'ready': True, 'source': 'workflow_engine', 'last_error': ''}`。

### 3.2 前端（dashboard.js `renderTaskStats`）

```js
if (stats.ready === false) {                       // 数据源未就绪
    el.innerHTML = '<div class="ts-empty">统计初始化中…（数据源未就绪）</div>';
    return;
}
if (stats.error) {                                 // 接口异常
    el.innerHTML = '<div class="ts-empty">暂无任务统计</div>';
    return;
}
function _num(v) { return (v == null) ? 0 : v; }   // null 安全
// 正常渲染：今日完成 / 执行中(pulse) / 异常(error) / 已锁定目的仓(locked)
```

> 兼容性：旧后端无 `ready` 字段时 `stats.ready === false` 不成立，走正常渲染，行为与现状一致。
