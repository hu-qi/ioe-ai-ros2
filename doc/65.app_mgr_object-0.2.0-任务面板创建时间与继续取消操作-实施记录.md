## 1. 实施概述

| 项 | 现状（问题） | 改动 | 结果 |
|---|---|---|---|
| 创建时间 | 后端 `get_active_instances` 硬编码 `created_at=''`（business_collector.py）→ 前端恒显示 `--` | `WorkflowInstance` 暴露 `start_time`；engine 透传 `created_at`；business_collector 格式化为本地时间字符串 | ✅ 活跃任务显示真实创建时间戳 |
| 继续按钮 | 前端依赖 `t.rcs_task_no` 才显示，但后端**未透传 rcs_task_no** → 继续按钮永不显示（只剩查询/取消） | business_collector 透传 `rcs_task_no`；前端继续按钮**常显**（无 RCS 任务号时由后端提示） | ✅ 操作列 = 查询 + 继续 + 取消 |
| 按钮图标 | 沿用工程 `btn-outline btn-sm` 风格 | 查询 `fa-search`、继续 `fa-play`（绿）、取消 `fa-times`（红） | ✅ 与既有 UI 一致 |

## 3. 代码变更说明

### 3.1 后端透传

```python
# instance.py
@property
def start_time(self) -> float:
    """实例创建时间戳（秒）"""
    return self._start_time

# engine.py get_active_instances
'rcs_task_no': inst.context.get('rcs_task_no', ''),
'created_at': inst.start_time,
'src_bay': inst.context.get('src_bay', ''),

# business_collector.py get_active_instances（主分支）
'rcs_task_no': snap.get('rcs_task_no', ''),
'created_at': (time.strftime('%Y-%m-%d %H:%M:%S',
    time.localtime(snap.get('created_at') or 0))
    if snap.get('created_at') else ''),
```

### 3.2 前端（dashboard.js renderActiveTasks）

- 创建时间列：`t.created_at || '--'`（后端补数据后自然显示本地时间）；
- 操作列（常显三个按钮，图标符合既有 btn-outline btn-sm 风格）：

```js
// 查询
'... title="查询"><i class="fas fa-search"></i>...'
// 继续（常显；无 RCS 任务号时 task_controller 返回“无 RCS 任务号”提示）
'... color:var(--accent-green);" title="继续执行（RCS continueTask）"><i class="fas fa-play"></i>...'
// 取消
'... color:var(--accent-red);" title="取消任务（释放资源）"><i class="fas fa-times"></i>...'
```
