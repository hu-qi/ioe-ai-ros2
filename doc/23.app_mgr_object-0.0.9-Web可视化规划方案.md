## 1. 现状诊断

### 1.1 当前 Web 能力矩阵

| 能力 | 现状 | 数据来源 |
|:---|:---|:---|
| 系统健康概览 | ✓ 已实现 | StatusMonitor (psutil, netifaces) |
| ROS2 节点状态 | ✓ 已实现 | StatusMonitor (ros2 node list) |
| 通道信号状态 | ✓ 已实现 | StatusMonitor (HTTP callback) |
| 系统负载 (CPU/内存/磁盘) | ✓ 已实现 | StatusMonitor (psutil) |
| WebSocket 实时推送 | ✓ 已实现 | ConnectionManager |
| 告警管理 | ✓ 已实现 | AlarmManager |
| 运维控制 (重启/启动) | ✓ 已实现 | ControlExecutor |
| 图片/标定 | ✓ 已实现 | InferenceImageManager |
| **起始仓位状态** | ✗ **缺失** | BayCache (bay_status_fusion) |
| **终点仓位状态** | ✗ **缺失** | DestBayCache (status_poller) |
| **AGV 实时状态** | ✗ **缺失** | RobotCache (status_poller) |
| **任务队列状态** | ✗ **缺失** | TaskQueue (smart_trigger) |
| **工作流实例状态** | ✗ **缺失** | WorkflowEngine (workflow_engine) |
| **任务终态分布** | ✗ **缺失** | WorkflowPersistence (SQLite) |
| **计数器/吞吐量** | ✗ **缺失** | 各插件统计字段 |

### 1.2 根因分析

**web_monitor_plugin.py** 的核心问题：

```python
# web_monitor_plugin.py — 当前数据采集逻辑
# 只通过 StatusMonitor 采集系统级数据，从未访问业务插件

# 缺失的连接（代码中完全不存在）:
#   self.node.plugin_manager.get_plugin('bay_status_fusion')
#   self.node.plugin_manager.get_plugin('status_poller')
#   self.node.plugin_manager.get_plugin('smart_trigger')
#   self.node.plugin_manager.get_plugin('workflow_engine')
#   self.node.plugin_manager.get_plugin('task_status_monitor')
```

**web_server.py** 只有一个业务无关的 API 端点：

```python
# 当前唯一的状态 API
@app.get("/api/status")   →  返回系统健康度 / 节点 / 通道 / 服务 / 负载

# 缺失的端（完全不存在）:
#   /api/bay/status       →  起始仓位状态
#   /api/dest/status      →  终点仓位状态
#   /api/agv/status       →  AGV 状态
#   /api/task/queue       →  任务队列
#   /api/task/instances   →  工作流实例
#   /api/task/stats       →  任务统计
#   /api/task/history     →  历史任务
#   /api/trigger/status   →  触发器状态
```

### 1.3 已有数据的可访问性

业务数据技术上是可访问的 — 各插件维护了内存缓存并暴露了 `get_*()` 方法：

| 数据 | 所在插件 | 可访问方法 | 状态 |
|:---|:---|:---|:---|
| 起始仓位 | bay_status_fusion | `.cache.get_all_bay_status()` | ✓ 数据就绪 |
| 终点仓位 | status_poller | `.dest_cache.get_all_bay_status()` | ✓ 数据就绪 |
| AGV 状态 | status_poller | `.robot_cache.get_all_robot_status()` | ✓ 数据就绪 |
| 任务队列 | smart_trigger | `._task_queue.get_stats()` | ✓ 数据就绪 |
| 活跃实例 | workflow_engine | `._engine.get_active_count()` 等 | ✓ 数据就绪 |
| 历史任务 | workflow_engine | `._engine._persistence.get_all_instances()` | ✓ 数据就绪 |
| 触发统计 | smart_trigger | `.get_status()` | ✓ 数据就绪 |
| 轮询统计 | task_monitor | `.get_status()` | ✓ 数据就绪 |

**关键结论**：数据全在内存中，缺的是采集层→API 层→展示层的"管道"。

### 2.2 各数据块的字段详细

#### 起始仓位 (BayCache) — 24 个仓位

| 字段 | 类型 | 说明 | 可视化用途 |
|:---|:---|:---|:---|
| `bay_id` | str | A1001~D1006 | 仓位编号标签 |
| `cargo_type` | int | 1~6 | 颜色分类 |
| `ai_detected` | bool | AI 是否检测到货 | 底纹/图标指示 |
| `bind_status` | int | 0=未绑定, 1=已绑定, 2=绑定中 | 状态色块 |
| `in_task` | bool | 是否已被分配任务 | 锁定图标 |
| `bind_time` | float | 绑定时间戳 | 等待时长计算 |
| `last_seen` | float | 最后检测时间 | 超时告警 |

#### 终点仓位 (DestBayCache) — 18 个仓位

| 字段 | 类型 | 说明 | 可视化用途 |
|:---|:---|:---|:---|
| `bay_id` | str | T2001~T4006 | 仓位编号标签 |
| `cargo_type` | int | 1~6 | 颜色分类 |
| `floor_no` | int | 2~4 | 楼层分组 |
| `is_empty` | bool | True=可接受任务 | 空/满图标 |
| `update_time` | float | 最后更新时间 | 超时告警 |

#### AGV 状态 (RobotCache) — 2 台

| 字段 | 类型 | 说明 | 可视化用途 |
|:---|:---|:---|:---|
| `robot_id` | int | 1001/1002 | AGV 编号 |
| `status` | str | AVAILABLE/BUSY/OFFLINE/ERROR | 状态灯 |
| `current_task_id` | str | 当前执行任务号 | 任务关联 |
| `battery` | int | 0~100 | 电量条 |
| `position_code` | str | 位置编码 | 位置指示 |

#### 任务队列 (TaskQueue)

| 字段 | 说明 | 可视化用途 |
|:---|:---|:---|
| `queue_size` | 当前排队数 | 队列长度计数器 |
| `enqueue_count` | 累计入队数 | 吞吐量指标 |
| `dequeue_count` | 累计出队数 | 吞吐量指标 |
| `skip_duplicate_count` | 跳过去重数 | 冗余指标 |
| `queued_src` | 排队中起点集合 | 冲突检测 |

#### 工作流实例状态

| 字段 | 说明 | 可视化用途 |
|:---|:---|:---|
| `task_id` | 任务唯一 ID | 标识 |
| `current_state` | calling_rcs/monitoring/warn_pause/... | 状态流图高亮 |
| `status` | running/completed/failed/cancelled | 终态标识 |
| `src_bay` | 起始仓位 | 关联显示 |
| `dst_bay` | 终点仓位 | 关联显示 |
| `robot_id` | 分配 AGV | 关联显示 |
| `cargo_type` | 货物类型 | 分类 |
| `duration` | 已运行时长 | 耗时显示 |
| `rcs_task_no` | RCS 任务流水号 | 外部关联 |

### 3.2 数据流更新策略

| 数据块 | 更新策略 | 间隔 | 原因 |
|:---|:---|:---|:---|
| 起始仓位 | 轮询 + 事件 | 3s / 实时 | AI 检测时效性高，bind_time 需及时 |
| 终点仓位 | 轮询 | 10s | RCS 轮询本身 10s 一次 |
| AGV 状态 | 轮询 | 3s | RCS 轮询本身 3s 一次 |
| 任务队列 | 事件驱动 | 实时 | 出入队事件触发推送 |
| 工作流实例 | 事件驱动 | 实时 | 状态变化触发推送 |
| 任务统计 | 轮询 | 10s | 汇总数据，不需高频 |

**WebSocket 推送策略**：

```
web_monitor_plugin 的 _monitoring_loop() 中:
  每 monitor_interval (默认 5s) 采集一轮所有数据 →
  通过 WebServer.manager.schedule_broadcast() 推送

smart_trigger / workflow_engine 事件:
  出入队 / 状态变化 → EventBus →
  web_monitor 订阅 → 立即 schedule_broadcast()
```

## 5. 展示面：页面/面板规划

### 5.1 页面体系

```
首页 (/) — 更新
├── 系统概览 (已有 + 增强)
│   └── 新增: AGV 状态卡片、今日任务 KPI
├── 起始仓位热力图 (新增)
├── 任务队列摘要 (新增)
└── 实时工作流状态条 (新增)

仓位监控 (/bay) — 新增页面
├── 起始仓位网格 (2F/3F/4F 分区)
│   └── 每格: 编号 + 状态色 + 货物类型 + 等待时长
├── 终点仓位网格 (按楼层)
│   └── 每格: 编号 + 空/满状态
└── 仓位统计面板

AGV 监控 (/agv) — 新增页面
├── AGV 状态卡片 (1001/1002)
│   ├── 状态灯 (绿=AVAILABLE/黄=BUSY/灰=OFFLINE/红=ERROR)
│   ├── 电量条
│   ├── 当前位置
│   └── 当前任务关联
└── AGV 历史任务列表

任务管理 (/task) — 新增页面
├── 任务队列面板
│   ├── 排队中任务列表 (src→dst, 优先级)
│   ├── 队列统计 (入队/出队/跳过)
│   └── 锁定资源清单
├── 活跃工作流面板
│   ├── 状态流图 (高亮当前状态)
│   └── 实例列表 (task_id, 状态, 耗时)
├── 任务统计面板
│   ├── 今日完成/失败/运行中 KPI
│   └── 按类型分布柱状图
└── 历史任务表 (分页, 筛选, 搜索)

工作流详情 (/workflow) — 新增页面
├── 状态流图 (SVG/Canvas 可视化)
│   └── calling_rcs → monitoring → ... → completed
├── 实例时间线
├── 状态变更历史日志
└── 异常事件日志
```

### 7.3 Phase 1 详细: 后端数据采集方法

#### web_monitor_plugin.py 新增方法

```python
# ── 添加到 WebMonitorPlugin 类中 ──

def _get_bay_status(self) -> dict:
    """采集起始仓位状态 (BayCache)"""
    try:
        fusion = self._get_plugin('bay_status_fusion')
        if not fusion or not fusion.cache:
            return {'bays': [], 'total': 0}
        bays = fusion.cache.get_all_bay_status()
        now = time.time()
        result = []
        by_type = {}
        for bid, bay in bays.items():
            ct = bay.get('cargo_type', 0)
            by_type.setdefault(str(ct), {'total': 0, 'bound': 0, 'available': 0})
            by_type[str(ct)]['total'] += 1
            if bay.get('bind_status') == 1:
                by_type[str(ct)]['bound'] += 1
                if not bay.get('in_task'):
                    by_type[str(ct)]['available'] += 1
            result.append({
                'bay_id': bay['bay_id'],
                'cargo_type': ct,
                'bind_status': bay.get('bind_status', 0),
                'bind_status_label': {0: '未绑定', 1: '已绑定', 2: '绑定中'}.get(bay.get('bind_status', 0), '未知'),
                'ai_detected': bay.get('ai_detected', False),
                'in_task': bay.get('in_task', False),
                'bind_time': bay.get('bind_time', 0),
                'bind_duration': round(now - bay.get('bind_time', now), 1) if bay.get('bind_status') == 1 else 0,
                'last_seen': bay.get('last_seen', 0),
            })
        return {
            'timestamp': now,
            'total': len(result),
            'bound_count': sum(1 for b in result if b['bind_status'] == 1),
            'in_task_count': sum(1 for b in result if b['in_task']),
            'by_type': by_type,
            'bays': result,
        }
    except Exception as e:
        self.logger.error(f"采集起始仓位状态失败: {e}")
        return {'bays': [], 'total': 0, 'error': str(e)}


def _get_agv_status(self) -> dict:
    """采集 AGV 状态 (RobotCache)"""
    try:
        poller = self._get_plugin('status_poller')
        if not poller or not poller.robot_cache:
            return {'robots': [], 'available_count': 0}
        robots = poller.robot_cache.get_all_robot_status()
        result = []
        for rid, r in robots.items():
            result.append({
                'robot_id': rid,
                'status': r.get('status', 'OFFLINE'),
                'battery': r.get('battery', 0),
                'position_code': r.get('position_code', ''),
                'current_task_id': r.get('current_task_id', ''),
                'update_time': r.get('update_time', 0),
            })
        return {
            'timestamp': time.time(),
            'available_count': sum(1 for r in result if r['status'] == 'AVAILABLE'),
            'busy_count': sum(1 for r in result if r['status'] == 'BUSY'),
            'robots': result,
        }
    except Exception as e:
        self.logger.error(f"采集 AGV 状态失败: {e}")
        return {'robots': [], 'available_count': 0}


def _get_task_queue(self) -> dict:
    """采集任务队列状态 (TaskQueue)"""
    try:
        trigger = self._get_plugin('smart_trigger')
        if not trigger or not trigger._task_queue:
            return {'queue_size': 0}
        stats = trigger._task_queue.get_stats()
        engine = trigger._trigger_engine
        locked = engine.get_locked_count() if engine else {}
        return {
            'queue_size': stats.get('queue_size', 0),
            'enqueue_count': stats.get('enqueue_count', 0),
            'dequeue_count': stats.get('dequeue_count', 0),
            'skip_duplicate_count': stats.get('skip_duplicate_count', 0),
            'locked_resources': locked,
        }
    except Exception as e:
        self.logger.error(f"采集任务队列失败: {e}")
        return {'queue_size': 0}


def _get_workflow_instances(self) -> dict:
    """采集活跃工作流实例 (WorkflowEngine)"""
    try:
        wf = self._get_plugin('workflow_engine')
        if not wf or not wf._engine:
            return {'active_count': 0, 'instances': [], 'by_state': {}}

        engine = wf._engine
        instances = []
        by_state = {}
        for task_id, inst in list(engine._instances.items()):
            state = inst.current_state
            by_state[state] = by_state.get(state, 0) + 1
            instances.append({
                'task_id': task_id,
                'current_state': state,
                'status': inst.status,
                'src_bay': inst.context.get('src_bay', ''),
                'dst_bay': inst.context.get('dst_bay', ''),
                'robot_id': inst.context.get('robot_id', ''),
                'cargo_type': inst.context.get('cargo_type', 0),
                'duration': round(inst.duration, 1),
                'rcs_task_no': inst.context.get('rcs_task_no', ''),
            })
        return {
            'active_count': len(instances),
            'by_state': by_state,
            'instances': instances,
        }
    except Exception as e:
        self.logger.error(f"采集工作流实例失败: {e}")
        return {'active_count': 0, 'instances': [], 'by_state': {}}


def _get_task_stats(self) -> dict:
    """采集任务统计 (从 WorkflowPersistence SQLite)"""
    try:
        wf = self._get_plugin('workflow_engine')
        if not wf or not wf._engine:
            return {}
        persistence = wf._engine._persistence
        # 查询今日统计
        import sqlite3
        db_path = persistence._db_path
        today = time.strftime('%Y-%m-%d')
        with sqlite3.connect(db_path) as conn:
            conn.row_factory = sqlite3.Row
            # 今日任务总数
            row = conn.execute(
                "SELECT COUNT(*) as cnt FROM task_instances "
                "WHERE date(created_at) = ?", (today,)
            ).fetchone()
            total = row['cnt'] if row else 0
            # 按终态分布
            rows = conn.execute(
                "SELECT current_state, COUNT(*) as cnt FROM task_instances "
                "WHERE date(created_at) = ? GROUP BY current_state", (today,)
            ).fetchall()
            by_state = {r['current_state']: r['cnt'] for r in rows}
        return {
            'today': {
                'total': total,
                'completed': by_state.get('completed', 0),
                'failed': by_state.get('failed', 0),
                'manual_intervention': by_state.get('manual_intervention', 0),
                'running': sum(by_state.values()) - by_state.get('completed', 0) - by_state.get('failed', 0),
            }
        }
    except Exception as e:
        self.logger.error(f"采集任务统计失败: {e}")
        return {}


def _collect_business_status(self) -> dict:
    """聚合采集所有业务数据"""
    return {
        'type': 'full_business',
        'timestamp': time.time(),
        'bay': self._get_bay_status(),
        'dest': self._get_dest_status(),
        'agv': self._get_agv_status(),
        'queue': self._get_task_queue(),
        'workflow': self._get_workflow_instances(),
        'stats': self._get_task_stats(),
    }
```

```python
# web_monitor_plugin.py — 新增方法
def _get_dest_status(self) -> dict:
    """采集终点仓位状态 (DestBayCache)"""
    try:
        poller = self._get_plugin('status_poller')
        if not poller or not poller.dest_cache:
            return {'bays': [], 'total': 0}
        bays = poller.dest_cache.get_all_bay_status()
        result = []
        by_floor = {}
        for bid, bay in bays.items():
            floor = bay.get('floor_no', 0)
            by_floor.setdefault(str(floor), {'total': 0, 'empty': 0})
            by_floor[str(floor)]['total'] += 1
            if bay.get('is_empty'):
                by_floor[str(floor)]['empty'] += 1
            result.append({
                'bay_id': bay['bay_id'],
                'cargo_type': bay.get('cargo_type', 0),
                'floor_no': floor,
                'is_empty': bay.get('is_empty', True),
                'update_time': bay.get('update_time', 0),
            })
        return {
            'timestamp': time.time(),
            'total': len(result),
            'empty_count': sum(1 for b in result if b['is_empty']),
            'by_floor': by_floor,
            'bays': result,
        }
    except Exception as e:
        self.logger.error(f"采集终点仓位状态失败: {e}")
        return {'bays': [], 'total': 0}
```

```javascript
class BayHeatmap {
    constructor(containerId, rows, cols) {
        this.container = document.getElementById(containerId);
        this.rows = rows;    // ['A', 'B', 'C', 'D']
        this.cols = cols;    // [1, 2, 3, 4, 5, 6]

    render(bayData) {
        // bayData: { bays: [{bay_id, cargo_type, bind_status, in_task, bind_duration}] }
        let html = '<div class="bay-grid">';

        for (const row of this.rows) {
            html += '<div class="bay-row">';
            for (const col of this.cols) {
                const bayId = `${row}${col}001`;
                const bay = bayData.bays.find(b => b.bay_id === bayId) || {};
                const stateClass = this._getStateClass(bay);
                const typeClass = this._getTypeClass(bay.cargo_type);
                const label = this._getStateLabel(bay);
                const duration = bay.bind_duration > 0 ? `${Math.floor(bay.bind_duration)}s` : '';

                html += `
                    <div class="bay-cell ${stateClass} ${typeClass}"
                         title="${bayId}: ${label} ${duration}">
                        <div class="bay-id">${bayId}</div>
                        <div class="bay-status">${label}</div>
                        <div class="bay-duration">${duration}</div>
                    </div>`;
            }
            html += '</div>';
        }
        html += '</div>';
        this.container.innerHTML = html;
    }

    _getStateClass(bay) {
        if (bay.in_task) return 'state-in-task';
        if (bay.bind_status === 1) return 'state-bound';
        if (bay.bind_status === 2) return 'state-binding';
        if (bay.ai_detected) return 'state-detecting';
        return 'state-empty';
    }

    _getTypeClass(cargoType) {
        return `type-${cargoType || 0}`;
    }

    _getStateLabel(bay) {
        if (bay.in_task) return '⚙ 任务中';
        if (bay.bind_status === 1) return '■ 已绑定';
        if (bay.bind_status === 2) return '◉ 绑定中';
        if (bay.ai_detected) return '◌ 检测中';
        return '□ 空';
    }
}
```
