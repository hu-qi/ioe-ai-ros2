# app_mgr_object-0.0.9 参数 YAML 独立文件拆分 — 启动驱动 + 热加载持久化实施指南

> 文档编号：31
> 目标工程：`app_mgr_object-0.0.9(基础版)-5-3`
> 前置规划：[30.app_mgr_object-0.0.9-参数热加载持久化技术方案.md](./30.app_mgr_object-0.0.9-参数热加载持久化技术方案.md)
> 实施目标：将 `params.yaml` 中嵌入的 YAML 块字符串（`plugin_configs` 和 `web_monitor`）拆分为独立 YAML 文件，实现一键加载驱动启动 + 单文件原子热写持久化
> 核心理念：**一个配置段 → 一个独立 YAML 文件**，无双重编码，人可直接手改，git 友好 diff
> 实施日期：2026-08-05

---

## 0. 为什么拆为独立 YAML 文件（而非 ROS2 简单参数）

| 对比维度 | YAML 块字符串（现状） | ROS2 简单参数 | **独立 YAML 文件（本方案）** |
|---|---|---|---|
| 可读性 | ❌ 嵌套 YAML，IDE 不识别语法 | ⚠️ `ros2 param dump` 格式冗长 | ✅ 标准 YAML，IDE 高亮+校验 |
| 热加载写入 | ❌ `yaml.dump` → 字符串 → 外层 `yaml.dump`，双编码退化 | ✅ 系统级原子 | ✅ 单文件原子写入，无双重编码 |
| 单段修改粒度 | ❌ 必须修改整个 `plugin_configs` 块字符串 | ✅ 逐键修改 | ✅ 只重写单个文件（~20 行 vs 200+ 行） |
| 版本控制 | ❌ 巨型块字符串 diff 不可读 | ⚠️ 大平铺 diff | ✅ 按模块 diff，清晰可追溯 |
| 人手工编辑 | ❌ 在 YAML 内写 YAML，缩进地狱 | ✅ `ros2 param set` 可编辑 | ✅ 直接 `vi` 修改，`ros2 param reload` 生效 |
| 启动加载 | ✅ 现有机制 | ✅ ROS2 原生 | ✅ 一次遍历目录，兼容现有代码零侵入 |
| 迁移成本 | — | 🔴 需改造 12+ 插件配置读取代码 | 🟢 ParamManager 内部改造，插件无感 |

**结论**：独立 YAML 文件方案比 ROS2 简单参数改造风险低一个量级（插件 `self.config.get(...)` 零改动），同时彻底消除双重 YAML 编码问题。

## 2. 技术方案总览

### 2.1 加载链路

```
启动 → main.py
  → ParamManager.__init__()
    → _declare_common_parameters()        ← ROS2 声明顶层参数（含 plugin_configs_dir / web_monitor_config）
    → _load_plugin_configs_from_dir()     ← 新增：遍历 plugin_configs/ 目录，汇编为 dict
      → yaml.safe_load(plugins/bay_status_fusion.yaml) → dict
      → yaml.safe_load(plugins/status_poller.yaml)      → dict
      → ...
    → _load_web_monitor_config_from_file() ← 新增：读取 web_monitor.yaml
    → _params['plugin_configs'] = 合成的 dict
    → _params['web_monitor'] = 解析的 dict
  → PluginManager.load_plugin(name, config)  ← 无改动！config 来源不变
```

### 2.2 热加载写回链路（单文件原子）

```
Web PUT /api/config/bay {"mappings":{"A1001": 2}}
  → web_monitor_plugin.apply_config('bay_configs', value)
    → param_manager.update_plugin_config_nested(['bay_status_fusion', 'bay_configs'], value)
      → 定位文件：config/plugin_configs/bay_status_fusion.yaml
      → _read_yaml(file) → dict
      → dict['bay_configs'] = value
      → _write_yaml_atomic(file, dict)  ← 单文件原子写入（无双重编码！）
      → 更新 _params['plugin_configs'] 内存
      → node.set_parameters 触发回调
```

### 2.3 与文档 30 的关系

本文档在文档 30 的 ParamManager 原子写入基础上，向前推进一步：**消除 YAML 块字符串，改用独立文件**。文档 30 的 `_write_yaml_atomic()` 被直接复用，但写入目标从整个 `params.yaml` 改为单个插件配置文件。

#### S2.1 新增目录加载方法 `_load_plugin_configs_from_dir`

在 `param_manager.py` 中新增：

```python
def _load_plugin_configs_from_dir(self, configs_dir: str) -> dict:
    """从独立 YAML 目录加载所有插件配置，汇编为 plugin_configs dict。

    目录结构：
        config/plugin_configs/
            network.yaml            → plugin_configs['network']
            callback_handler.yaml   → plugin_configs['callback_handler']
            ...

    Returns:
        dict: 合并后的 plugin_configs（key = 文件名去 .yaml）
    """
    plugin_configs = {}
    
    if not os.path.isdir(configs_dir):
        self.logger.warning(f"插件配置目录不存在: {configs_dir}")
        return plugin_configs

    for entry in sorted(os.listdir(configs_dir)):
        if not entry.endswith('.yaml'):
            continue
        filepath = os.path.join(configs_dir, entry)
        plugin_name = entry[:-5]  # 去 .yaml 后缀即为插件名
        try:
            config = self._read_yaml(filepath)
            if not isinstance(config, dict):
                self.logger.warning(f"插件配置文件不是字典: {filepath}")
                continue
            plugin_configs[plugin_name] = config
            self.logger.debug(f"已加载插件配置: {plugin_name} ({len(config)} 项)")
        except Exception as e:
            self.logger.error(f"加载插件配置失败 [{filepath}]: {e}")

    self.logger.info(f"从目录加载了 {len(plugin_configs)} 个插件配置")
    return plugin_configs


def _load_config_from_file(self, filepath: str) -> dict:
    """从单个 YAML 文件加载配置（用于 web_monitor 等独立文件）。

    Args:
        filepath: YAML 文件路径（绝对路径 或 相对于包共享目录）

    Returns:
        dict: 解析后的配置字典
    """
    if not os.path.isabs(filepath):
        filepath = os.path.join(self._get_pkg_share_dir(), filepath)

    if not os.path.isfile(filepath):
        self.logger.warning(f"配置文件不存在: {filepath}，使用空配置")
        return {}

    try:
        config = self._read_yaml(filepath)
        if not isinstance(config, dict):
            self.logger.warning(f"配置文件不是字典: {filepath}")
            return {}
        self.logger.info(f"已加载配置: {filepath} ({len(config)} 项)")
        return config
    except Exception as e:
        self.logger.error(f"加载配置失败 [{filepath}]: {e}")
        return {}


def _get_pkg_share_dir(self) -> str:
    """获取包共享目录（config/ 目录的父级）"""
    import os
    try:
        from ament_index_python.packages import get_package_share_directory
        return get_package_share_directory('app_mgr_object')
    except Exception:
        return os.getcwd()
```

#### S2.2 改造 `__init__` 启动流程

修改 `ParamManager.__init__`，在声明参数后加载外部配置：

```python
def __init__(self, node: Node):
    self.node = node
    self.logger = node.get_logger()
    self._params = {}
    self._param_callbacks = {}
    self._yaml_lock = threading.Lock()         # 新增：文件写锁（文档 30）
    self._pkg_share = None                      # 缓存包共享目录

    # Step 1: 声明 ROS2 参数（含 plugin_configs_dir / web_monitor_config 新参数）
    self._declare_common_parameters()
    
    # Step 2: 从独立 YAML 文件加载配置
    self._load_external_configs()
    
    # Step 3: 注册参数变更回调
    self._setup_param_callback()

    self.logger.info("参数管理器初始化完成（独立文件模式）")


def _load_external_configs(self):
    """从独立 YAML 文件加载 plugin_configs 和 web_monitor"""
    pkg_share = self._get_pkg_share_dir()

    # 加载 plugin_configs（目录模式）
    configs_dir_rel = self.get_param('plugin_configs_dir', 'config/plugin_configs')
    if not os.path.isabs(configs_dir_rel):
        configs_dir_rel = os.path.join(pkg_share, configs_dir_rel)
    plugin_configs = self._load_plugin_configs_from_dir(configs_dir_rel)
    if plugin_configs:
        self._params['plugin_configs'] = plugin_configs
        self.logger.info(f"plugin_configs 加载完成: {list(plugin_configs.keys())}")
    else:
        self.logger.warning("plugin_configs 为空，请检查 plugin_configs_dir 配置")
        self._params['plugin_configs'] = {}

    # 加载 web_monitor（单文件模式）
    web_monitor_path = self.get_param('web_monitor_config', 'config/web_monitor.yaml')
    web_monitor = self._load_config_from_file(web_monitor_path)
    if web_monitor:
        self._params['web_monitor'] = web_monitor
        self.logger.info(f"web_monitor 配置加载完成: {len(web_monitor)} 项")
    else:
        self._params['web_monitor'] = {}
```

#### S2.3 改造 `_declare_common_parameters` — 移除插件配置块声明

```python
def _declare_common_parameters(self):
    """声明通用参数（不再声明 plugin_configs / web_monitor 为块字符串）"""
    common_params = [
        ('dry_run', False),
        ('log_level', 'info'),
        ('operation_mode', 'development'),
        # ... 所有现有简单参数保留 ...
        ('status_report_interval', 300),
        ('plugin_auto_start', True),
        # ===== 新增：外部配置文件路径 =====
        ('plugin_configs_dir', 'config/plugin_configs'),   # 插件配置目录
        ('web_monitor_config', 'config/web_monitor.yaml'),  # Web 监控配置文件
    ]
    
    for name, default in common_params:
        try:
            self.node.declare_parameter(name, default)
            param_value = self.node.get_parameter(name).value
            # JSON/YAML 字符串解析（保留现有逻辑）
            if isinstance(param_value, str) and param_value.startswith(('{', '[')):
                try:
                    param_value = json.loads(param_value)
                except json.JSONDecodeError:
                    try:
                        param_value = yaml.safe_load(param_value)
                    except yaml.YAMLError:
                        pass
            self._params[name] = param_value
        except Exception as e:
            self.logger.warning(f"声明参数 {name} 失败: {e}")
            self._params[name] = default

    # plugin_load_order 声明（保留现有逻辑）
    try:
        descriptor = ParameterDescriptor(type=ParameterType.PARAMETER_STRING_ARRAY)
        self.node.declare_parameter('plugin_load_order', [], descriptor)
        self._params['plugin_load_order'] = self.node.get_parameter('plugin_load_order').value
    except Exception as e:
        self.logger.warning(f"声明 plugin_load_order 失败: {e}")
        self._params['plugin_load_order'] = []
```

#### S2.4 改造 `update_plugin_config_nested` — 单文件原子写入

**这是核心改造点**：不再操作 `params.yaml` 中的块字符串，而是直接读写插件对应的独立 YAML 文件。

```python
def update_plugin_config_nested(self, path: list, value: Any) -> bool:
    """更新 plugin_configs 中嵌套路径的值，并原子持久化到对应的独立 YAML 文件。

    映射规则：
        path[0] = 插件名 → 对应 config/plugin_configs/<plugin_name>.yaml

    Args:
        path: 键路径，如 ['bay_status_fusion', 'bay_configs']
              如 ['smart_trigger', 'work_schedule', 'schedules']
        value: 新值
    """
    if not path:
        self.logger.error("update_plugin_config_nested: path 不能为空")
        return False

    plugin_name = path[0]
    
    try:
        # 1. 定位独立 YAML 文件
        yaml_file = self._get_plugin_config_file(plugin_name)
        if not yaml_file:
            self.logger.error(f"找不到插件配置文件: {plugin_name}")
            return False

        # 2. 读取当前文件内容
        plugin_config = self._read_yaml(yaml_file)
        if not isinstance(plugin_config, dict):
            self.logger.error(f"插件配置 YAML 格式异常: {yaml_file}")
            return False

        import copy
        plugin_config = copy.deepcopy(plugin_config)

        # 3. 沿路径导航（支持 dict + list index）
        target = plugin_config
        for key in path[1:-1]:       # 跳过 plugin_name
            if isinstance(target, list) and isinstance(key, int):
                if key < 0 or key >= len(target):
                    raise IndexError(f"列表索引越界: {key}")
                target = target[key]
            elif isinstance(target, dict):
                target = target.setdefault(key, {})
            else:
                raise TypeError(f"路径类型不匹配: {type(target).__name__}")

        # 4. 写入新值
        leaf_key = path[-1]
        if isinstance(target, list) and isinstance(leaf_key, int):
            target[leaf_key] = value
        elif isinstance(target, dict):
            target[leaf_key] = value
        else:
            raise TypeError(f"目标不可写: {type(target).__name__}")

        # 5. 单文件原子写入（无双重 YAML 编码！）
        if not self._write_yaml_atomic(yaml_file, plugin_config):
            self.logger.error(f"插件配置写入失败: {yaml_file}")
            return False

        # 6. 更新内存 _params['plugin_configs']
        if 'plugin_configs' in self._params and isinstance(self._params['plugin_configs'], dict):
            self._params['plugin_configs'][plugin_name] = plugin_config

        # 7. 同步 ROS2 参数（通知回调）
        self._notify_plugin_config_changed(plugin_name, plugin_config)

        self.logger.info(f"独立文件热加载成功: {plugin_name} → {' → '.join(str(k) for k in path[1:])}")
        return True

    except Exception as e:
        self.logger.error(f"独立文件热加载失败 [{path}]: {e}")
        return False


def _get_plugin_config_file(self, plugin_name: str) -> str:
    """根据插件名获取其对应的独立 YAML 文件路径"""
    configs_dir = self.get_param('plugin_configs_dir', 'config/plugin_configs')
    if not os.path.isabs(configs_dir):
        configs_dir = os.path.join(self._get_pkg_share_dir(), configs_dir)
    return os.path.join(configs_dir, f"{plugin_name}.yaml")


def _notify_plugin_config_changed(self, plugin_name: str, config: dict):
    """单个插件配置变更通知（轻量）"""
    try:
        # 1. 分发注册的参数回调
        cb = self._param_callbacks.get('plugin_configs')
        if cb:
            merged = self._params.get('plugin_configs', {})
            try:
                cb('plugin_configs', merged)
            except Exception as e:
                self.logger.error(f"plugin_configs 回调失败: {e}")

        # 2. EventBus 广播（供其他插件局部 reload）
        if hasattr(self.node, 'event_bus') and self.node.event_bus:
            self.node.event_bus.publish('plugin_configs.updated', {
                'plugin_name': plugin_name,
                'config': config,
            })
    except Exception as e:
        self.logger.warning(f"配置变更通知失败: {e}")
```

def _deep_merge(base: dict, override: dict) -> dict:
    """深度合并两个字典"""

def set_param_and_persist(self, name: str, value: Any) -> bool:

#### S2.7 复用文档 30 的原子写入方法

```python
def _write_yaml_atomic(self, path: str, config: dict) -> bool:
    """原子写入 YAML 文件（文档 30 代码直接复用）

    - 临时文件 .tmp → yaml.dump + fsync → os.replace → 回读校验
    """
    with self._yaml_lock:
        tmp_path = path + '.tmp'
        bak_path = path + '.bak'
        try:
            if os.path.exists(path):
                shutil.copy2(path, bak_path)

            with open(tmp_path, 'w', encoding='utf-8') as f:
                yaml.dump(
                    config, f,
                    allow_unicode=True,
                    default_flow_style=False,
                    sort_keys=False,
                    indent=2,
                    width=120,
                )
                f.flush()
                os.fsync(f.fileno())

            os.replace(tmp_path, path)

            if not self._verify_yaml(path, config):
                if os.path.exists(bak_path):
                    os.replace(bak_path, path)
                return False

            self._write_version += 1
            return True

        except Exception as e:
            self.logger.error(f"原子写入失败 [{path}]: {e}")
            if os.path.exists(tmp_path):
                try:
                    os.remove(tmp_path)
                except OSError:
                    pass
            return False
```

## 5. 风险与回滚

### 5.1 风险矩阵

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| 独立 YAML 文件路径解析失败 | 低 | 启动失败 | `_load_external_configs` 兜底返回空 dict，不阻塞启动 |
| 目录权限不足导致热写失败 | 低 | 配置热加载失败 | `_write_yaml_atomic` 返回 False，调用方提示错误 |
| 手改 YAML 语法错误 | 中 | 热写后被错误内容覆盖 | 热写前不校验手改内容（设计决定）；建议 Web UI 写入 |
| `setup.py` 遗漏新文件 | 低 | 安装后文件缺失 | 编译后检查 `install/.../share/.../config/plugin_configs/` |
| 旧版 `params.yaml` 残留块字符串 | 中 | 启动时被忽略（新代码不读块字符串） | 删除或注释旧块字符串 |

### 5.2 回滚方案

1. 保留 `params.yaml.bak`（拆分前的完整文件）
2. 恢复旧版 `param_manager.py` → `cp base/param_manager.py.bak base/param_manager.py`
3. 恢复旧版 `params.yaml` → `cp config/params.yaml.bak config/params.yaml`
4. `colcon build && ros2 launch ...`
