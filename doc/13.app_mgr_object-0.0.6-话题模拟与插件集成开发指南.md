## 2. `/dev01_object_status` 话题数据结构

### 2.1 ROS2 自定义消息定义

#### BayStatus.msg（顶层消息）
```
std_msgs/Header header        # 时间戳 + frame_id
string device_id              # 设备标识，如 "dev01"
BayChannelStatus[] channels   # 通道列表
```

#### BayChannelStatus.msg（通道级状态）
```
int32 channel_id              # 通道编号 (0, 1, 2, ...)
bool signal_status            # 信号状态 (true: 有信号, false: 无信号)
BayArea[] areas               # 该通道下的仓位列表
```

#### BayArea.msg（仓位级状态）
```
string bay_id                 # 仓位编号，如 "A1001"
bool has_cargo                # 是否有货物 (true: 有货, false: 无货)
int32 cargo_type              # 货物类型 (1~6)
float64 timestamp             # 检测时间戳 (秒, 可用 time.time())
```

### 2.2 话题订阅配置（params.yaml）

```yaml
bay_status_fusion:
  auto_start: true
  stable_threshold: 3          # 防抖阈值（连续 N 帧有货视为稳定）
  filter_timeout: 2.0          # 滤波超时（秒）
  bind_enabled: true           # 是否启用自动 RCS 绑定
  ai_topic: "/dev01_object_status"  # AI 检测话题
```

### 2.3 仓位配置映射

| 前缀 | 货物类型 | 仓位编号 | 说明 |
|:---|:---|:---|:---|
| A | 1, 2, 3 | A1001~A1006 | 1楼 -- 类型1×2, 类型2×2, 类型3×2 |
| B | 1, 2, 3 | B1001~B1006 | 1楼 -- 类型1×2, 类型2×2, 类型3×2 |
| C | 4, 5, 6 | C1001~C1006 | 2楼 -- 类型4×2, 类型5×2, 类型6×2 |
| D | 4, 5, 6 | D1001~D1006 | 2楼 -- 类型4×2, 类型5×2, 类型6×2 |

## 3. 话题模拟器 — 键盘控制仓位状态发布

### 3.1 设计思路

模拟器是一个独立的 ROS2 节点，通过 `pynput` 库监听键盘输入，动态构造 `BayStatus` 消息发布到 `/dev01_object_status`。

**按键映射**:
- `A+1` → A1001 有货 (type=1)
- `A+2` → A1002 有货 (type=1)
- `B+1` → B1001 有货 (type=1)
- `B+2` → B1002 有货 (type=1)
- `C+1` → C1001 有货 (type=4)
- `C+2` → C1002 有货 (type=4)
- `D+1` → D1001 有货 (type=4)
- `D+2` → D1002 有货 (type=4)
- `数字键 1~6` → 设定当前货物类型
- `X` → 清除指定仓位（设为无货）
- `S` → 显示当前所有仓位状态
- `Q` → 退出程序

### 3.2 完整代码

文件路径: `app_mgr_object-0.0.6(基础版)/scripts/bay_status_simulator.py`

```python
#!/usr/bin/env python3
"""
bay_status_simulator.py — /dev01_object_status 话题模拟器

通过键盘快捷键灵活模拟仓位货物的有无状态，发布 BayStatus 三层消息。
支持两种模式：
  1. 编译模式：使用自定义 BayStatus/BayChannelStatus/BayArea 消息类型
  2. 降级模式：使用 std_msgs/String JSON 发布（无需编译自定义消息）

使用方法:
  python3 bay_status_simulator.py                    # 降级模式
  python3 bay_status_simulator.py --custom-msg       # 编译模式（需 colcon build 后）
"""

import json
import time
import threading
import sys
import os
from typing import Dict, Set, Optional

# ════════════════════════════════════════════════════════════
#  ROS2 初始化
# ════════════════════════════════════════════════════════════
try:
    import rclpy
    from rclpy.node import Node
    from std_msgs.msg import String
    RCLPY_AVAILABLE = True
except ImportError:
    print("[ERROR] rclpy 未安装，请先执行: pip install rclpy")
    print("        或在 ROS2 环境中运行: source /opt/ros/humble/setup.bash")
    sys.exit(1)

# 尝试导入自定义消息
try:
    from app_mgr_object.custom_msgs.msg import BayStatus, BayChannelStatus, BayArea
    CUSTOM_MSG_AVAILABLE = True
except ImportError:
    BayStatus = None
    BayChannelStatus = None
    BayArea = None
    CUSTOM_MSG_AVAILABLE = False

# ════════════════════════════════════════════════════════════
#  键盘监听 (pynput)
# ════════════════════════════════════════════════════════════
try:
    from pynput import keyboard as pynput_keyboard
    PYNPUT_AVAILABLE = True
except ImportError:
    print("[WARN] pynput 未安装，尝试安装中...")
    os.system(f"{sys.executable} -m pip install pynput -q")
    try:
        from pynput import keyboard as pynput_keyboard
        PYNPUT_AVAILABLE = True
    except ImportError:
        print("[ERROR] pynput 安装失败，请手动执行: pip install pynput")
        sys.exit(1)

# ════════════════════════════════════════════════════════════
#  仓位配置
# ════════════════════════════════════════════════════════════
# 完整仓位映射: {bay_id: cargo_type}
BAY_CONFIGS: Dict[str, int] = {
    # A 区 (1楼, 类型 1~3)
    'A1001': 1, 'A1002': 1,
    'A1003': 2, 'A1004': 2,
    'A1005': 3, 'A1006': 3,
    # B 区 (1楼, 类型 1~3)
    'B1001': 1, 'B1002': 1,
    'B1003': 2, 'B1004': 2,
    'B1005': 3, 'B1006': 3,
    # C 区 (2楼, 类型 4~6)
    'C1001': 4, 'C1002': 4,
    'C1003': 5, 'C1004': 5,
    'C1005': 6, 'C1006': 6,
    # D 区 (2楼, 类型 4~6)
    'D1001': 4, 'D1002': 4,
    'D1003': 5, 'D1004': 5,
    'D1005': 6, 'D1006': 6,
}

# 通道布局: [{channel_id, bays: [bay_id, ...]}]
CHANNEL_LAYOUT = [
    {
        'channel_id': 0,
        'bays': ['A1001', 'A1002', 'A1003', 'A1004', 'A1005', 'A1006',
                 'B1001', 'B1002', 'B1003', 'B1004', 'B1005', 'B1006']
    },
    {
        'channel_id': 1,
        'bays': ['C1001', 'C1002', 'C1003', 'C1004', 'C1005', 'C1006',
                 'D1001', 'D1002', 'D1003', 'D1004', 'D1005', 'D1006']
    },
]

# 快捷按键 → 仓位映射
SHORTCUT_MAP = {
    'A1': 'A1001', 'A2': 'A1002', 'A3': 'A1003',
    'A4': 'A1004', 'A5': 'A1005', 'A6': 'A1006',
    'B1': 'B1001', 'B2': 'B1002', 'B3': 'B1003',
    'B4': 'B1004', 'B5': 'B1005', 'B6': 'B1006',
    'C1': 'C1001', 'C2': 'C1002', 'C3': 'C1003',
    'C4': 'C1004', 'C5': 'C1005', 'C6': 'C1006',
    'D1': 'D1001', 'D2': 'D1002', 'D3': 'D1003',
    'D4': 'D1004', 'D5': 'D1005', 'D6': 'D1006',
}


class BayStatusSimulator:
    """仓位状态模拟器 — 键盘驱动"""

    def __init__(self, use_custom_msg: bool = False):
        self._use_custom_msg = use_custom_msg and CUSTOM_MSG_AVAILABLE
        if use_custom_msg and not CUSTOM_MSG_AVAILABLE:
            print("[WARN] 自定义消息不可用，降级为 JSON 模式")
            self._use_custom_msg = False

        # 当前仓位状态 {bay_id: bool}
        self._bay_states: Dict[str, bool] = {
            bay_id: False for bay_id in BAY_CONFIGS
        }

        # 当前激活的 cargo_type（默认 1）
        self._current_cargo_type: int = 1

        # 上次按下的字母键（用于组合键）
        self._last_letter: Optional[str] = None
        self._last_letter_time: float = 0.0
        self._combo_timeout: float = 0.5  # 组合键超时（秒）

        # ROS2 节点
        self._node: Optional[Node] = None
        self._publisher = None
        self._running = False

        # 发布统计
        self._publish_count: int = 0

    # ══════════════════════════════════════════════════
    #  ROS2 节点
    # ══════════════════════════════════════════════════

    def _init_ros2(self):
        """初始化 ROS2 节点和发布器"""
        self._node = Node('bay_status_simulator')

        if self._use_custom_msg:
            self._publisher = self._node.create_publisher(
                BayStatus, '/dev01_object_status', 10
            )
            self._node.get_logger().info("使用 BayStatus 自定义消息发布")
        else:
            self._publisher = self._node.create_publisher(
                String, '/dev01_object_status', 10
            )
            self._node.get_logger().info("使用 std_msgs/String (JSON) 降级模式发布")

        self._running = True
        self._node.get_logger().info("BayStatus 模拟器就绪，等待键盘输入...")

    # ══════════════════════════════════════════════════
    #  消息构建与发布
    # ══════════════════════════════════════════════════

    def _publish_bay_status(self):
        """发布当前仓位状态"""
        if not self._publisher:
            return

        now = time.time()
        if self._use_custom_msg:
            msg = self._build_custom_msg(now)
        else:
            msg = self._build_json_msg(now)

        self._publisher.publish(msg)
        self._publish_count += 1

    def _build_custom_msg(self, timestamp: float):
        """构建 BayStatus 自定义消息"""
        msg = BayStatus()
        msg.header.stamp.sec = int(timestamp)
        msg.header.stamp.nanosec = int((timestamp - int(timestamp)) * 1e9)
        msg.header.frame_id = 'bay_status_frame'
        msg.device_id = 'dev01'

        for ch_layout in CHANNEL_LAYOUT:
            ch = BayChannelStatus()
            ch.channel_id = ch_layout['channel_id']
            ch.signal_status = True

            for bay_id in ch_layout['bays']:
                area = BayArea()
                area.bay_id = bay_id
                area.has_cargo = self._bay_states.get(bay_id, False)
                area.cargo_type = BAY_CONFIGS.get(bay_id, 0)
                area.timestamp = timestamp
                ch.areas.append(area)

            msg.channels.append(ch)

        return msg

    def _build_json_msg(self, timestamp: float):
        """构建 JSON 降级消息 (std_msgs/String)"""
        data = {
            'device_id': 'dev01',
            'timestamp': timestamp,
            'channels': []
        }

        for ch_layout in CHANNEL_LAYOUT:
            channel = {
                'channel_id': ch_layout['channel_id'],
                'signal_status': True,
                'areas': []
            }
            for bay_id in ch_layout['bays']:
                channel['areas'].append({
                    'bay_id': bay_id,
                    'has_cargo': self._bay_states.get(bay_id, False),
                    'cargo_type': BAY_CONFIGS.get(bay_id, 0),
                    'timestamp': timestamp,
                })
            data['channels'].append(channel)

        msg = String()
        msg.data = json.dumps(data, ensure_ascii=False)
        return msg

    # ══════════════════════════════════════════════════
    #  操作
    # ══════════════════════════════════════════════════

    def set_cargo(self, bay_id: str):
        """设置仓位有货"""
        if bay_id not in BAY_CONFIGS:
            print(f"  [ERROR] 无效仓位: {bay_id}")
            return
        self._bay_states[bay_id] = True
        ct = BAY_CONFIGS[bay_id]
        print(f"  [✓] {bay_id} → 有货 (type={ct})")
        self._publish_bay_status()

    def clear_cargo(self, bay_id: str):
        """设置仓位无货"""
        if bay_id not in BAY_CONFIGS:
            print(f"  [ERROR] 无效仓位: {bay_id}")
            return
        self._bay_states[bay_id] = False
        print(f"  [✗] {bay_id} → 无货")
        self._publish_bay_status()

    def show_status(self):
        """显示当前所有仓位状态"""
        print("\n" + "=" * 60)
        print("  当前仓位状态 (✓=有货  ✗=无货)")
        print("=" * 60)
        for bay_id in sorted(self._bay_states.keys()):
            state = '✓' if self._bay_states[bay_id] else '✗'
            ct = BAY_CONFIGS[bay_id]
            print(f"  {bay_id}  [{state}]  type={ct}")
        print(f"\n  当前货物类型: {self._current_cargo_type}")
        print(f"  已发布消息数: {self._publish_count}")
        print("=" * 60 + "\n")

    def set_cargo_type(self, cargo_type: int):
        """设置当前货物类型（用于后续批量操作）"""
        if 1 <= cargo_type <= 6:
            self._current_cargo_type = cargo_type
            print(f"  [⚙] 当前货物类型设为: {cargo_type}")
        else:
            print(f"  [ERROR] 无效货物类型: {cargo_type} (范围 1~6)")

    # ══════════════════════════════════════════════════
    #  键盘处理
    # ══════════════════════════════════════════════════

    def _on_key_press(self, key):
        """键盘按下回调"""
        try:
            # 字母键
            if hasattr(key, 'char') and key.char:
                ch = key.char.upper()
                if ch in ('A', 'B', 'C', 'D'):
                    self._last_letter = ch
                    self._last_letter_time = time.time()
                    return

                # 数字键 1~6
                if ch in ('1', '2', '3', '4', '5', '6'):
                    num = int(ch)
                    # 检查是否与上次字母键组成组合键
                    if self._last_letter and (time.time() - self._last_letter_time) < self._combo_timeout:
                        bay_id = SHORTCUT_MAP.get(f'{self._last_letter}{num}')
                        if bay_id:
                            self.set_cargo(bay_id)
                    else:
                        # 纯数字键 → 切换 cargo_type
                        self.set_cargo_type(num)

                    self._last_letter = None
                    return

                # X 键 → 清除模式
                if ch == 'X':
                    # 等待下一个数字键来指定清除的仓位
                    self._last_letter = 'X'
                    self._last_letter_time = time.time()
                    return

            # 功能键
            if key == pynput_keyboard.KeyCode.from_char('s') or key == pynput_keyboard.KeyCode.from_char('S'):
                self.show_status()
                return

            if key == pynput_keyboard.KeyCode.from_char('q') or key == pynput_keyboard.KeyCode.from_char('Q'):
                self._running = False
                print("\n[INFO] 正在退出...")
                return

        except Exception as e:
            print(f"  [ERROR] 键盘处理异常: {e}")

    def _on_key_release(self, key):
        """键盘释放回调（用于处理 X+数字键组合）"""
        try:
            if hasattr(key, 'char') and key.char:
                ch = key.char.upper()
                if ch in ('1', '2', '3', '4', '5', '6') and self._last_letter == 'X':
                    if (time.time() - self._last_letter_time) < self._combo_timeout:
                        # 清除所有匹配前缀的仓位，例如 X+1 → 清除 A1001/A2001（如果存在）
                        # 简化版：X + 数字 只清除当前焦点字母+数字
                        pass
                    self._last_letter = None
        except Exception:
            pass

    # ══════════════════════════════════════════════════
    #  主循环
    # ══════════════════════════════════════════════════

    def run(self):
        """启动模拟器"""
        print("\n" + "=" * 60)
        print("  BayStatus 话题模拟器 — /dev01_object_status")
        print("=" * 60)
        print("  键盘控制:")
        print("    A+1~6  → 设置 A1001~A1006 有货")
        print("    B+1~6  → 设置 B1001~B1006 有货")
        print("    C+1~6  → 设置 C1001~C1006 有货")
        print("    D+1~6  → 设置 D1001~D1006 有货")
        print("    1~6    → 切换当前货物类型")
        print("    S      → 显示所有仓位状态")
        print("    Q      → 退出")
        print("=" * 60)
        mode = "BayStatus 自定义消息" if self._use_custom_msg else "std_msgs/String (JSON 降级)"
        print(f"  消息模式: {mode}")
        print("=" * 60 + "\n")

        self._init_ros2()

        # 启动键盘监听（后台线程）
        listener = pynput_keyboard.Listener(
            on_press=self._on_key_press,
            on_release=self._on_key_release
        )
        listener.daemon = True
        listener.start()

        # ROS2 spin (非阻塞)
        try:
            while self._running and rclpy.ok():
                rclpy.spin_once(self._node, timeout_sec=0.1)
        except KeyboardInterrupt:
            pass
        finally:
            listener.stop()
            if self._node:
                self._node.destroy_node()
            print("[INFO] 模拟器已停止")


# ════════════════════════════════════════════════════════════
#  入口
# ════════════════════════════════════════════════════════════

def main():
    rclpy.init(args=None)

    use_custom = '--custom-msg' in sys.argv
```

```python
def _on_bay_status_fallback(self, msg):
    """降级回调 — 增强字段容错"""
    import json
    try:
        data = json.loads(msg.data)
    except json.JSONDecodeError as e:
        self.logger.error(f"JSON 解析失败: {e}")
        return

    device_id = data.get('device_id', 'unknown')
    channels = data.get('channels', [])

    if not isinstance(channels, list):
        self.logger.warning(f"channels 不是列表: {type(channels)}")
        return

    self.logger.debug(f"收到 AI 检测消息 (fallback): device={device_id}, "
                      f"channels={len(channels)}")

    area_count = 0
    for channel in channels:
        if not isinstance(channel, dict):
            continue
        if not channel.get('signal_status', False):
            continue
        for area in channel.get('areas', []):
            if not isinstance(area, dict):
                continue
            bay_id = area.get('bay_id', '')
            has_cargo = area.get('has_cargo', False)
            cargo_type = area.get('cargo_type', 0)
            if bay_id:
                self._process_single_bay(bay_id, has_cargo, cargo_type)
                area_count += 1

    self.logger.debug(f"处理完成: {area_count} 个仓位, device={device_id}")
```

#### 优化 2: 增加绑定重试机制

当 RCS 绑定失败时（网络抖动），增加重试逻辑：

```python
def _on_stable_cargo(self, bay_id: str, cargo_type: int, result: dict):
    """稳定有货 → 触发 RCS 绑定（增加重试）"""
    self.logger.info(
        f"仓位 {bay_id} 稳定有货 (cargo_type={cargo_type}), 触发绑定"
    )

    status = self.cache.get_bay_status(bay_id)
    if status and status.get('bind_status') == 1:
        self.logger.debug(f"仓位 {bay_id} 已绑定，跳过")
        return

    self._publish_event('bay.status_changed', {
        'bay_id': bay_id,
        'has_cargo': True,
        'cargo_type': cargo_type,
        'action': 'stable_cargo_detected',
        'filter_info': result,
    })

    if not self._bind_enabled:
        self.logger.debug(f"绑定已禁用，跳过仓位 {bay_id}")
        return

    # 标记绑定中
    self.cache.set_binding(bay_id)

    # 重试绑定（最多 3 次）
    max_retries = 3
    for attempt in range(1, max_retries + 1):
        try:
            rcs_adapter = self._get_rcs_adapter()
            ctnr_code = f"CTNR_{bay_id}"
            resp = rcs_adapter.bind_ctnr_and_bin(
                ctnr_code=ctnr_code,
                ctnr_typ=str(cargo_type),
                stg_bin_code=bay_id,
                ind_bind="1"
            )

            if resp.get('code') == '0':
                self.cache.set_bound(bay_id)
                self._publish_event('bay.bound', {
                    'bay_id': bay_id,
                    'cargo_type': cargo_type,
                    'ctnr_code': ctnr_code,
                    'rcs_response': resp,
                })
                self.logger.info(
                    f"仓位 {bay_id} 绑定成功 (attempt={attempt}): {ctnr_code}"
                )
                return
            else:
                self.logger.warning(
                    f"仓位 {bay_id} 绑定失败 (attempt={attempt}): "
                    f"code={resp.get('code')}, msg={resp.get('msg', '未知')}"
                )

        except Exception as e:
            self.logger.warning(
                f"仓位 {bay_id} 绑定异常 (attempt={attempt}): {e}"
            )

        if attempt < max_retries:
            import time
            time.sleep(1.0 * attempt)  # 指数退避

    # 全部重试失败
    self.cache.set_unbound(bay_id)
    self.logger.error(
        f"仓位 {bay_id} 绑定失败 (已重试 {max_retries} 次)"
    )
```

| workflow_engine 无输出 | plugin_load_order 未更新 | 确认 params.yaml 中 plugin_load_order 包含全部 9 个插件 |
| `ModuleNotFoundError: pynput` | 缺少键盘监听库 | `pip install pynput` |
| `ModuleNotFoundError: custom_msgs` | 自定义消息未编译 | 使用 JSON 降级模式（默认），或 `colcon build` |
