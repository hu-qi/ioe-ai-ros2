## 一、规划文档梳理结论

### 1.1 doc/04.1《前端核心界面规划方案 v2.0》要点

- **三页核心**:首页、学员、报告;诊断与闭环整合进报告页 Tab,不再设独立菜单。
- **首页驾驶舱 5 区域**:①实时训练动态(40%,380px) ②概览4指标卡(高160px) ③五维诊断热点Top3(60%,360px) ④需关注学员(40%,360px) ⑤最近完成轮次(5行)。
- **取消近7天趋势图**,首页聚焦实时+诊断+需关注。
- **减少弹窗**:内嵌展开 > 独立页面 > 弹窗(仅确认类);"查看报告"为独立页面。
- **按工序区分**:所有评分/诊断/统计界面支持工序筛选(拆解/组装/全部)。
- **设置页**:评分规则/诊断阈值按工序编辑(保存/重载/校验/回滚)+学员同步。
- **键盘**:Ctrl+F 全局搜索、Esc 收起、←/→ 大图切换。

### 1.2 doc/05.1《视觉与交互设计规范 v1.1》要点

- **设计方向**:简洁/专业/克制的教育管理后台,蓝灰主色 `#2B5CE6`+橙强调 `#F5A623`,中高密度。
- **工作台优先**:典型分析任务 Route 切换 ≤1 次;指标卡点击**原地联动过滤**,不跳页。
- **三级交互层级**:原地联动 > Drawer/Popover/Lightbox > 独立页面;Drawer 优先于 Dialog。
- **三个 Drawer**:StudentDrawer(三问:为何关注/最近表现/薄弱步骤)、ReportDrawer(总分/异常/时间线摘要)、DiagnosisDrawer(描述/建议/证据/涉及轮次)。
- **状态保持**:筛选写入 URL Query;返回恢复上下文;Drawer 支持上一条/下一条;浏览器后退优先关 Drawer。
- **键盘快捷键**:Ctrl+F / Esc / ←→ / Enter。
- **状态色规则**:优秀绿/良好蓝/合格橙/不合格红;超时橙/中断红。
- **验收红线**:无必要跳转、返回不丢上下文、工作台+单 Drawer 完成任务。

**E2E 发现并修复的真实缺陷**(静态审查未发现,均回归确认):

2. `ReportsView.vue` 教学闭环 Tab 绑定 `ta.cls` 但 `ta` 对象未定义 → 切 Tab 即崩溃。
3. `.filter-bar` 工具条类 4 个视图共用却无任何样式定义 → 学员页搜索/筛选/按钮挤成一列(用户反馈的按钮排列 bug);排查其余 9 个常用类均有定义。
4. `workspace.analysisParams` 空工序时也传 `process_name=''` → 后端按字面过滤。
5. 顶栏 57px(border-bottom 撑高)→ 补 `box-sizing:border-box`。

**E2E 运行方式**:`cd /tmp/e2e-ui && npm i playwright && npx playwright install chromium && env -u DISPLAY node e2e-smoke.cjs`(需 `env -u DISPLAY`,本机 DISPLAY 指向不可达 X server 会导致 chromium 启动挂起)。
