## 1. 设计思路

### 1.1 清理策略

| 表 | 清理条件 | 保留天数 | 原因 |
|:---|:---|:---|:---|
| `alarm_logs` | `logged_at < now - 90 days` | 90 天 | 告警日志用于短期故障排查 |
| `state_change_log` | `changed_at < now - 90 days` | 90 天 | 状态变更历史用于任务溯源 |
| `exception_log` | `logged_at < now - 90 days` | 90 天 | 异常事件用于趋势分析 |
| `task_instances` | **不清理** | 永久 | 核心业务数据, 不可删除 |

### 1.2 触发方式

```
方案 A: 启动时自动清理 (persistence._init_db)
  → 每次系统启动执行一次, 开销可忽略

方案 B: 周期性清理 (task_monitor 每周 Timer)
  → ROS2 Timer: 604800s (7 天)
  → 确保长期运行的系统也能持续清理
```

**最终采用**: A + B 双保险。启动时立即清理一次，之后每周自动清理。

### 1.3 安全设计

- 清理操作在独立 `try/except` 中，失败不影响主流程
- 仅 DELETE，不 DROP 表或修改结构
- 事务内执行，原子性保证
- 清理后不 vacuum（避免锁表），磁盘空间由 SQLite 自动回收

## 2. Step 1: persistence.py — 新增 cleanup_old_logs 方法

**文件路径**: `app_mgr_object/components/workflow/persistence.py` **(修改)**

### 2.1 位置

### 2.2 代码

```python
# ====== 新增: 定期自动清理过期日志 ======

def cleanup_old_logs(self, retention_days: int = 90) -> dict:
    """清理超过保留期限的日志记录

    清理范围: alarm_logs / state_change_log / exception_log
    不影响: task_instances (核心业务数据)

    Args:
        retention_days: 保留天数, 默认 90

    Returns:
        {
            'alarm_logs_deleted': int,
            'state_change_log_deleted': int,
            'exception_log_deleted': int,
            'total_deleted': int,
            'retention_days': int,
        }
    """
    result = {
        'alarm_logs_deleted': 0,
        'state_change_log_deleted': 0,
        'exception_log_deleted': 0,
        'total_deleted': 0,
        'retention_days': retention_days,
    }

    try:
        with sqlite3.connect(self._db_path) as conn:
            # 1. 清理告警日志
            cursor = conn.execute(
                "DELETE FROM alarm_logs "
                "WHERE logged_at < datetime('now', ?)",
                (f'-{retention_days} days',)
            )
            result['alarm_logs_deleted'] = cursor.rowcount

            # 2. 清理状态变更日志
            cursor = conn.execute(
                "DELETE FROM state_change_log "
                "WHERE changed_at < datetime('now', ?)",
                (f'-{retention_days} days',)
            )
            result['state_change_log_deleted'] = cursor.rowcount

            # 3. 清理异常事件日志
            cursor = conn.execute(
                "DELETE FROM exception_log "
                "WHERE logged_at < datetime('now', ?)",
                (f'-{retention_days} days',)
            )
            result['exception_log_deleted'] = cursor.rowcount

            conn.commit()

            result['total_deleted'] = (
                result['alarm_logs_deleted'] +
                result['state_change_log_deleted'] +
                result['exception_log_deleted']
            )

    except Exception as e:
        if self._logger:
            self._logger.warning(f"日志清理异常 (非致命): {e}")

    if self._logger and result['total_deleted'] > 0:
        self._logger.info(
            f"日志清理完成: 保留 {retention_days} 天, "
            f"删除 {result['total_deleted']} 条 "
            f"(告警:{result['alarm_logs_deleted']}, "
            f"状态:{result['state_change_log_deleted']}, "
            f"异常:{result['exception_log_deleted']})"
        )

    return result

# ======================================================
```

```python
self._cleanup_retention_days = self.config.get('log_retention_days', 90)
```

### 3.2 Step 2B — 在 `_activate_impl` 中启动清理定时器

```python

    self.node.destroy_timer(self._cleanup_timer)
    self._cleanup_timer = None
# ============================
```

### 3.4 Step 2D — 新增 `_cleanup_logs_once` 方法

在 `_on_status_changed` 方法之后（或 `_publish_event` 使用之前）新增:

```python
# ====== 新增: 日志定期清理 ======

def _cleanup_logs_once(self):
    """执行一次日志清理（启动时 + 每 7 天）"""
    try:
        engine = self._get_workflow_engine()
        if not engine:
            return

        persistence = engine._persistence
        result = persistence.cleanup_old_logs(self._cleanup_retention_days)

        if result.get('total_deleted', 0) > 0:
            self.logger.info(
                f"日志定期清理: 删除 {result['total_deleted']} 条 "
                f"(保留 {self._cleanup_retention_days} 天)"
            )
    except Exception as e:
        self.logger.warning(f"日志清理异常 (非致命): {e}")

# =================================
```

## 4. 手动触发清理

除了自动定时清理, 提供手动触发方式供运维使用:

### 4.1 通过 Python 直接调用

```python
# 在 ROS2 节点环境中
engine_plugin = node.plugin_manager.get_plugin('workflow_engine')
persistence = engine_plugin._engine._persistence

# 清理 60 天前的日志
result = persistence.cleanup_old_logs(retention_days=60)
print(result)
# → {'alarm_logs_deleted': 127, 'state_change_log_deleted': 312, ...}

# 清理 30 天前的日志 (更激进)
result = persistence.cleanup_old_logs(retention_days=30)

# 清理全部日志 (保留 0 天)
result = persistence.cleanup_old_logs(retention_days=0)
```

### 4.2 通过 SQLite 命令行

```bash

# 手动清理 90 天前记录
```
