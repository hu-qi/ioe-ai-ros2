# app_mgr_object-0.1.8 运维控制页操作说明卡与最近操作卡统一 UI 改造指南

> 文档版本：v1.0
> 编写日期：2026-08-10
> 适用工程：`app_mgr_object-0.1.8(标准版)`
> 需求：运维控制页（`/control`）右侧两处卡片统一为首页 UI 风格：
>   1) "操作说明"卡：文字/折叠面板样式统一；
>   2) "最近操作"卡："查看更多"按钮及卡片文字风格统一。

---

## 0. 审查结论

| 位置 | 现状 | 问题 |
|---|---|---|
| 操作说明卡（L475~L541）| Bootstrap 默认 Accordion + `text-info/warning/danger` | 白底黑字、黑色折叠箭头，与深色主题不符 |
| 最近操作卡（L460~L472）| 卡片头 `<h5 class="mb-0">`；"查看更多"按钮 `btn btn-outline-info` | Bootstrap 浅蓝描边按钮，与首页 `btn-outline` 风格不符 |
| 最近操作列表（动态渲染 L1542~L1585）| `.recent-operation-item` + `<h6>` + Bootstrap `badge bg-success/bg-danger` | 条目无主题化样式，`h6` 依赖继承色 |

改造文件：

- `app_mgr_object/components/web/static/css/custom.css`（追加样式段）
- `app_mgr_object/components/web/templates/control.html`（卡片头 + 按钮 + 提示行类）

折叠交互、`loadMoreOperations()` 逻辑、`/api/control/logs` 数据链路均不改变。

## 2. 统一规则

```text
卡片头：         去掉 <h5>，统一为 <i class="fas ..."></i> 标题（custom.css 已归一化 h5 视觉）
按钮：           查看更多 btn-outline-info → btn-outline btn-sm
操作条目：        .recent-operation-item 主题化（深色底/边框/浅色标题/灰时间）
成功/失败徽标：   Bootstrap bg-success/bg-danger 保留（状态语义），可选换 .op-badge
操作说明面板：    Accordion 深色主题化 + .help-note.info/.warning/.danger 提示行
```

---

## 3. 修改步骤

```text
Step 1  custom.css 末尾追加样式段（Accordion 深色 + help-note + recent-operation-item + op-badge）
Step 2  control.html 最近操作卡：卡片头 h5 简化；"查看更多"按钮换 btn-outline btn-sm
Step 3  control.html updateRecentOperationsDisplay()：h6 加统一类（可选）
Step 4  control.html 操作说明卡：卡片头 h5 简化；3 处 text-* → help-note *
Step 5  刷新 /control（Ctrl+F5）验证深浅主题
```

## 4. 修改代码

### 4.1 `static/css/custom.css` 末尾追加

```css
/* ============================================================
   运维控制页 — 最近操作卡 / 操作说明卡（统一深色主题）
   ============================================================ */

/* ---- 最近操作条目 ---- */
.recent-operation-item {
    padding: 8px 10px;
    border: 1px solid var(--border);
    border-radius: 6px;
    background: var(--bg-tertiary);
    margin-bottom: 6px;
}
.recent-operation-item h6 {
    font-size: 12px;
    font-weight: 600;
    color: var(--text-primary);
    margin-bottom: 4px;
}
.recent-operation-item .operation-time {
    font-size: 11px;
    color: var(--text-muted);
}

/* 成功/失败徽标（主题化，替代 Bootstrap bg-success/bg-danger） */
.op-badge {
    display: inline-block;
    padding: 1px 8px;
    border-radius: 9px;
    font-size: 10px;
    color: #fff;
}
.op-badge.success { background: var(--accent-green); }
.op-badge.failed  { background: var(--accent-red); }

/* ---- 操作说明卡（Accordion 深色主题化） ---- */
.accordion-item {
    background: var(--bg-secondary);
    border: 1px solid var(--border);
    color: var(--text-primary);
    border-radius: 6px !important;
    margin-bottom: 6px;
    overflow: hidden;
}
.accordion-item:first-of-type,
.accordion-item:last-of-type { border-radius: 6px !important; }

.accordion-button {
    background: var(--bg-tertiary);
    color: var(--text-primary);
    font-size: 12px;
    font-weight: 600;
    padding: 8px 14px;
    box-shadow: none;
}
.accordion-button:not(.collapsed) {
    background: var(--bg-tertiary);
    color: var(--accent-blue);
    box-shadow: inset 0 -1px 0 var(--border);
}
.accordion-button:focus { box-shadow: none; }

/* Bootstrap 折叠箭头为黑色 SVG，深色主题反白 */
.accordion-button::after { filter: invert(0.7); }

.accordion-body {
    background: var(--bg-secondary);
    color: var(--text-secondary);
    font-size: 12px;
    padding: 10px 14px;
}
.accordion-body p  { color: var(--text-secondary); margin-bottom: 6px; }
.accordion-body ul { margin: 0; padding-left: 18px; }
.accordion-body li { color: var(--text-secondary); margin-bottom: 3px; }
.accordion-body strong { color: var(--text-primary); font-weight: 600; }

/* 操作说明提示行（替代 Bootstrap text-info/warning/danger） */
.help-note {
    font-size: 11px;
    margin-top: 8px;
    display: flex;
    align-items: center;
    gap: 5px;
}
.help-note.info    { color: var(--accent-blue); }
.help-note.warning { color: var(--accent-orange); }
.help-note.danger  { color: var(--accent-red); }

/* 浅色主题：折叠箭头恢复黑色 */
[data-theme="light"] .accordion-button::after { filter: none; }
```

## 5. 验证清单

1. "最近操作"卡：卡片头与首页一致；"查看更多"为描边小按钮（`btn-outline btn-sm`），点击后仍调用 `loadMoreOperations()`（每次 +10 条）；
2. 操作条目：深色底、浅色标题、灰色时间，成功/失败徽标颜色与主题色板一致；
3. "操作说明"卡：折叠面板深色底浅色字，展开/收起动画正常，箭头可见；
4. 三处提示行颜色（蓝/橙/红）与主题 accent 色一致；
5. 浅色主题切换后：两卡文字、按钮、箭头对比度正常；
6. 其余卡片与功能（节点控制/服务管理/操作日志弹窗）不受影响；
7. `Ctrl+F5` 强制刷新确认静态资源更新。
