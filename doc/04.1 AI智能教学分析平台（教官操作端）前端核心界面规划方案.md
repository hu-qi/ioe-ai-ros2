# 04 AI智能教学分析平台（教官操作端）
## 前端核心界面规划方案 v2.0（整合优化版）

> 版本：v2.0  
> 对应产品定义：v3.1（按工序区分评分与诊断）  
> 对应技术方案：v1.2  
> 使用环境：教官办公室台式机，**Web 浏览器（鼠标 + 键盘，非触屏）**  
> **本次修订核心**：
> 1. **首页、学员、报告（诊断与闭环整合）** 三大核心页面；
> 2. **取消近 7 天趋势图**，首页聚焦“实时动态 + 诊断热点 + 需关注学员”；
> 3. **尽量不用跳转**，详情内容以内嵌展开呈现，减少上下文丢失。


---

## 一、设计原则（修订）

| 原则 | 说明 |
|------|------|
| **三页核心** | 平台只保留三大主页面：**首页、学员、报告**；诊断与闭环整合进报告页。 |
| **首页即驾驶舱** | 打开首页即看到“正在发生什么”和“最需要关注什么”。 |
| **不打断上下文** | 详情优先内嵌展开，**避免跳转独立页面**。 |
| **数据→行动** | 每个诊断结论旁附“教官该做什么”的建议，而非只给数字。 |
| **按工序区分** | 所有涉及评分、诊断、统计的界面均支持按工序（三种科目（自动机/输弹机/扣机）拆解/组装）以及 全部 筛选，工序由上报的操作流程名称。 |
| **鼠标优先** | 悬停提示、右键菜单、键盘快捷键，针对 PC 浏览器优化。 |
| **一屏看清** | 关键信息在一屏内呈现，避免频繁滚动与跳转。 |

## 二、整体信息架构（修订）

```
AI智能教学分析平台（教官操作端）
├── 首页（Dashboard）
│   ├── 实时训练动态（当前设备/学员/工序/进度）
│   ├── 概览（考试人数、平均分）
│   ├── 五维诊断热点（Top 3，点击展开详情）
│   └── 需关注学员列表
│
├── 学员（Students）
│   ├── 学员列表（搜索、筛选、批量导入）
│   └── 学员详情（个体追踪、趋势、薄弱步骤、历史报告）
│
├── 报告（Reports，整合诊断与闭环）
│   ├── 报告列表（按学员/工序/时间/完成率筛选）
│   ├── 报告详情（时间线 + 子步骤得分 + 抓拍图 + 总分等级）
│   ├── 五维诊断（班级 + 工序，诊断结果 + 建议 + 证据）
│   └── 教学闭环（教学调整记录 + 改进效果对比）
│
└── 系统设置（Settings，侧边入口）
    ├── 评分规则配置（按工序）
    ├── 诊断阈值配置（按工序）
    └── 学员同步
```

**关键变化**：
- 取消独立的“诊断中心”“教学闭环”菜单，整合进“报告”页的 Tab。
- 取消“近 7 天趋势”图表，首页更聚焦。
- 所有详情优先**内嵌展开**。

### 3.2 区域①：实时训练动态

**目的**：一眼看到当前训练，实时步骤推进。

**界面元素**：

| 元素 | 内容 | 交互 |
|------|------|------|
| 设备/学员/工序 | 当前设备 ID、学员姓名、工序名称 | 点击学员名进入学员详情 |
| 实时进度条 | 已完成子步骤 / 总子步骤 | 悬停显示当前子步骤名 |
| 当前子步骤 | 名称 + 已用时长 / 标准时长 | 超时高亮（橙色） |
| 实时事件流 | 最近 10 条事件 + 时间偏移 | 滚动，新事件置顶 |


**内嵌展开设计**：
  抓拍缩略图是作为超时步骤学员的证据来呈现。

**刷新机制**：每 2 秒轮询 `/api/v1/dashboard/realtime` （如已实现请忽略，先评估必要性）。

### 3.3 区域②：概览

**指标卡片**（4 个）：

| 卡片 | 指标 | 交互 |
|------|------|------|
| 考试人数 | 完成的轮次数 | 点击跳转报告列表（可筛选如今日） |
| 平均分 | 所有轮次平均总分 | 点击跳转报告列表 |
| 通过率 | 得分 ≥60 的比例 | 点击跳转报告列表 |
| 待辅导学员 | 退步预警 + 薄弱环节突出的人数 | 点击跳转学员列表（筛选待辅导） |

**设计要点**：
- 白底，圆角 8px，左侧 4px 色条。
- 数值 28px 加粗，状态色。
- 辅助文字 12px 灰色，显示环比变化。
- 悬停轻微上浮，鼠标变手型。

## 七、交互规范（修订：减少弹窗）

### 7.1 详情展示方式（优先级）

| 方式 | 使用场景 | 示例 |
|------|----------|------|
| **内嵌展开** | 列表中的条目详情、诊断详情、证据大图、特定场景的详情 | 诊断条目展开、抓拍大图、报告详情 | 
| **独立页面** | 报告详情、学员详情、设置页 | 点击“查看报告”跳转 |
| **Tab 切换** | 同一页面的不同视图 | 报告页的诊断/闭环 Tab |
| **弹窗（仅限）** | 确认类操作（删除、回滚） | 删除学员确认 |

## 九、总结

本方案在 v1.0 基础上，根据产品核心与建议完成三大修订：

1. **三页核心**：首页、学员、报告（诊断与闭环整合进报告页 Tab），信息架构更简洁。
2. **取消 7 日趋势**：首页聚焦实时动态、概览、五维诊断热点、需关注学员、最近完成轮次。
3. **减少弹窗**：详情优先内嵌展开或独立页面，仅确认类操作使用弹窗。

同时保留并强化：
- **实时训练动态**：进度条 + 事件流 + 抓拍缩略图。
- **五维诊断热点**：Top 3 + 建议 + 证据，点击内嵌展开。
- **操作记录与评分**：报告详情页时间线 + 得分明细 + 证据图墙（按子步骤分组）。
- **学员个体追踪**：趋势 + 薄弱步骤 + 退步预警。
- **教学闭环**：状态标签 + 改进效果对比。
- **按工序区分**：所有界面支持工序筛选。

设计针对 PC 浏览器优化，配合 Element Plus + ECharts 轻量构建，首屏 gzip 后 < 500KB，适合教官办公室台式机使用。本方案可作为前端开发与验收的基准文档。
