## 2. 功能增强一：参数配置 Web 化 + 热加载

### 2.1 业务场景

生产现场需要根据物料类型调整仓位映射关系，例如：

- 某批次 type=1 物料较多，将部分 type=2 仓位临时改为 type=1
- 终点仓位按楼层分配变化，需要重新配置 T4xxx 层 cargo_type
- 工作时段调整（节假日加班、检修停产）

**关键要求**: 修改后立即生效，无需重启 ROS2 节点。

```http

Content-Type: application/json

{
  "mappings": {
```

**后端处理逻辑**:

```python
# web_server.py — 新增端点
@app.put("/api/config/bay")
async def update_bay_config(data: dict):
    """
    接收仓位配置更新 → 写入 params.yaml → 触发热加载
    
    安全约束:
      1. 仅允许修改 cargo_type (1~6)
      2. bay_id 必须存在于现有配置中
      3. 通过 ROS2 set_parameter 触发回调
    """
    try:
        mappings = data.get('mappings', {})
        # 1. 校验
        valid_types = {1, 2, 3, 4, 5, 6}
        for bay_id, cargo_type in mappings.items():
            if cargo_type not in valid_types:
                raise ValueError(f"{bay_id}: cargo_type 必须为 1~6, 收到 {cargo_type}")

        # 2. 写入 params.yaml
        self._update_yaml_config('bay_configs', mappings)

        # 3. 触发热加载
        self._trigger_hot_reload('bay_configs', mappings)

        # 4. 返回
        return {
            "success": True,
            "message": f"已更新 {len(mappings)} 个仓位配置",
            "hot_reload": True
        }
    except Exception as e:
        return {"success": False, "error": str(e)}
```

### 2.4 params.yaml 热加载实现

```python
# param_manager.py — 新增方法
def trigger_config_reload(self, config_key: str, new_value: Any):
    """
    触发配置热加载
    
    流程:
      1. 更新 ROS2 parameter（触发 on_parameter_event 回调）
      2. 回调中调用各插件的 reload_config() 方法
    """
    import yaml
    
    # 读取并更新 params.yaml
    yaml_path = self._get_params_yaml_path()
    with open(yaml_path, 'r', encoding='utf-8') as f:
        config = yaml.safe_load(f)
    
    # 更新 bay_configs 节点
    app_config = config.get('app_mgr_object', {}).get('ros__parameters', {})
    plugin_configs_str = app_config.get('plugin_configs', '')
    
    if isinstance(plugin_configs_str, str):
        plugin_configs = yaml.safe_load(plugin_configs_str)
    else:
        plugin_configs = plugin_configs_str
    
    # 更新目标配置段
    if config_key == 'bay_configs':
        plugin_configs['bay_status_fusion']['bay_configs'] = new_value
    elif config_key == 'dest_bay_configs':
        plugin_configs['status_poller']['dest_bay_configs'] = new_value
    elif config_key == 'schedules':
        plugin_configs['work_schedule']['schedules'] = new_value
    
    # 写回文件
    app_config['plugin_configs'] = yaml.dump(plugin_configs, allow_unicode=True)
    config['app_mgr_object']['ros__parameters'] = app_config
    
    with open(yaml_path, 'w', encoding='utf-8') as f:
        yaml.dump(config, f, allow_unicode=True, default_flow_style=False)
    
    # 通过 ROS2 parameter 触发回调
    from rcl_interfaces.msg import Parameter, ParameterValue, ParameterType
    param = Parameter()
    param.name = 'plugin_configs'
    param.value.type = ParameterType.PARAMETER_STRING
    param.value.string_value = yaml.dump(plugin_configs, allow_unicode=True)
    
    self.node.set_parameters([param])
    self.logger.info(f"配置热加载已触发: {config_key}")

def _get_params_yaml_path(self) -> str:
    """获取 params.yaml 的绝对路径"""
    import os
    from ament_index_python.packages import get_package_share_directory
    pkg_share = get_package_share_directory('app_mgr_object')
    return os.path.join(pkg_share, 'config', 'params.yaml')
```

## 3. 功能增强二：工作流人工操作控制台

### 3.1 操作能力矩阵

基于 `workflow_engine_plugin.py` 中的 `task_control` ROS2 服务，支持以下操作：

| 操作 | 适用状态 | ROS2 事件 | 说明 | 需要确认 |
|:---|:---|:---|:---|:---|
| **重试** | `manual_intervention` | `user_retry` → `calling_rcs` | 重新下发 RCS 任务 | ✓ 二次确认 |
| **取消** | `manual_intervention` / `monitoring` | `user_cancel` → `failed` | 取消任务，释放资源 | ✓ 二次确认 |
| **强制触发** | — (新建) | 直接调用 `trigger_engine` | 手动为一个仓位对生成任务 | ✓ 确认 |
| **继续执行** | `calling_rcs` 失败 | `continue_task` | RCS 接口 continueTask | ✓ 确认 |
| **查询详情** | 任意 | `query` | 返回实例状态+上下文 | — |

### 3.2 API 端点新增

```http
POST /api/task/control
Content-Type: application/json

{
  "operation": "retry",     // retry | cancel | force_trigger | continue | query
  "task_id": "TASK_A1001_1723456000",
  "force": false            // 可选，强制取消
}
```

响应：

```json
{
  "success": true,
  "message": "任务重试命令已发送: TASK_A1001_1723456000",
```

**后端实现**:

```python
# web_server.py — 新增端点
@app.post("/api/task/control")
async def task_control_api(data: dict):
    """
    工作流人工操作端点
    
    操作类型:
      - retry: 从 manual_intervention 重试
      - cancel: 取消任务
      - force_trigger: 手动触发任务
      - continue: RCS continueTask
      - query: 查询任务详情
    """
    op = data.get('operation', '')
    task_id = data.get('task_id', '')
    force = data.get('force', False)
    
    # 获取 workflow_engine 插件
    wf_plugin = getattr(self.node, 'workflow_engine', None)
    if not wf_plugin:
        wf_plugin = self.node.plugin_manager.get_plugin('workflow_engine')
    
    if not wf_plugin:
        return {"success": False, "error": "工作流引擎未加载"}
    
    try:
        if op == 'force_trigger':
            # 手动触发：直接调用 smart_trigger
            src_bay = data.get('src_bay', '')
            dst_bay = data.get('dst_bay', '')
            cargo_type = data.get('cargo_type', 0)
            trigger = self.node.plugin_manager.get_plugin('smart_trigger')
            if trigger:
                ctx = trigger._trigger_engine.scan(cargo_type)
                if ctx:
                    trigger._publish_event('trigger.task_created', ctx.to_dict())
                    return {"success": True, "task_id": ctx.task_id, "message": "任务已手动触发"}
            return {"success": False, "error": "触发失败，条件不满足"}
        
        # 委托给 workflow_engine 的 task_control 服务
        import asyncio
        loop = wf_plugin._loop
        
        if op == 'query':
            instance = wf_plugin._engine.get_instance(task_id)
            if instance:
                return {
                    "success": True,
                    "task_id": task_id,
                    "current_state": instance.current_state,
                    "status": instance.status,
                    "duration": instance.duration,
                    "context": {
                        "src_bay": instance.context.get('src_bay'),
                        "dst_bay": instance.context.get('dst_bay'),
                        "robot_id": instance.context.get('robot_id'),
                        "cargo_type": instance.context.get('cargo_type'),
                        "rcs_task_no": instance.context.get('rcs_task_no'),
                    }
                }
            return {"success": False, "error": f"任务不存在: {task_id}"}
        
        # retry / cancel
        event_map = {'retry': 'user_retry', 'cancel': 'user_cancel'}
        event = event_map.get(op, op)
        
        future = asyncio.run_coroutine_threadsafe(
            wf_plugin._engine.inject_event(task_id, event, {}),
            loop
        )
        
        return {
            "success": True,
            "message": f"操作 {op} 已发送: {task_id}",
            "task_id": task_id,
            "operation": op
        }
        
    except Exception as e:
        return {"success": False, "error": str(e)}
```

## 4. 功能增强三：首页一体化工业仪表盘

### 4.1 设计理念

- **一屏全览**: 打开首页即可看到系统健康 + 仓位状态 + AGV 状态 + 任务进度
- **工业简洁**: 卡片式布局，信息密度适中，不堆砌数据
- **颜色语义化**: 绿色=正常/可用，橙色=忙碌/等待，红色=故障/异常，灰色=离线/空
- **操作就近**: 需要操作的区域旁直接放置按钮（如仓位配置入口、任务操作）
- **面板可折叠**: 非核心面板默认收起，按需展开

### 6.1 Toast 通知规范

```javascript
// 增强版 Toast 通知系统
const Toast = {
    show(title, message, type = 'info', duration = 5000) {
        const colors = {
            success: '#27ae60',
            error:   '#e74c3c',
            warning: '#f39c12',
            info:    '#3498db',
        };

        const icons = {
            success: 'fa-check-circle',
            error:   'fa-exclamation-circle',
            warning: 'fa-exclamation-triangle',
            info:    'fa-info-circle',
        };

        const toast = document.createElement('div');
        toast.className = 'toast-notification';
        toast.style.cssText = `
            position: fixed;
            top: 20px;
            right: 20px;
            z-index: 9999;
            min-width: 320px;
            max-width: 420px;
            background: white;
            border-left: 4px solid ${colors[type]};
            border-radius: 8px;
            box-shadow: 0 4px 20px rgba(0,0,0,0.15);
            padding: 14px 18px;
            animation: slideInRight 0.3s ease;
            font-family: 'Segoe UI', sans-serif;
        `;

        toast.innerHTML = `
            <div style="display: flex; align-items: flex-start; gap: 10px;">
                <i class="fas ${icons[type]}" style="color: ${colors[type]}; font-size: 20px; margin-top: 2px;"></i>
                <div style="flex: 1;">
                    <div style="font-weight: 600; font-size: 14px; color: #2c3e50;">${title}</div>
                    <div style="font-size: 13px; color: #666; margin-top: 4px;">${message}</div>
                </div>
                <button onclick="this.parentElement.parentElement.remove()"
                    style="background: none; border: none; color: #999; cursor: pointer; font-size: 16px;">×</button>
            </div>
        `;

        document.body.appendChild(toast);
        setTimeout(() => {
            toast.style.animation = 'slideOutRight 0.3s ease';
            setTimeout(() => toast.remove(), 300);
        }, duration);
    }
};
```

### 6.2 操作确认 Modal 规范

```javascript
// 确认弹窗（工业风格）
function confirmOperation(title, description, consequences, onConfirm) {
    const modal = document.getElementById('confirmModal');
    const titleEl = document.getElementById('confirmTitle');
    const descEl = document.getElementById('confirmDescription');
    const conseqEl = document.getElementById('confirmConsequences');
    const confirmBtn = document.getElementById('confirmBtn');

    titleEl.innerHTML = `<i class="fas fa-exclamation-triangle" style="color: #f39c12;"></i> ${title}`;
    descEl.textContent = description;

    let conseqHtml = '<ul style="margin: 0; padding-left: 20px; color: #666; font-size: 13px;">';
    consequences.forEach(c => conseqHtml += `<li>${c}</li>`);
    conseqHtml += '</ul>';
    conseqEl.innerHTML = conseqHtml;

    confirmBtn.onclick = () => {
        onConfirm();
        bootstrap.Modal.getInstance(modal).hide();
    };

    new bootstrap.Modal(modal).show();
}
```
